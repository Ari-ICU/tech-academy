## 🌐 សេចក្តីផ្តើម (Overview)

មុននឹងធ្វើការសន្និដ្ឋានអ្វីមួយ Data Analyst ត្រូវស្គាល់ទិន្នន័យរបស់ខ្លួនអោយច្បាស់សិន។ **EDA (Exploratory Data Analysis)** គឺជាដំណើរការនៃការស៊ើបអង្កេតទិន្នន័យ ហើយជំហានដំបូងនៃ EDA គឺការមើល **ស្ថិតិពិពណ៌នា (Descriptive Statistics)**។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការប្រើប្រាស់ `describe()`

```python
import pandas as pd

df = pd.DataFrame({
    'Salary': [500, 600, 550, 800, 1200, 500, 650]
})

print(df.describe())
```
**លទ្ធផល:**
- `count`: ចំនួនជួរ
- `mean`: មធ្យមភាគ
- `std`: គម្លាតស្តង់ដារ (ការបែកខ្ញែក)
- `min`, `max`, `25%`, `50%`, `75%`: តម្លៃអប្បបរមា អតិបរមា និង Quartiles

### ២. គណនាដោយដៃ (Mean, Median, Mode)

```python
print("Mean:", df['Salary'].mean())
print("Median:", df['Salary'].median())
print("Mode:", df['Salary'].mode()[0])
```
