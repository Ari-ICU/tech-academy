## 🌐 សេចក្តីផ្តើម (Overview)

**Univariate Analysis (វិភាគឯកអថេរ)** គឺជាការផ្តោតទៅលើជួរឈរតែមួយគត់ (១ អថេរ) ដោយមិនខ្វល់ពីជួរឈរផ្សេងទៀត។ គោលបំណងគឺដើម្បីមើលថា តើទិន្នន័យនៅក្នុងជួរឈរនោះ មានរូបរាងបែបណា (Distribution) និងមានកម្រិតប្រមូលផ្តុំនៅត្រង់ណា?

---

## 💻 ការបំបែកកូដ (Code Breakdown)

ឧបមាថាយើងមាន DataFrame `df` កត់ត្រាការលក់របស់ហាងមួយ៖

### ១. វិភាគលើទិន្នន័យប្រភេទអក្សរ (Categorical Variables)

ឧទាហរណ៍៖ "តើអតិថិជនយើងភាគច្រើនជាប្រុស ឫស្រី?" ឬ "តើទំនិញមួយណាលក់ដាច់ជាងគេ?"

```python
import pandas as pd

data = {'ភេទ': ['ប្រុស', 'ស្រី', 'ស្រី', 'ប្រុស', 'ស្រី'], 
        'អាយុ': [25, 30, 22, 40, 28]}
df = pd.DataFrame(data)

# ប្រើប្រាស់ value_counts() ដើម្បីរាប់ចំនួន
gender_counts = df['ភេទ'].value_counts()

print("ចំនួនអតិថិជនតាមភេទ:")
print(gender_counts)

# ចង់មើលជាភាគរយ (Percentage) ? គ្រាន់តែថែម normalize=True
gender_percent = df['ភេទ'].value_counts(normalize=True) * 100
print("\nគិតជាភាគរយ:")
print(gender_percent)
```

**លទ្ធផល:**
```text
ស្រី      60.0
ប្រុស    40.0
Name: ភេទ, dtype: float64
```

### ២. វិភាគលើទិន្នន័យប្រភេទលេខ (Numerical Variables)

សម្រាប់ជួរឈរជាលេខ (ឧ. អាយុ, ប្រាក់ខែ, តម្លៃ) អ្នកមិនអាចរាប់ `value_counts()` ទេ ព្រោះអាយុអាចខុសគ្នាទាំងអស់ (25.5, 26, 26.2...)។ យើងត្រូវប្រើស្ថិតិ!

```python
# មើលស្ថិតិសង្ខេប (បានរៀនក្នុងម៉ូឌុលមុនរួចហើយ)
print(df['អាយុ'].describe())
```
**អ្វីដែលយើងអាចសន្និដ្ឋានបាន (Insights):**
- បើមើលឃើញ Mean ធំជាង Median (50%) ឆ្ងាយ មានន័យថាមានអ្នកអាយុច្រើនៗ (Outliers) ទាញទិន្នន័យអោយលម្អៀង។
- ភាគច្រើនអតិថិជនយើងស្ថិតក្នុងវ័យ ២០ ទៅ ៣០ ឆ្នាំ។

ការវិភាគឯកអថេរ (Univariate) គឺជាជំហានដំបូង មុននឹងយើងយកអថេរទាំងពីរ (ឧ. ភេទ និង អាយុ) មកប្រៀបធៀបគ្នាក្នុង Bivariate Analysis!
