## 🌐 សេចក្តីផ្តើម (Overview)

អ្នកបានរៀនកូដអស់ហើយ! ឥឡូវនេះគឺជាជំនាញទន់ (Soft Skill)។ **Insight** មិនមែនគ្រាន់តែជាការអានតួលេខនោះទេ (ឧ. "ថ្ងៃនេះលក់បាន ១០០ កែវ")។ Insight គឺជាការប្រាប់ពី "ហេតុផល" និង "ចំណុចគួរកែប្រែ" (ឧ. "ថ្ងៃនេះលក់កាហ្វេបាន ១០០កែវ កើនឡើង ៥០% ព្រោះយើងទើបបញ្ចុះតម្លៃសម្រាប់សិស្សសាលា។ យើងគួរធ្វើកម្មវិធីនេះរាល់ថ្ងៃច័ន្ទ!")។

## 💼 ក្បួនបង្កើត Insights ល្អៗ (Data Storytelling)

ដើម្បីប្រែក្លាយតួលេខទៅជា Insights អ្នកត្រូវឆ្លើយសំណួរ ៣ នេះតាមលំដាប់៖

### ១. តើមានអ្វីកើតឡើង? (What happened?)
- **ទិន្នន័យ:** `df.groupby('ខែ')['ចំណូល'].sum()` បង្ហាញថាខែ ១១ ចំណូលធ្លាក់ចុះ។
- **ការពន្យល់:** ចំណូលខែវិច្ឆិកាបានធ្លាក់ចុះ ២០% ធៀបនឹងខែតុលា។

### ២. ហេតុអ្វីបានជាវាកើតឡើង? (Why did it happen?)
អ្នកត្រូវយកជួរឈរផ្សេងទៀតមកធ្វើ **Bivariate Analysis** ដើម្បីរកមូលហេតុ។
- **ទិន្នន័យ:** ពេលអ្នកធ្វើ `df.groupby(['ខែ', 'ប្រភេទទំនិញ'])` អ្នកឃើញថា អាវរងា លក់លែងចេញ។
- **ការពន្យល់:** ការធ្លាក់ចុះនេះ បណ្តាលមកពីការលក់អាវរងាធ្លាក់ចុះ ព្រោះខែវិច្ឆិកាឆ្នាំនេះ អាកាសធាតុនៅតែក្តៅខ្លាំង។

### ៣. តើយើងគួរធ្វើអ្វីបន្ត? (So What? / Recommendations)
នេះជាចំណុចដែលកំណត់ថាអ្នកជា Data Analyst ធម្មតា ឬជា Data Analyst ឆ្នើម!
- **អនុសាសន៍:** យើងគួរតែផ្អាកការកុម្ម៉ង់អាវរងាពីចិនសិន ហើយបញ្ចេញស្តុកខោអាវរដូវក្តៅមកលក់ជំនួសវិញ ជាមួយនឹងប្រូម៉ូសិនទិញ ២ ថែម ១ ដើម្បីទាញចំណូលមកវិញ។

**សន្និដ្ឋាន:** ការវិភាគទិន្នន័យ គឺជាការស៊ើបអង្កេតដូចប៉ូលិស (Detective Work)! អ្នកត្រូវជីកកកាយពីរឿងមួយ ទៅរឿងមួយ រហូតរកឃើញឬសគល់នៃបញ្ហា។ ត្រៀមខ្លួនសម្រាប់ធ្វើ Mini Project ចុងបញ្ចប់នៃ Phase 2 ហើយឬនៅ?
