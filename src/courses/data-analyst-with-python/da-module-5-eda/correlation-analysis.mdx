## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងមេរៀន Bivariate យើងបានរៀនត្រួសៗរួចហើយ។ ឥឡូវនេះយើងនឹងចូលអោយជ្រៅបន្តិច! **Correlation (សហសម្ព័ន្ធ)** គឺជាការវាស់ស្ទង់ថាតើលេខក្នុងជួរឈរពីរ ផ្លាស់ប្តូរតាមគ្នាដែរឬទេ?
តម្លៃរបស់វា (ហៅថា r) តែងតែស្ថិតនៅចន្លោះពី **-1 ដល់ 1**:
- **+1 (Positive):** ដើរស្របទិសគ្នា (ឧ. បទពិសោធន៍ការងារកើន -> ប្រាក់ខែកើន)
- **-1 (Negative):** ដើរផ្ទុយទិស (ឧ. បញ្ចុះតម្លៃទំនិញកាន់តែច្រើន -> ប្រាក់ចំណេញកាន់តែតិច)
- **0 (Neutral):** គ្មានពាក់ព័ន្ធគ្នាទាល់តែសោះ (ឧ. ទំហំស្បែកជើង និង IQ)

## 💻 ការបំបែកកូដ (Code Breakdown)

ឧបមាថាយើងមាន DataFrame ដែលមានជួរឈរជាលេខសុទ្ធ ចំនួន ៣។ យើងមិនបាច់បញ្ជាក់ជួរឈរម្តងមួយៗទេ យើងអាចវាយតម្លៃតារាងទាំងមូល (Correlation Matrix) បានតែម្តង!

```python
import pandas as pd

# ទិន្នន័យចំណាយលើការផ្សាយពាណិជ្ជកម្ម (Ads), ចំនួនអ្នកចូលមើល (Visits) និង ចំណេញ (Profit)
data = {
    'លុយផ្សាយពាណិជ្ជកម្ម': [10, 20, 30, 40, 50],
    'អ្នកចូលមើល': [100, 250, 290, 410, 500],
    'តម្លៃជួលតូប': [500, 500, 500, 500, 500]
}
df = pd.DataFrame(data)

# គណនា Correlation គ្រប់ជួរឈរទាំងអស់
corr_matrix = df.corr()

print(corr_matrix)
```
**លទ្ធផលរំពឹងទុក:**
```text
                     លុយផ្សាយពាណិជ្ជកម្ម   អ្នកចូលមើល   តម្លៃជួលតូប
លុយផ្សាយពាណិជ្ជកម្ម                 1.00        0.98          NaN
អ្នកចូលមើល                         0.98        1.00          NaN
តម្លៃជួលតូប                           NaN         NaN          NaN
```
**ការបកស្រាយ (Insights):**
- **0.98 រវាង លុយផ្សាយ និង អ្នកចូលមើល:** ទំនាក់ទំនងស្របគ្នាខ្លាំងណាស់ (ជិត 1.0)។ ន័យថា ចំណាយលុយផ្សាយកាន់តែច្រើន មនុស្សចូលមើលកាន់តែកើន!
- **តម្លៃជួលតូបចេញ NaN:** ព្រោះវាជាលេខ 500 ថេររហូត មិនមានការប្រែប្រួល (No variance) ទើបមិនអាចវាស់ស្ទង់បាន។

### ⚠️ ចំណាំដ៏សំខាន់ (Correlation $\neq$ Causation)
ទោះបីជា "លុយផ្សាយពាណិជ្ជកម្ម" និង "អ្នកចូលមើល" មាន Correlation កម្រិត 0.98 ក៏ដោយ ក៏អ្នកមិនអាចសន្និដ្ឋានថា *"ការចំណាយលុយ គឺជាហេតុផលតែមួយគត់ដែលធ្វើអោយមនុស្សចូលមើល"* នោះទេ។ អាចមានកត្តាផ្សេងដូចជា ខែហ្នឹងជាខែបុណ្យទាន ទើបមនុស្សទិញច្រើន។ នេះជាច្បាប់មាសក្នុង Data Science!
