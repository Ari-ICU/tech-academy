## 🌐 សេចក្តីផ្តើម (Overview)

**Outlier (ទិន្នន័យខុសប្រក្រតី)** គឺជាលេខដែលស្ថិតនៅឆ្ងាយដាច់ពីគេ។ ឧទាហរណ៍៖ អាយុ 15, 20, 22, 25, 21, **150**។ លេខ 150 គឺជា Outlier! វាអាចបណ្តាលមកពីការវាយបញ្ចូលខុស ឫជាព្រឹត្តិការណ៍ពិតតែកម្រកើតមាន (ឧ. មហាសេដ្ឋី Bill Gates ដើរចូលមកទិញកាហ្វេ)។ ការស្វែងរកវាអោយឃើញ គឺជាកាតព្វកិច្ចរបស់អ្នក!

## 💻 ការបំបែកកូដ (Code Breakdown)

ឧបមាថាយើងមាន DataFrame `df`:
```python
import pandas as pd

data = {'ប្រាក់ខែ': [500, 550, 480, 600, 520, 1000000, 490]}
df = pd.DataFrame(data)
```

### ជំហានទី ១៖ ប្រើ `.describe()` ដើម្បីត្រួតពិនិត្យជាមុន

```python
print(df['ប្រាក់ខែ'].describe())
```
**លទ្ធផល:**
```text
count          7.0
mean      143305.7   <-- មើលចុះ! មធ្យមភាគឡើងដល់ 14 ម៉ឺន!
min          480.0
50%          520.0   <-- (Median) បុគ្គលិកកណ្តាលគេ បានត្រឹមតែ 520 ទេ
max      1000000.0   <-- នេះហើយជនល្មើស!
```
គ្រាន់តែប្រៀបធៀប **Mean** និង **50% (Median)** អ្នកនឹងដឹងភ្លាមថាមាន Outlier កំពុងទាញទិន្នន័យឡើងលើ!

### ជំហានទី ២៖ ក្បួនសាមញ្ញដើម្បីចាប់ Outlier

សម្រាប់កម្រិតដំបូង យើងអាចប្រើប្រាស់ Boolean Filtering ដើម្បីកាត់យកជនល្មើសនោះចេញ។ ឧបមាថាយើងដឹងថា ក្រុមហ៊ុនយើងគ្មាននរណាប្រាក់ខែលើស $5000 ទេ។

```python
# ស្វែងរក Outlier
outliers = df[df['ប្រាក់ខែ'] > 5000]
print("នេះគឺជា Outlier:\n", outliers)

# បង្កើត DataFrame ថ្មីដែលគ្មាន Outlier (យកតែអ្នកប្រាក់ខែ < 5000)
clean_salaries = df[df['ប្រាក់ខែ'] <= 5000]
print("\nមធ្យមភាគពិតប្រាកដ:", clean_salaries['ប្រាក់ខែ'].mean())
# លទ្ធផល: 523.3 (ត្រឹមត្រូវតាមសភាពពិត!)
```

នៅក្នុងពិភព Data Science កម្រិតខ្ពស់ គេប្រើប្រាស់រូបមន្តស្ថិតិដូចជា **Z-Score** ឫ **IQR (Interquartile Range)** ដើម្បីគណនារកកម្រិតអតិបរមា (Max Limit) ដោយស្វ័យប្រវត្តិ។ យើងនឹងរៀនពីវានៅពេលបន្ទាប់!
