## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងពិភពការងារ សំណួរតែងតែមានភាពស្មុគស្មាញដែលទាមទារការពិចារណាលើកត្តាច្រើន។ **Bivariate Analysis (វិភាគទ្វេអថេរ)** គឺជាការយកជួរឈរ ២ មកប្រៀបធៀបគ្នា ដើម្បីមើលថា "តើអថេរទី ១ មានឥទ្ធិពលលើអថេរទី ២ ដែរឬទេ?" (ឧទាហរណ៍៖ តើបទពិសោធន៍ការងារកាន់តែច្រើន ធ្វើអោយប្រាក់ខែកាន់តែខ្ពស់មែនទេ?)។

## 💻 ការបំបែកកូដ (Code Breakdown)

### ករណីទី ១៖ អក្សរ vs លេខ (Categorical vs Numerical)

នេះជារឿងទូទៅបំផុត! "តើភេទមួយណា ចំណាយលុយច្រើនជាងគេ?"

```python
import pandas as pd

data = {
    'ភេទ': ['ប្រុស', 'ស្រី', 'ស្រី', 'ប្រុស', 'ស្រី'],
    'ចំណាយសរុប': [100, 250, 150, 120, 300]
}
df = pd.DataFrame(data)

# យើងប្រើ GroupBy ដែលរៀនកាលពី Module 3!
# ចងក្រងតាម 'ភេទ' រួចរកមធ្យមភាគ 'ចំណាយសរុប'
spending_by_gender = df.groupby('ភេទ')['ចំណាយសរុប'].mean()

print("ចំណាយជាមធ្យមតាមភេទ:")
print(spending_by_gender)
```
**Insights:** អ្នកនឹងឃើញថាអតិថិជនជាស្ត្រី ចំណាយលុយជាមធ្យមខ្ពស់ជាងបុរស។ ដូច្នេះ Marketing គួរតែតម្រង់ទិសទៅរកស្ត្រី!

### ករណីទី ២៖ លេខ vs លេខ (Numerical vs Numerical)

"តើអតិថិជនដែលមានអាយុច្រើន (ចាស់ៗ) ចំណាយលុយច្រើនជាងអតិថិជនវ័យក្មេងមែនទេ?" (អាយុ និង ចំណាយ ជាលេខទាំងពីរ)។

វិធីសាស្ត្រល្អបំផុត គឺប្រើប្រាស់ **Scatter Plot (ក្រាហ្វិកចំណុច)**។ ដោយសារតែយើងមិនទាន់ចូលដល់ Module 6 (Visualization) វិធីសាស្រ្តមួយទៀតគឺការគណនា **Correlation (សហសម្ព័ន្ធ)**។

```python
data_2 = {
    'អាយុ': [20, 25, 30, 35, 40],
    'ចំណាយសរុប': [50, 80, 110, 150, 200]
}
df_2 = pd.DataFrame(data_2)

# គណនា Correlation រវាងអាយុ និង ចំណាយ
correlation = df_2['អាយុ'].corr(df_2['ចំណាយសរុប'])

print(f"សហសម្ព័ន្ធ (Correlation): {correlation:.2f}")
```
**Insights:** ប្រសិនបើ Correlation ខិតជិតលេខ ១ (ឧ. 0.98) មានន័យថា អាយុកាន់តែច្រើន ចំណាយកាន់តែច្រើន (ទំនាក់ទំនងស្របទិសគ្នា)។
