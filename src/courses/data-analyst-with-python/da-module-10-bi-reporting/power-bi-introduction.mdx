## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងក្រុមហ៊ុនពិតប្រាកដ គ្មានថៅកែណាដែលបើកកម្មវិធី Jupyter Notebook ដើម្បីចូលទៅមើលក្រាហ្វិក Matplotlib របស់អ្នកនោះទេ។ ពួកគេចង់បានកម្មវិធីមួយដែលអាចចុច (Clickable) លើខែមករា ហើយក្រាហ្វិកទាំងអស់លោតប្តូរទិន្នន័យទៅខែមករាភ្លាមៗ។ 

នោះហើយជាការងាររបស់កម្មវិធី **Business Intelligence (BI)** ដូចជា **Microsoft Power BI** ឬ **Tableau**។

## 💻 លក្ខណៈពិសេសរបស់ Power BI

Power BI គឺជាកម្មវិធី (Software) របស់ក្រុមហ៊ុន Microsoft ដែលអនុញ្ញាតអោយអ្នកបង្កើត Interactive Dashboard ដោយមិនបាច់សរសេរកូដ (Drag and Drop)។

### ១. Interactive Filters (ចុចមួយ ប្រែប្រួលទាំងអស់)
- នៅលើ Power BI បើអ្នកចុចលើពាក្យ "ស្រី" នៅក្នុងក្រាហ្វិកទី១ នោះក្រាហ្វិកទី២ ទី៣ ទី៤ នឹងផ្លាស់ប្តូរលេខដោយស្វ័យប្រវត្តិ ដើម្បីបង្ហាញតែទិន្នន័យរបស់ "មនុស្សស្រី"។ នេះហៅថា **Cross-filtering** ដែល Matplotlib មិនអាចធ្វើបាន (លុះត្រាតែអ្នកសរសេរកូដឡើងវិញ)។

### ២. ការតភ្ជាប់ទិន្នន័យផ្ទាល់ (Live Connection)
- អ្នកអាចភ្ជាប់ Power BI ទៅកាន់ Database (SQL) របស់ក្រុមហ៊ុនដោយផ្ទាល់។ 
- រាល់ពេលដែលមានអតិថិជនថ្មីទិញអីវ៉ាន់ Dashboard របស់អ្នកនឹង Update តួលេខដោយស្វ័យប្រវត្តិ ដោយមិនបាច់អោយអ្នករត់កូដម្តងទៀតទេ។

### ៣. ងាយស្រួលចែករំលែក (Sharing)
- បន្ទាប់ពីបង្កើតរួច អ្នកអាចចុចប៊ូតុង `Publish` នោះ Dashboard របស់អ្នកនឹងហោះទៅកាន់ Cloud (Website)។ អ្នកអាចផ្ញើ Link ទៅអោយនាយកប្រតិបត្តិ (CEO) មើលនៅលើទូរស័ព្ទដៃ ឫ iPad របស់គាត់បានគ្រប់ទីកន្លែង។

## 🤝 Python + SQL + Power BI = The Dream Team

លំហូរការងារ (Workflow) ដ៏ល្អឥតខ្ចោះរបស់កំពូល Data Analyst:
1. **SQL:** ទាញយកទិន្នន័យពី Database
2. **Python (Pandas):** យកទិន្នន័យនោះមកសំអាត (Clean) ដក Outliers និងគណនាស្ថិតិស៊ីជម្រៅ (A/B Testing, Correlation) ដែល Power BI ពិបាកធ្វើ។
3. **Power BI:** ទាញយកទិន្នន័យដែលស្អាតពី Python មកគូរជា Dashboard រួចផ្ញើជូនថ្នាក់ដឹកនាំ!
