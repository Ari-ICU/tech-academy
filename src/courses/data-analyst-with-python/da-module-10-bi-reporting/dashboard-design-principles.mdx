## 🌐 សេចក្តីផ្តើម (Overview)

Dashboard គឺជា "ផ្ទាំងគ្រប់គ្រង" (ស្រដៀងនឹងកុងទ័រឡាន) ដែលអនុញ្ញាតអោយថៅកែមើលឃើញពីស្ថានភាពក្រុមហ៊ុនទាំងមូលត្រឹមមួយភ្លែត។ Dashboard ដែលអាក្រក់ នឹងធ្វើអោយអ្នកមើលវិលមុខ។ Dashboard ដែលល្អ នឹងប្រាប់រឿងរ៉ាវយ៉ាងច្បាស់លាស់។

---

## 💻 គោលការណ៍មាសទាំង ៤ នៃការរចនា (Golden Principles)

### ១. ច្បាប់ ៥ វិនាទី (The 5-Second Rule)
អ្នកមើល ត្រូវតែអាចឆ្លើយសំណួរថា "តើក្រុមហ៊ុនកំពុងល្អ ឫអាក្រក់?" ក្នុងរយៈពេល ៥ វិនាទីដំបូង ដែលពួកគេបើក Dashboard។ 
- **របៀបធ្វើ:** ប្រើពណ៌ **បៃតង** សម្រាប់កំណើន (ល្អ) និងពណ៌ **ក្រហម** សម្រាប់ការធ្លាក់ចុះ (អាក្រក់) រួមជាមួយសញ្ញាព្រួញ (ឡើង/ចុះ)។

### ២. ទម្រង់អានអក្សរ F (The F-Pattern Layout)
មនុស្សអានពីឆ្វេងទៅស្តាំ និងពីលើចុះក្រោម។
- **ខាងលើបំផុត (Top):** ដាក់សន្លឹកបៀរតួលេខ (Scorecards ឫ KPI) ដូចជា "ចំណូលសរុប: $1M" "អតិថិជនថ្មី: 5K"។
- **កណ្តាល (Middle):** ដាក់ក្រាហ្វិកបន្ទាត់ (Line Chart) មើលនិន្នាការតាមខែ និង Bar Chart។
- **ខាងក្រោម (Bottom):** ដាក់តារាងលម្អិត (Data Table) ឫបញ្ជីឈ្មោះអតិថិជនជំពាក់លុយ។

### ៣. ភាពសាមញ្ញ (Keep It Simple, Stupid - KISS)
- កុំប្រើក្រាហ្វិក 3D (វាធ្វើអោយទិន្នន័យខូចទ្រង់ទ្រាយពេលមើលពីចំហៀង)។
- កុំប្រើ Pie Chart បើមានចំណែកលើសពី ៤ (ប្រើ Bar Chart វិញ)។
- លុបចោល Gridlines (បន្ទាត់ក្រឡា) ដែលក្រាស់ៗពេក។ ធ្វើអោយផ្ទៃខាងក្រោយពណ៌ស ឫ ប្រផេះខ្ចី ស្រឡះភ្នែកល្អ។

### ៤. ភាពស៊ីសង្វាក់គ្នា (Consistency)
- បើអ្នកប្រើពណ៌ "ទឹកក្រូច" តំណាងអោយ "ផលិតផលកាហ្វេ" នៅក្នុងក្រាហ្វិកទី១។ នៅក្រាហ្វិកទី២ ទី៣ កាហ្វេក៏ត្រូវតែពណ៌ទឹកក្រូចដែរ។ 
- ការប្តូរពណ៌ចុះឡើង នឹងធ្វើអោយខួរក្បាលអ្នកមើលត្រូវចំណាយពេលគិតសាជាថ្មី។

នៅពេលអ្នកយល់ពីគោលការណ៍ទាំងនេះ ការបង្កើត Dashboard នៅក្នុងកម្មវិធីណាក៏ដោយ (ទោះជាប្រើ Python ឫ Power BI) គឺសុទ្ធតែទទួលបានលទ្ធផលកម្រិតស្តង់ដារពិភពលោកទាំងអស់។ មេរៀនបន្ទាប់ យើងនឹងស្គាល់ពីកម្មវិធី Power BI!
