## 🌐 សេចក្តីផ្តើម (Overview)

អ្នកបានខិតខំសំអាតទិន្នន័យ និងវិភាគរកឃើញ Business Insights ដ៏អស្ចារ្យ។ ឥឡូវនេះ ដល់ពេលត្រូវ "វេចខ្ចប់ (Package)" វាដើម្បីផ្ញើទៅប្រាប់អ្នកដទៃហើយ។ 

---

## 💻 របៀបនាំចេញ (Export Methods)

### ១. នាំចេញទិន្នន័យទៅជា Excel / CSV

ជួនកាល ថៅកែមិនទារមើលក្រាហ្វិកទេ គាត់គ្រាន់តែចង់បាន "បញ្ជីឈ្មោះអតិថិជន VIP" ដែលអ្នកទើបតែ Filter រួច យកទៅអោយផ្នែកលក់ដើម្បីតេហៅអតិថិជន។

```python
import pandas as pd

# ឧបមាថាអ្នកបានចម្រាញ់បានទិន្នន័យអតិថិជន VIP (df_vip)
# នាំចេញទៅជា Excel
df_vip.to_excel('vip_customers_report.xlsx', index=False)

# ឬនាំចេញទៅជា CSV (ស្រាលជាង)
df_vip.to_csv('vip_customers_report.csv', index=False)
```
*ចំណាំ៖ `index=False` ដើម្បីកុំអោយវាភ្ជាប់លេខរៀង (0,1,2...) របស់ Pandas ទៅក្នុង Excel នាំអោយទើសភ្នែក។*

### ២. នាំចេញ Notebook ជា HTML ឫ PDF

នៅក្នុង Jupyter Notebook ឫ Google Colab អ្នកអាចចុចទៅលើ `File` -> `Download as` ឫ `Export`។
អ្នកមានជម្រើស៖
- **HTML:** វានឹងបង្កើតជាឯកសារ Webpage (បើកដោយ Chrome) ដែលក្រាហ្វិកនៅស្អាតច្បាស់ល្អ អាច Zoom បាន។
- **PDF:** ល្អបំផុតសម្រាប់ការបោះពុម្ព (Print) និងចែកជូនក្នុងអង្គប្រជុំ។

### ៣. បច្ចេកទេសលាក់កូដ (Hiding Code)

ប្រសិនបើអ្នកប្រើ Jupyter Notebook (ក្នុងម៉ាស៊ីន) អ្នកអាចប្រើពាក្យបញ្ជា (Command Line) ដ៏មានឥទ្ធិពលនេះ ដើម្បីទាញយកតែក្រាហ្វិក និងអត្ថបទ តែលាក់កូដទាំងអស់ចោល!

```bash
# ដំឡើងឧបករណ៍
pip install nbconvert

# បំប្លែងរបាយការណ៍ឈ្មោះ analysis.ipynb ទៅជា HTML ដោយលាក់កូដ
jupyter nbconvert analysis.ipynb --to html --no-input
```

`--no-input` គឺជាអាថ៌កំបាំងដែលជួយកាត់ផ្តាច់កូដចោល ធ្វើអោយរបាយការណ៍របស់អ្នកមើលទៅដូចជាអត្ថបទកាសែត ដែលមានតែអក្សរពន្យល់ និងក្រាហ្វិកស្រស់ស្អាត។
