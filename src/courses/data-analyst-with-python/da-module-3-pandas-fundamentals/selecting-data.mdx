## 🌐 សេចក្តីផ្តើម (Overview)

តារាងទិន្នន័យពេលខ្លះមានដល់ទៅ ១០០ ជួរឈរ។ ដើម្បីងាយស្រួលធ្វើការ អ្នកប្រហែលជាចង់ទាញយកតែជួរឈរ "ឈ្មោះ" និង "ប្រាក់ខែ" មកមើលប៉ុណ្ណោះ។ ការជ្រើសរើសទិន្នន័យ (Selecting / Subsetting) គឺជាជំនាញមូលដ្ឋានដែលត្រូវប្រើប្រចាំថ្ងៃ។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

សន្មតថាយើងមាន DataFrame `df` បុគ្គលិកដូចខាងក្រោម៖
| លេខកាត (Index) | ឈ្មោះ | អាយុ | ប្រាក់ខែ |
| :--- | :--- | :--- | :--- |
| EMP01 | សុខ | 25 | 500 |
| EMP02 | សៅ | 30 | 800 |
| EMP03 | វ៉ាន់ | 22 | 450 |

### ១. ការជ្រើសរើសជួរឈរ (Columns)

```python
# ជ្រើសរើស ១ ជួរឈរ (លទ្ធផលចេញមកជា Series)
names = df["ឈ្មោះ"]
print(names)

# ជ្រើសរើស ច្រើនជួរឈរ (ត្រូវប្រើវង់ក្រចកជ្រុង ២ ជាន់ [[]] ព្រោះវាចេញជា DataFrame ថ្មី)
subset_df = df[["ឈ្មោះ", "ប្រាក់ខែ"]]
print(subset_df)
```

### ២. ការជ្រើសរើសជួរដេក (Rows) ដោយប្រើ `.loc[]` និង `.iloc[]`

Pandas មានក្បួនពីរក្នុងការស្វែងរកជួរដេក៖
- **`loc` (Location):** រកតាម "ឈ្មោះ (Label)" ដែលយើងឃើញនឹងភ្នែក (ឧ. `EMP02`)។
- **`iloc` (Integer Location):** រកតាម "លេខរៀងទីតាំង (Position)" ក្នុងកុំព្យូទ័រ ចាប់ពីសូន្យ (0, 1, 2...)។

```python
# ឧបមាថា Index របស់ DataFrame ត្រូវបានកំណត់ជា លេខកាត ('EMP01', 'EMP02'...)

# ប្រើ loc រកតាមឈ្មោះអក្សរ
print(df.loc["EMP02"]) 
# ចេញពត៌មានរបស់ សៅ (អាយុ 30, ប្រាក់ខែ 800)

# ប្រើ iloc រកតាមលេខរៀងទី ២ (Index = 1)
print(df.iloc[1]) 
# ចេញពត៌មានរបស់ សៅ ដូចគ្នា!
```

### ៣. ការកាត់តំបន់ទិន្នន័យ (Slicing ទាំងជួរដេក និងជួរឈរ)

អ្នកអាចបញ្ជាអោយទាញយកទាំង ជួរដេក និងជួរឈរ ក្នុងពេលតែមួយ ដោយប្រើរូបមន្ត `df.loc[ ជួរដេក , ជួរឈរ ]`។

```python
# ទាញយកតាំងពីបុគ្គលិក EMP01 ដល់ EMP02 ប៉ុន្តែយកតែជួរឈរ 'ឈ្មោះ' និង 'ប្រាក់ខែ'
area_data = df.loc["EMP01":"EMP02", ["ឈ្មោះ", "ប្រាក់ខែ"]]
print(area_data)

# ទាញយកបុគ្គលិកលេខរៀងទី 0 ដល់ 2 (ផ្តាច់មុខ) គ្រប់ជួរឈរទាំងអស់
slice_data = df.iloc[0:2, :]
print(slice_data)
```

ការប្រើ `loc` និង `iloc` អាចនឹងរាងច្របូកច្របល់បន្តិចនៅពេលដំបូង ប៉ុន្តែសូមចាំរូបមន្តនេះ៖ **"បើឃើញអក្សរប្រើ `loc` បើចង់រាប់លេខរៀងប្រើ `iloc`!"**
