## 🌐 សេចក្តីផ្តើម (Overview)

NumPy មាន 1D Array និង 2D Array។ ចំណែកឯ Pandas ក៏មានទម្រង់ដូចគ្នាដែរ ប៉ុន្តែវាផ្តល់ឈ្មោះពិរោះជាងមុនគឺ៖
- **Series** (ប្រៀបបាននឹង 1D Array ប៉ុន្តែមានឈ្មោះជួរឈរ)
- **DataFrame** (ប្រៀបបាននឹង 2D Array ឫ តារាង Excel)

---

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការបង្កើត Series (1 ជួរឈរ)

Series គឺជាជួរឈរតែមួយ ដែលមានលេខរៀង (Index) នៅខាងឆ្វេង។

```python
import pandas as pd

# បង្កើត Series ពី List ធម្មតា
ages = pd.Series([25, 30, 22, 28])
print(ages)

"""
លទ្ធផលដែលទទួលបាន:
0    25
1    30
2    22
3    28
dtype: int64  <-- ប្រាប់ថាវាជាលេខគត់
"""

# យើងអាចប្តូរលេខរៀង (Index) អោយទៅជាអក្សរបាន!
sales = pd.Series([100, 200, 150], index=['Jan', 'Feb', 'Mar'])
print("\nការលក់ប្រចាំខែ:\n", sales)
```

### ២. ការបង្កើត DataFrame (តារាង 2D)

DataFrame គឺជារចនាសម្ព័ន្ធទិន្នន័យដែលពេញនិយមបំផុត! វិធីងាយបំផុតក្នុងការបង្កើតវា គឺប្រើប្រាស់ Python Dictionary (Keys ក្លាយជាឈ្មោះជួរឈរ ឯ Values ក្លាយជាទិន្នន័យ)។

```python
# ១. រៀបចំទិន្នន័យក្នុង Dictionary
data = {
    'ឈ្មោះ': ['សុខ', 'សៅ', 'វ៉ាន់', 'លីណា'],
    'អាយុ': [25, 30, 22, 28],
    'ប្រាក់ខែ': [500, 800, 450, 700],
    'ផ្នែក': ['IT', 'HR', 'IT', 'Marketing']
}

# ២. បំប្លែងវាទៅជា DataFrame
df = pd.DataFrame(data)

# ៣. បង្ហាញលទ្ធផល (ក្នុង Jupyter Notebook វានឹងចេញជាតារាងយ៉ាងស្រស់ស្អាត)
print(df)
```

**លទ្ធផល:**
```text
  ឈ្មោះ  អាយុ  ប្រាក់ខែ      ផ្នែក
0   សុខ    25       500         IT
1   សៅ    30       800         HR
2  វ៉ាន់    22       450         IT
3 លីណា    28       700  Marketing
```

នៅក្នុងពិភពពិត យើងកម្រនឹងវាយទិន្នន័យបញ្ចូលដោយផ្ទាល់ដៃបែបនេះណាស់។ ផ្ទុយទៅវិញ យើងនឹងទាញយកទិន្នន័យពីរាប់ម៉ឺនជួរពីឯកសារ Excel ឬ CSV ដែលយើងនឹងរៀននៅមេរៀនបន្ទាប់!
