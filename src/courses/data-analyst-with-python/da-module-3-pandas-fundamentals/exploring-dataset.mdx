## 🌐 សេចក្តីផ្តើម (Overview)

នៅពេលអ្នកបើកឯកសារ CSV ដែលមានទំហំ ៥ លានជួរ អ្នកមិនអាចអូស (Scroll) មើលវាដោយភ្នែកបានទេ។ អ្នកត្រូវមានឧបករណ៍ដើម្បី "ស្ទាបស្ទង់ (Explore)" វាត្រួសៗ សិន មុននឹងសម្រេចចិត្តថាត្រូវវិភាគវាបែបណា។ Pandas ផ្តល់នូវមុខងារ ៤ ដ៏មានឥទ្ធិពលសម្រាប់កិច្ចការនេះ។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

ឧបមាថាយើងទើបតែអានឯកសារទិន្នន័យផ្ទះលក់ (Housing Data) ចូលមកក្នុងអថេរ `df` ។

### ១. មើលរាងរៅទិន្នន័យ (`head` និង `tail`)

```python
import pandas as pd
# សន្មតថាមានឯកសារនេះ
df = pd.read_csv("housing.csv")

# មើល ៥ ជួរដំបូងគេបង្អស់ (អ្នកអាចដាក់លេខក្នុងវង់ក្រចក ឧ. head(10))
print(df.head())

# មើល ៥ ជួរចុងក្រោយគេបង្អស់
print(df.tail())
```

### ២. ត្រួតពិនិត្យទំហំ និងប្រភេទជួរឈរ (`info`)

នេះជាជំហានដ៏សំខាន់បំផុត ដើម្បីដឹងថាទិន្នន័យមានកំហុសអក្ខរាវិរុទ្ធ (ឧ. លេខតែវាយជាអក្សរ) ឫអត់។

```python
df.info()
```

### ៣. សេចក្តីសង្ខេបស្ថិតិ (`describe`)

មុខងារនេះនឹងយកជួរឈរណាដែលជា **លេខ** មកគណនាស្ថិតិ (អប្បបរមា អតិបរមា មធ្យម) អោយអ្នកភ្លាមៗ!

```python
# គណនាស្ថិតិសង្ខេប
print(df.describe())
```
