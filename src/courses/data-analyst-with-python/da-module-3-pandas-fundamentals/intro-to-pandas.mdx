## 🌐 សេចក្តីផ្តើម (Overview)

ប្រសិនបើ **NumPy** គឺជាម៉ាស៊ីន (Engine) ដ៏ខ្លាំងក្លា នោះ **Pandas** គឺជាតួឡានដ៏ស្រស់ស្អាតដែលអនុញ្ញាតអោយអ្នកបញ្ជាម៉ាស៊ីននោះបានយ៉ាងងាយស្រួល។ នៅក្នុងការងារប្រចាំថ្ងៃ Data Analyst ចំណាយពេលជិត ៧០% ទៅលើការប្រើប្រាស់ Pandas។ វាប្រៀបបាននឹង "Microsoft Excel ជំនាន់ថ្មី" ដែលអាចផ្ទុកទិន្នន័យរាប់លានជួរដោយមិនគាំង!

---

## 💻 អ្វីទៅជា Pandas?

**Pandas** គឺជាបណ្ណាល័យដែលត្រូវបានបង្កើតឡើងដោយលោក Wes McKinney ក្នុងឆ្នាំ ២០០៨។ ឈ្មោះរបស់វាមិនមែនយកតាមសត្វខ្លាឃ្មុំផេនដា (Panda Bear) ទេ ប៉ុន្តែវាមកពីពាក្យ **Panel Data** ដែលជាពាក្យបច្ចេកទេសក្នុងវិស័យសេដ្ឋកិច្ច សំដៅលើទិន្នន័យដែលប្រមូលបានតាមពេលវេលា។

### លក្ខណៈពិសេសរបស់ Pandas
- អាចអានឯកសារបានច្រើនប្រភេទ (CSV, Excel, SQL Database, JSON)
- អាចសំអាតទិន្នន័យ កែតម្រូវចន្លោះប្រហោង (Missing values) បានយ៉ាងងាយ
- អាចច្រោះ (Filter), រៀបលំដាប់ (Sort), និងចងក្រង (Group By) ទិន្នន័យបានយ៉ាងលឿន
- មានមុខងារគូរក្រាហ្វិកភ្ជាប់មកជាមួយស្រាប់

### របៀបហៅវាមកប្រើ (Importing)

ដូចគ្នានឹង NumPy ដែរ យើងត្រូវហៅវាចូលមកសិនមុននឹងប្រើប្រាស់។ ឈ្មោះកាត់ជាសកលរបស់វាគឺ **`pd`**។

```python
# ហៅ Pandas មកប្រើ ហើយតាងវាថា pd
import pandas as pd

# យើងតែងតែហៅ NumPy មកជាមួយដែរ ព្រោះវាជាដៃគូនឹងគ្នា
import numpy as np

# ពិនិត្យមើល Version (ឧទាហរណ៍ 2.0.3)
print(pd.__version__)
```

រាល់ពេលដែលអ្នកបង្កើតឯកសារវិភាគទិន្នន័យថ្មី (Jupyter Notebook) សូមកុំភ្លេចសរសេរកូដទាំងពីរជួរនេះនៅក្រឡា (Cell) ខាងលើគេបង្អស់! នៅក្នុងមេរៀនបន្ទាប់ យើងនឹងស្គាល់ពីឆ្អឹងជំនីររបស់ Pandas គឺ **Series** និង **DataFrame**។
