## 🌐 សេចក្តីផ្តើម (Overview)

នៅពេលអ្នកធ្វើរបាយការណ៍ ថ្នាក់ដឹកនាំតែងតែចង់ឃើញ "Top 10 អ្នកលក់បានច្រើនជាងគេ" ឫ "អតិថិជន ៥ នាក់ដែលជំពាក់លុយយូរជាងគេ"។ ការរៀបលំដាប់ (Sorting) គឺជាវិធីដ៏ងាយបំផុតដើម្បីស្វែងរកទិន្នន័យកំពូលៗ (Top/Bottom) ទាំងនោះ។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

យើងនឹងបន្តប្រើប្រាស់មុខងារដ៏មានឥទ្ធិពលគឺ `.sort_values()`។

### ១. រៀបលំដាប់តាមជួរឈរតែមួយ

```python
import pandas as pd

# ឧបមាថា df មានជួរឈរ 'ឈ្មោះ', 'អាយុ', 'ប្រាក់ខែ'

# រៀបតាមប្រាក់ខែ ពីតូចទៅធំ (អក្សរ A ទៅ Z ឬ លេខ 1 ទៅ 10)
# អ្នកបានប្រាក់ខែតិច នៅលើគេ!
sorted_salary_asc = df.sort_values(by="ប្រាក់ខែ")
# ចំណាំ: ascending=True ត្រូវបានកំណត់រួចជាស្រេចដោយមិនបាច់សរសេរ

# រៀបតាមប្រាក់ខែ ពីធំមកតូច (អ្នកបានប្រាក់ខែច្រើន នៅលើគេ)
sorted_salary_desc = df.sort_values(by="ប្រាក់ខែ", ascending=False)

print(sorted_salary_desc.head(3)) # បង្ហាញ Top 3 អ្នកប្រាក់ខែខ្ពស់ជាងគេ!
```

### ២. រៀបលំដាប់តាមជួរឈរច្រើន (Multiple Columns)

ចុះបើមានបុគ្គលិក ២ នាក់មានប្រាក់ខែស្មើគ្នា? តើគួរអោយអ្នកណានៅលើ? យើងអាចប្រាប់ Pandas ថា៖ "រៀបតាមប្រាក់ខែមុន។ បើប្រាក់ខែស្មើគ្នា សូមរៀបតាមអាយុពីក្មេងទៅចាស់បន្តទៀត!"។

```python
# រៀបតាម ប្រាក់ខែ (ពីធំមកតូច) បន្ទាប់មករៀបតាម អាយុ (ពីតូចទៅធំ)
# យើងត្រូវផ្តល់ជា List អោយទៅប៉ារ៉ាម៉ែត្រទាំងពីរ
complex_sort = df.sort_values(
    by=["ប្រាក់ខែ", "អាយុ"], 
    ascending=[False, True]
)

print(complex_sort)
```

### ៣. រៀបលំដាប់តាមឈ្មោះជួរដេក (Sort Index)

ពេលខ្លះ បន្ទាប់ពីរៀបចុះរៀបឡើង លេខរៀង (Index) នៅខាងឆ្វេងរញ៉េរញ៉ៃអស់ (ឧទាហរណ៍ ចេញលេខរៀង 5, 2, 9, 1...)។ អ្នកអាចរៀបវាអោយត្រឡប់មកតាមលំដាប់ដើមវិញបាន។

```python
# រៀបលេខរៀង Index (0, 1, 2...) អោយត្រឹមត្រូវឡើងវិញ
original_order = complex_sort.sort_index()
```

ការប្រើប្រាស់ `.sort_values()` ផ្គួបជាមួយ `.head()` គឺជាក្បួន (Combo) ដ៏សាហាវបំផុតដើម្បីទាញយក Top 10 ចេញពីទិន្នន័យរាប់លានជួរ!
