## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការច្រោះដោយប្រើលក្ខខណ្ឌតែមួយ

ស្រដៀងទៅនឹងការធ្វើ Boolean Indexing ក្នុង NumPy ដែរ យើងប្រើប្រាស់ប្រអប់ `[]` ដើម្បីត្រងយកទិន្នន័យ។

```python
import pandas as pd

# ឧបមាថា df មានជួរឈរ 'ឈ្មោះ', 'អាយុ', 'ប្រាក់ខែ', 'ផ្នែក'

# រកមើលអ្នកដែលមានប្រាក់ខែលើសពី (ឫស្មើ) ៥០០ ដុល្លារ
high_salary = df[df["ប្រាក់ខែ"] >= 500]

# បង្ហាញលទ្ធផល (វានឹងចេញតារាងថ្មីដែលមានតែអ្នកប្រាក់ខែខ្ពស់)
print(high_salary)
```

### ២. ការច្រោះដោយប្រើលក្ខខណ្ឌច្រើន (AND / OR)

នៅពេលមានលក្ខខណ្ឌច្រើន សូមកុំភ្លេច៖
1. ប្រើសញ្ញា `&` (សឹងតែ) ឬ `|` (មួយណាក៏បាន)
2. រុំលក្ខខណ្ឌនីមួយៗក្នុងវង់ក្រចក `()`

```python
# រកបុគ្គលិកដែលធ្វើការផ្នែក IT "និង (&)" មានប្រាក់ខែលើសពី ៥០០
it_high_salary = df[(df["ផ្នែក"] == "IT") & (df["ប្រាក់ខែ"] > 500)]

# រកបុគ្គលិកដែលធ្វើការផ្នែក IT "ឬ (|)" ផ្នែក HR (អោយតែនៅមួយណា ក៏យកដែរ)
it_or_hr = df[(df["ផ្នែក"] == "IT") | (df["ផ្នែក"] == "HR")]
```

### ៣. ការប្រើប្រាស់ `.isin()` (វិធីសាស្ត្រខ្លី)

ប្រសិនបើអ្នកចង់រកមនុស្សដែលធ្វើការនៅផ្នែក IT ឫ HR ឫ Marketing កូដនៅខាងលើអាចនឹងវែងខ្លាំង (`|` ច្រើនដង)។ ប្រើ `.isin()` លឿនជាង!

```python
# បង្កើតបញ្ជីរាយនាមផ្នែកដែលយើងចង់បាន
target_departments = ["IT", "HR", "Marketing"]

# ច្រោះយកតែបុគ្គលិកណា ដែលផ្នែករបស់ពួកគេ ស្ថិតនៅក្នុង (isin) បញ្ជីខាងលើ
selected_staff = df[df["ផ្នែក"].isin(target_departments)]

print(selected_staff)
```

ជាមួយនឹងបច្ចេកទេស Filtering ទាំងនេះ អ្នកអាចឆ្លើយសំណួរស្ទើរតែទាំងអស់ដែលថៅកែសួរមកអ្នកបានយ៉ាងងាយស្រួល!
