## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងមេរៀនមុន យើងអាចគណនា "ចំណូលសរុបរបស់ក្រុមហ៊ុន" បាន។ ប៉ុន្តែនៅក្នុងកិច្ចប្រជុំ ថៅកែតែងតែសួរថា៖ *"តើសាខាភ្នំពេញ និងសាខាសៀមរាប មួយណាលក់ដាច់ជាង?"*។ ដើម្បីឆ្លើយសំណួរនេះ អ្នកមិនអាចបូកសរុបទាំងអស់ចូលគ្នាទេ អ្នកត្រូវ "ចងក្រងជាក្រុម (GroupBy)" តាមឈ្មោះសាខាសិន សឹមធ្វើការបូក!

## 💻 ការបំបែកកូដ (Code Breakdown)

ឧបមាថាយើងមាន DataFrame `df`:
| សាខា | ផលិតផល | ចំណូល |
| :--- | :--- | :--- |
| ភ្នំពេញ | កាហ្វេ | 50 |
| សៀមរាប | តែ | 30 |
| ភ្នំពេញ | តែ | 20 |
| សៀមរាប | កាហ្វេ | 40 |

### ១. GroupBy តាមជួរឈរតែមួយ

```python
import pandas as pd

# ១. តើសាខានីមួយៗរកចំណូលបានប៉ុន្មាន?
# ចងក្រងតាម "សាខា" ជ្រើសរើស "ចំណូល" រួចធ្វើការបូក "sum()"
branch_sales = df.groupby("សាខា")["ចំណូល"].sum()

print(branch_sales)
```
**លទ្ធផល:**
```text
សាខា
ភ្នំពេញ    70   (បានមកពី 50 + 20)
សៀមរាប    70   (បានមកពី 30 + 40)
Name: ចំណូល, dtype: int64
```

### ២. GroupBy រួចប្រើ `.agg()`

ចុះបើចង់ដឹងទាំង "ចំណូលសរុប" និង "ចំនួនវិក្កយបត្រ (count)" របស់សាខានីមួយៗ? យើងផ្សំវាជាមួយកូដមេរៀនមុន!

```python
branch_summary = df.groupby("សាខា")["ចំណូល"].agg(['sum', 'count'])
print(branch_summary)
```

### ៣. GroupBy តាមជួរឈរច្រើន (Multi-level)

តើសាខាភ្នំពេញលក់កាហ្វេបានប៉ុន្មាន? លក់តែបានប៉ុន្មាន? យើងត្រូវ Group តាមសាខាផង តាមផលិតផលផង!

```python
# ផ្តល់បញ្ជីរាយនាមជួរឈរដែលត្រូវ GroupBy ទៅក្នុងវង់ក្រចកជ្រុង []
detailed_sales = df.groupby(["សាខា", "ផលិតផល"])["ចំណូល"].sum()

print(detailed_sales)
```
**លទ្ធផល:**
```text
សាខា     ផលិតផល 
ភ្នំពេញ   កាហ្វេ    50
         តែ       20
សៀមរាប   កាហ្វេ    40
         តែ       30
Name: ចំណូល, dtype: int64
```

`groupby` គឺជា "បេះដូង" នៃការធ្វើរបាយការណ៍ (Reporting) នៅក្នុងការិយាល័យ! វគ្គបន្ទាប់យើងនឹងយកចំណេះដឹង Pandas ទាំងមូលមកធ្វើការនៅក្នុង Mini Project ជាក់ស្តែង!
