## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងមេរៀនមុនៗ (NumPy) យើងបានរៀនប្រើប្រាស់ `np.sum()` ឬ `np.mean()`។ ដំណឹងល្អគឺថា Pandas បានបញ្ចូលមុខងារទាំងនោះមកជាស្រេច! អ្នកអាចប្រើមុខងារទាំងនោះដោយផ្ទាល់នៅលើ Series ឫ DataFrame តែម្តង ដោយមិនបាច់ហៅ NumPy មកជួយទេ។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការគណនាលើជួរឈរតែមួយ (Series Aggregation)

```python
import pandas as pd

# ឧបមាថា df មានជួរឈរ 'ចំណូល' និង 'ចំណាយ'

# គណនាចំណូលសរុប (Sum)
total_revenue = df["ចំណូល"].sum()
print("ចំណូលសរុប:", total_revenue)

# គណនាចំណាយជាមធ្យម (Mean)
avg_expense = df["ចំណាយ"].mean()
print("ចំណាយមធ្យម:", avg_expense)

# រាប់ចំនួនវិក្កយបត្រ (Count)
num_invoices = df["ចំណូល"].count()
```

### ២. ការគណនាលើ DataFrame ទាំងមូល

ប្រសិនបើអ្នកមិនបញ្ជាក់ជួរឈរទេ Pandas នឹងព្យាយាមគណនាគ្រប់ជួរឈរណាដែលជា "លេខ" ទាំងអស់ដោយស្វ័យប្រវត្តិ!

```python
# វាអាចនឹងបូក cả ជួរឈរ 'អាយុ' ចូលគ្នាដែរ (ទោះបីជាវាគ្មានន័យក៏ដោយ)
totals = df.sum(numeric_only=True)
print(totals)
```
*ចំណាំ: `numeric_only=True` ការពារមិនអោយកុំព្យូទ័រព្យាយាមយកអក្សរទៅបូកបញ្ចូលគ្នា (ដែលនាំអោយមាន Error)។*

### ៣. ការគណនាច្រើនមុខក្នុងពេលតែមួយដោយប្រើ `.agg()`

មុខងារ `.agg()` គឺអស្ចារ្យណាស់ ប្រសិនបើថៅកែចង់ដឹងទាំង "ចំណូលសរុប" និង "ចំណូលមធ្យម" ក្នុងពេលតែមួយ។

```python
# ផ្តល់បញ្ជីឈ្មោះមុខងារដែលអ្នកចង់គណនា
revenue_summary = df["ចំណូល"].agg(['sum', 'mean', 'max', 'min'])

print(revenue_summary)
```
**លទ្ធផល:**
```text
sum     150000.0
mean      1500.0
max       5000.0
min         50.0
Name: ចំណូល, dtype: float64
```

ការសរុបទិន្នន័យ (Aggregation) តែមួយមុខគឺអស្ចារ្យហើយ ប៉ុន្តែបើយើងអាចសរុបវា "តាមខែ" ឫ "តាមសាខា" ទៀតនោះ ទើបជាកំពូលអ្នកវិភាគទិន្នន័យ! នោះគឺមុខងារ `GroupBy` នៅក្នុងមេរៀនបន្ទាប់។
