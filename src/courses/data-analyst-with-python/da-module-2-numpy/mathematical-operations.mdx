## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងការិយាល័យពិតប្រាកដ ប្រសិនបើអ្នកមានប្រាក់ខែគោលរបស់បុគ្គលិក ១ ម៉ឺននាក់ ហើយអ្នកចង់បូកប្រាក់ថែមម៉ោងអោយពួកគេម្នាក់ៗ ១០០ ដុល្លារ តើអ្នកត្រូវសរសេរ For Loop ១ម៉ឺនជុំមែនទេ? ជាមួយនឹង NumPy អ្នកគ្រាន់តែប្រើសញ្ញាបូក (+) ជាការស្រេច! នេះគេហៅថា **Vectorization**។

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ប្រមាណវិធីជាមួយនឹងលេខទោល (Scalar Operations)

```python
import numpy as np

salaries = np.array([500, 600, 700])

# បូកថែម ១០០ អោយគ្រប់គ្នា
new_salaries = salaries + 100
print("ប្រាក់ខែថ្មី:", new_salaries) # [600, 700, 800]

# គុណនឹង ២ អោយគ្រប់គ្នា (ឡើងប្រាក់ខែទ្វេដង!)
double_salaries = salaries * 2
print("ប្រាក់ខែទ្វេដង:", double_salaries) # [1000, 1200, 1400]
```

### ២. ប្រមាណវិធីរវាង Array និង Array (Element-wise)

ចុះបើប្រាក់ខែថែមម៉ោងរបស់ម្នាក់ៗមិនដូចគ្នា? យើងអាចយក Array ពីរមកបូកបញ្ចូលគ្នាបាន (លក្ខខណ្ឌ៖ ទំហំ Array ត្រូវតែស្មើគ្នា)។

```python
base_salary = np.array([500, 600, 700])
bonus = np.array([50, 0, 150]) # អ្នកទី២ អត់បាន Bonus ទេ

# បូកបញ្ចូលគ្នាអ្នកណារៀងខ្លួន (តាមទីតាំងរៀងៗខ្លួន)
total_salary = base_salary + bonus
print("ប្រាក់ខែសរុប:", total_salary) # [550, 600, 850]
```

### ៣. អនុគមន៍គណិតវិទ្យា (Math Functions)

NumPy ក៏ផ្តល់នូវអនុគមន៍ដែលប្រើលើ Array ទាំងមូលផងដែរ (ជំនួសអោយការប្រើបណ្ណាល័យ `math` ដែលធ្វើបានតែមួយគ្រាប់ៗ)។

```python
numbers = np.array([1, 4, 9, 16])

# គណនាឫសការ៉េសម្រាប់គ្រប់ធាតុទាំងអស់
roots = np.sqrt(numbers)
print("ឫសការ៉េ:", roots) # [1. 2. 3. 4.]

# ស្វ័យគុណ
print("ការ៉េ:", np.power(numbers, 2)) # [1, 16, 81, 256]
```
ដោយសារតែចំណុចនេះហើយ ទើប NumPy ជាវីរបុរសពិតប្រាកដក្នុងពិភព Data Science!
