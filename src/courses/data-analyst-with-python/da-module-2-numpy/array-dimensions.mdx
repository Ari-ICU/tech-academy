## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងពិភពទិន្នន័យ វាមិនមែនមានតែទម្រង់ជាជួរតែមួយ (1D) នោះទេ។ ទិន្នន័យពិតតែងតែមកជាទម្រង់តារាង Excel ដែលមានទាំងជួរដេក និងជួរឈរ (2D)។ ការយល់ដឹងពីវិមាត្រ (Dimensions) ជួយអោយអ្នកដឹងថាអ្នកកំពុងប្រឈមមុខនឹងតារាងទំហំប៉ុនណា។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការបង្កើត និងត្រួតពិនិត្យ 2D Array

យើងបង្កើត 2D Array ដោយការដាក់ List ត្រួតគ្នា (List ក្នុង List)។

```python
import numpy as np

# នេះជា 2D Array (ដូចតារាង Excel មួយ)
matrix = np.array([
    [10, 20, 30], # ជួរដេកទី 1
    [40, 50, 60]  # ជួរដេកទី 2
])

# ពិនិត្យមើលចំនួនវិមាត្រ (Number of Dimensions)
print("វិមាត្រ (ndim):", matrix.ndim) # ចេញ 2 (ព្រោះវាជា 2D)

# ពិនិត្យមើលរាង (Shape = ជួរដេក x ជួរឈរ)
print("រាង (shape):", matrix.shape) # ចេញ (2, 3) 
```

### ២. ការប្តូររូបរាង (Reshape)

ពេលខ្លះ អ្នកទាញទិន្នន័យចេញមកមានរាងជាខ្សែវែងមួយ (1D) តែអ្នកចង់ប្តូរវាអោយទៅជាតារាង (2D) ដើម្បីស្រួលមើល។

```python
# បង្កើតខ្សែទិន្នន័យ 1D ពីលេខ 1 ដល់ 6
line = np.array([1, 2, 3, 4, 5, 6])
print("ទម្រង់ដើម 1D:", line)

# បំប្លែងវាអោយទៅជាតារាងដែលមាន 2 ជួរដេក និង 3 ជួរឈរ
table = line.reshape(2, 3)
print("\nបន្ទាប់ពី Reshape ទៅជា 2D:\n", table)

# បំប្លែងវាអោយទៅជាតារាងដែលមាន 3 ជួរដេក និង 2 ជួរឈរវិញក៏បាន!
table_2 = line.reshape(3, 2)
print("\nបន្ទាប់ពី Reshape ទៅជា 3x2:\n", table_2)
```

**ច្បាប់មាស:** ការគុណជួរដេក និងជួរឈរ ត្រូវតែស្មើនឹងចំនួនធាតុសរុប។ (ឧទាហរណ៍៖ ធាតុមាន ៦ អ្នកអាច reshape ជា 2x3 ឫ 3x2 បាន ប៉ុន្តែមិនអាចធ្វើ 2x4 បានទេ វាខ្វះធាតុ!)
