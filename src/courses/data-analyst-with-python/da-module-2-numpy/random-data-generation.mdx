## 🌐 សេចក្តីផ្តើម (Overview)

ជួនកាល អ្នកចង់សាកល្បងគូរក្រាហ្វិក ឬធ្វើតេស្តកូដ ប៉ុន្តែអ្នកអត់មានទិន្នន័យពិតក្នុងដៃ។ កុំបារម្ភ! NumPy អាចជួយអ្នកបង្កើត "ទិន្នន័យក្លែងក្លាយ (Dummy Data)" រាប់លានជួរដោយចៃដន្យ ក្នុងរយៈពេលត្រឹមតែមួយប៉ប្រិចភ្នែក។

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. លេខចៃដន្យចន្លោះ 0 និង 1

```python
import numpy as np

# ចាក់សោរភាពចៃដន្យ (អ្នកណាយកកូដនេះទៅ Run ក៏ចេញលេខដូចគ្នាដែរ)
np.random.seed(0)

# បង្កើតលេខទសភាគចៃដន្យ ចំនួន 3 គ្រាប់ (ចន្លោះ 0 ដល់ 1)
random_floats = np.random.rand(3)
print("លេខទសភាគចៃដន្យ:", random_floats)
```

### ២. លេខគត់ចៃដន្យ (Random Integers)

```python
# បង្កើតពិន្ទុសិស្ស (លេខគត់ពី 0 ដល់ 100) ចំនួន 10 នាក់
# ក្បួន: randint(low, high, size)
student_scores = np.random.randint(0, 101, size=10)
print("ពិន្ទុសិស្ស (ចៃដន្យ):", student_scores)
```

### ៣. លេខចៃដន្យតាមធម្មជាតិ (Normal Distribution)

ក្នុងធម្មជាតិ កម្ពស់មនុស្ស ឬពិន្ទុប្រឡង ច្រើនតែប្រមូលផ្តុំនៅកណ្តាល (មធ្យម)។ នេះហៅថា របាយកណ្តឹង (Normal Distribution)។ យើងអាចប្រាប់ NumPy អោយបង្កើតទិន្នន័យដោយធ្វើត្រាប់តាមធម្មជាតិ!

```python
# បង្កើតកម្ពស់មនុស្សចំនួន 5 នាក់
# ដោយដឹងថាមនុស្សទូទៅមានកម្ពស់មធ្យម 170cm និងលម្អៀង 5cm (Std)
mean_height = 170
std_dev = 5

heights = np.random.normal(loc=mean_height, scale=std_dev, size=5)
print("កម្ពស់មនុស្សប្រហាក់ប្រហែលធម្មជាតិ:\n", np.round(heights, 2))
```
