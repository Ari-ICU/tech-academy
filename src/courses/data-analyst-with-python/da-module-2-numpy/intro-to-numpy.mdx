## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងការវិភាគទិន្នន័យ យើងតែងតែធ្វើការជាមួយលេខរាប់លាន។ Python List ធម្មតាមិនមានល្បឿនលឿនគ្រប់គ្រាន់សម្រាប់កិច្ចការនេះទេ។ ដូច្នេះហើយទើបគេបង្កើត **NumPy (Numerical Python)** ឡើង។ គ្រប់ Library ល្បីៗទាំងអស់ (Pandas, Scikit-learn, TensorFlow) សុទ្ធតែប្រើប្រាស់ NumPy ជាគ្រឹះ។

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការបង្កើត NumPy Array (1D ឫ 2D)

```python
import numpy as np

# 1D Array (ដូចបញ្ជីធម្មតា)
prices = np.array([10, 20, 30, 40])
print(prices)

# 2D Array (ដូចតារាង Matrix)
matrix = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
print(matrix)
```

### ២. ការគណនាគណិតវិទ្យាដ៏មានអានុភាព (Broadcasting)

ជាមួយ NumPy អ្នកមិនបាច់ប្រើ `for loop` ដើម្បីគណនាទិន្នន័យច្រើននោះទេ។
```python
# ដកពន្ធ 10% ពីតម្លៃទាំងអស់ក្នុងពេលតែមួយ
net_prices = prices * 0.9
print(net_prices)
```

### ៣. មុខងារស្ថិតិ (Statistical Functions)

```python
ages = np.array([25, 30, 22, 28, 35])

print("មធ្យមភាគ:", np.mean(ages))
print("មេដ្យាន:", np.median(ages))
print("គម្លាតស្តង់ដារ (Standard Deviation):", np.std(ages))
print("តម្លៃខ្ពស់បំផុត:", np.max(ages))
```
រាល់ការគណនាជាមួយ NumPy គឺលឿនរន្ទះ!
