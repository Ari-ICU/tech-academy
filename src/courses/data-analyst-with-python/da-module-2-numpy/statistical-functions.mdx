## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ស្ថិតិសម្រាប់ទិន្នន័យ 1D (ទូទៅ)

```python
import numpy as np

# កត់ត្រាការលក់ ៥ ថ្ងៃ
sales = np.array([200, 150, 300, 150, 400])

print("ការលក់សរុប (Sum):", np.sum(sales))       # 1200
print("ការលក់ជាមធ្យម (Mean):", np.mean(sales)) # 240.0
print("តម្លៃកណ្តាល (Median):", np.median(sales))# 200.0 (តម្រៀបហើយយកកណ្តាលគេ)
print("ការលក់ខ្ពស់បំផុត (Max):", np.max(sales))   # 400
print("ការលក់ទាបបំផុត (Min):", np.min(sales))    # 150
```

### ២. ស្ថិតិសម្រាប់តារាង (2D Array) ជាមួយ Axis

ចុះបើមាន ហាង ៣ ហើយលក់បាន ៣ ថ្ងៃ (តារាង 3x3)? យើងចង់រកការលក់សរុបរបស់ "ហាងនីមួយៗ" និង "ថ្ងៃនីមួយៗ"!

```python
# ជួរដេក = ហាង ក, ខ, គ | ជួរឈរ = ថ្ងៃទី 1, 2, 3
matrix = np.array([
    [100, 150, 200], # ហាង ក
    [120, 160, 210], # ហាង ខ
    [90,  140, 190]  # ហាង គ
])

# បូកទាំងអស់ចូលគ្នា (ប្រាក់ចូលក្រុមហ៊ុន)
print("ចំណូលក្រុមហ៊ុនសរុប:", np.sum(matrix)) # 1360

# បូកសរុបតាម "ជួរឈរ / Column" (រកចំណូលតាមថ្ងៃនីមួយៗ) -> ប្រើ axis=0
# វានឹងយក 100+120+90, 150+160+140...
daily_sales = np.sum(matrix, axis=0)
print("ចំណូលតាមថ្ងៃ (ថ្ងៃ ១, ២, ៣):", daily_sales) 

# បូកសរុបតាម "ជួរដេក / Row" (រកចំណូលរបស់ហាងនីមួយៗ) -> ប្រើ axis=1
store_sales = np.sum(matrix, axis=1)
print("ចំណូលតាមហាង (ក, ខ, គ):", store_sales) 
```

**ចំណាំងាយៗ:** 
- `axis=0` = ចង់គណនាមើលពីលើចុះក្រោម (Column-wise)
- `axis=1` = ចង់គណនាមើលពីឆ្វេងទៅស្តាំ (Row-wise)
