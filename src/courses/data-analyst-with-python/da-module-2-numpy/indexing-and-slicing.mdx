## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការកាត់ 1D Array (ដូច Python List ធម្មតា)

លេខរៀង (Index) ចាប់ផ្តើមពី $0$។

```python
import numpy as np

arr = np.array([10, 20, 30, 40, 50])

print("យកធាតុដំបូង:", arr[0])      # 10
print("យកធាតុចុងក្រោយ:", arr[-1])  # 50
print("កាត់យកពីទីតាំងទី 1 ដល់ 3 (មិនរួមទី 4 ទេ):", arr[1:4]) # [20 30 40]
```

### ២. ការកាត់ 2D Array (កាត់តារាង)

នេះជាចំណុចដែល NumPy បង្ហាញភាពអស្ចារ្យ។ រូបមន្តគឺ `[ជួរដេក, ជួរឈរ]`។

```python
# តារាង 3x3
matrix = np.array([
    [1, 2, 3],   # ជួរដេកទី 0
    [4, 5, 6],   # ជួរដេកទី 1
    [7, 8, 9]    # ជួរដេកទី 2
])

# យកលេខ 6 (ជួរដេកទី 1, ជួរឈរទី 2)
print("យកលេខ 6:", matrix[1, 2])

# កាត់យកតែ ជួរដេកទី 0 (ជួរទីមួយទាំងមូល)
print("ជួរដេកទី 0:", matrix[0, :]) # សញ្ញា : មានន័យថាយកទាំងអស់

# កាត់យកតែ ជួរឈរទី 1 (កណ្តាលបញ្ឈរ)
print("ជួរឈរទី 1:", matrix[:, 1]) 

# កាត់យកតំបន់តូចមួយ (Sub-matrix: ជួរដេក 0-1, ជួរឈរ 1-2)
sub = matrix[0:2, 1:3]
print("ម៉ាទ្រីសតូច:\n", sub)
```

### ៣. ការជ្រើសរើសតាមលក្ខខណ្ឌ (Boolean Indexing)

តើចង់បានតែអ្នកណាដែលប្រឡងជាប់ (ពិន្ទុ >= 50)? មិនបាច់ប្រើ IF ទេ!

```python
scores = np.array([45, 85, 30, 92, 55])

# NumPy នឹងបញ្ចេញកូដ [False, True, False, True, True]
passed = scores >= 50

# យកពិន្ទុណាដែល True មកបង្ហាញ
print("ពិន្ទុអ្នកប្រឡងជាប់:", scores[passed]) 
# ឬសរសេរកាត់: scores[scores >= 50]
```
របៀបសរសេរកាត់បែបនេះ (Boolean Masking) នឹងជួយសន្សំពេលវេលាអ្នកបានច្រើនណាស់ក្នុងការសំអាតទិន្នន័យ (Data Cleaning) នាពេលខាងមុខ!
