## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងមេរៀនមុន យើងបានរៀនថាដើម្បីបូក Array ពីរបញ្ចូលគ្នា វាត្រូវតែមានទំហំស្មើគ្នា។ ចុះបើវាមិនស្មើគ្នាវិញ? ឧទាហរណ៍ អ្នកមានតារាងប្រាក់ខែបុគ្គលិក (2D) ហើយអ្នកចង់បូកលុយ Bonus អោយពួកគេ (1D)? NumPy នឹងព្យាយាមពង្រីកទិន្នន័យតូចអោយប៉ុនទិន្នន័យធំដោយស្វ័យប្រវត្តិ។ ក្បួននេះហៅថា **Broadcasting**។

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. Broadcasting ជាមួយលេខទោល (Scalar)
យើងធ្លាប់បានជួបវាម្តងរួចមកហើយ នៅពេលយើងយក Array ទៅគុណនឹង 2។ លេខ 2 (តូច) ត្រូវបានពង្រីកទៅគុណគ្រប់លេខទាំងអស់ក្នុង Array (ធំ)។ នេះគឺជា Broadcasting សាមញ្ញបំផុត។

### ២. Broadcasting រវាង 1D Array និង 2D Array

ឧបមាថាយើងមានតារាង (2D Matrix) ដែលកត់ត្រាការលក់របស់ ហាង ៣ (ជួរដេក) ក្នុងរយៈពេល ៣ ថ្ងៃ (ជួរឈរ)។ ឥឡូវនេះយើងដឹងថាមានកំហុសប្រព័ន្ធ ដែលធ្វើអោយបាត់ទិន្នន័យការលក់របស់ថ្ងៃនីមួយៗ (1D Vector)។ យើងចង់បូកវាបញ្ចូលគ្នា!

```python
import numpy as np

# តារាងការលក់ (3 ហាង x 3 ថ្ងៃ) -> 2D
sales = np.array([
    [100, 150, 200], # ហាងក
    [120, 160, 210], # ហាងខ
    [90,  140, 190]  # ហាងគ
])

# លុយបាត់ប្រចាំថ្ងៃ (ថ្ងៃទី១ បាត់ 10$, ទី២ បាត់ 20$, ទី៣ បាត់ 30$) -> 1D
missing_sales = np.array([10, 20, 30])

# តើ NumPy អាចបូក 2D និង 1D បានទេ?
correct_sales = sales + missing_sales

print("តារាងការលក់ដែលបានកែតម្រូវ:\n", correct_sales)
```

**តើមានអ្វីកើតឡើងនៅពីក្រោយខ្នង?**
NumPy បានយក `[10, 20, 30]` ទៅថតចម្លងធ្វើជា ៣ ជួរ (Stretch) ដើម្បីអោយមានទំហំប៉ុនតារាងការលក់ (3x3) រួចទើបបូកបញ្ចូលគ្នា! 
- វាបូកលេខ 10 ទៅកាន់ថ្ងៃទី 1 គ្រប់ហាង!
- វាបូកលេខ 20 ទៅកាន់ថ្ងៃទី 2 គ្រប់ហាង!
- វាបូកលេខ 30 ទៅកាន់ថ្ងៃទី 3 គ្រប់ហាង!

Broadcasting ជួយសន្សំសំចៃការសរសេរកូដ និង Memory យ៉ាងខ្លាំង!
