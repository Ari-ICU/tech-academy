## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុង Module 6 យើងសង្កេតឃើញថា ដើម្បីគូរក្រាហ្វិកមួយអោយស្អាត (មានពណ៌ មាន Grid) អ្នកត្រូវសរសេរកូដច្រើនបន្ទាត់ណាស់ជាមួយ Matplotlib។ នេះហើយជាពេលដែល **Seaborn** ចូលមកជួយសង្គ្រោះ!

Seaborn ត្រូវបានរចនាឡើងយ៉ាងពិសេស ដើម្បីធ្វើការជាមួយ **Pandas DataFrames**។ វាយល់ពីឈ្មោះជួរឈរ (Columns) និងប្រភេទលក្ខខណ្ឌ ដោយស្វ័យប្រវត្តិ។

---

## 💻 ការហៅមកប្រើប្រាស់ (Importing)

ដោយសារ Seaborn ជា "កូន" របស់ Matplotlib យើងតែងតែ Import ពួកវាទាំងពីរមកជាមួយគ្នាជានិច្ច ព្រោះជួនកាលយើងនៅតែត្រូវការ Matplotlib ដើម្បីប្តូរចំណងជើង (Title) ឫទំហំក្រាហ្វិក។

```python
import pandas as pd
import matplotlib.pyplot as plt

# ហៅបណ្ណាល័យ Seaborn ហើយតាងឈ្មោះកាត់ថា sns (យកតាមឈ្មោះ Samuel Norman Seaborn)
import seaborn as sns

# កំណត់ Theme របស់ Seaborn អោយដើរដោយស្វ័យប្រវត្តិលើក្រាហ្វិកទាំងអស់!
sns.set_theme() 
```

គ្រាន់តែអ្នក Run កូដ `sns.set_theme()` នោះសូម្បីតែកូដ Matplotlib ចាស់ៗរបស់អ្នក ក៏នឹងប្រែក្លាយទៅជាមានសោភ័ណភាពស្រស់ស្អាត (មានផ្ទៃខាងក្រោយពណ៌ប្រផេះខ្ចី មានបន្ទាត់ Grid ស) ភ្លាមៗតែម្តង!

នៅក្នុងមេរៀនបន្ទាប់ យើងនឹងចាប់ផ្តើមគូរក្រាហ្វិកស្ថិតិដែលពិបាកគូរក្នុង Matplotlib ប៉ុន្តែងាយស្រួលដូចបកចេកនៅក្នុង Seaborn!
