## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុង Matplotlib ប្រសិនបើអ្នកចង់គូរ Bar Chart ដែលមានសសរពីរឈរក្បែរគ្នា (ប្រៀបធៀបប្រុស និងស្រី) អ្នកត្រូវសរសេរកូដគណនាទីតាំងយ៉ាងស្មុគស្មាញ។ ចំណែកឯ Seaborn វិញ អ្នកគ្រាន់តែប្រាប់វាថា `hue='ភេទ'` ទៅគឺចប់បាត់ទៅហើយ!

---

## 💻 ការបំបែកកូដ (Code Breakdown)

ឧបមាថាយើងមាន DataFrame `df` ផ្ទុកទិន្នន័យអតិថិជន មានជួរឈរ 'ថ្ងៃ', 'ចំណាយ', និង 'ភេទ'។

```python
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

# ទិន្នន័យសាកល្បង
df = pd.DataFrame({
    'ថ្ងៃ': ['ច័ន្ទ', 'ច័ន្ទ', 'អង្គារ', 'អង្គារ', 'ពុធ', 'ពុធ'],
    'ចំណាយ': [10, 20, 15, 25, 30, 10],
    'ភេទ': ['ប្រុស', 'ស្រី', 'ប្រុស', 'ស្រី', 'ប្រុស', 'ស្រី']
})

sns.set_theme()
```

### ១. ក្រាហ្វិកសសរឆ្លាតវៃ (Bar Plot ជាមួយ Hue)

Seaborn នឹងធ្វើការ **បូកសរុបមធ្យមភាគ (Mean)** អោយយើងដោយស្វ័យប្រវត្តិ នៅពេលគូរ Barplot (វាធ្វើការងារ GroupBy អោយយើងស្រេច)!

```python
# ប្រាប់វាពីទីតាំង x, ទីតាំង y, និងទិន្នន័យទាំងមូល (data=df)
# hue='ភេទ' នឹងបំបែកសសរជា២ពណ៌ (ប្រុស vs ស្រី) សម្រាប់ថ្ងៃនីមួយៗ!
sns.barplot(data=df, x='ថ្ងៃ', y='ចំណាយ', hue='ភេទ')

plt.title("ការចំណាយមធ្យមប្រចាំថ្ងៃ (បែងចែកតាមភេទ)")
plt.show()
```

### ២. ក្រាហ្វិករាប់ចំនួន (Count Plot)

វាស្រដៀងនឹង Bar Chart ដែរ ប៉ុន្តែវាធ្វើការដូច `value_counts()`។ វារាប់ថាមានមនុស្សប៉ុន្មាននាក់ទិញនៅថ្ងៃច័ន្ទ!

```python
# មិនបាច់ប្រាប់អ័ក្ស y ទេ ព្រោះ Count Plot ចេះរាប់ចំនួនដោយខ្លួនឯង!
sns.countplot(data=df, x='ថ្ងៃ', hue='ភេទ')

plt.title("ចំនួនអតិថិជនមកទិញប្រចាំថ្ងៃ")
plt.show()
```

### ៣. ក្រាហ្វិកប្រអប់ (Box Plot) សម្រាប់រក Outlier

ជាមធ្យោបាយដ៏ល្អបំផុតដើម្បីរកមើលទិន្នន័យខុសប្រក្រតី (Outlier) ដែលយើងបានរៀនក្នុង Module 5។ ប្រសិនបើមានចំណុចខ្មៅ (Dots) លោតចេញនៅខាងក្រៅប្រអប់ នោះមានន័យថាជា Outlier ហើយ!

```python
# គូរ Box Plot មើលរបាយនៃការចំណាយ
sns.boxplot(data=df, y='ចំណាយ', color='skyblue')

plt.title("ការស្វែងរក Outlier នៃការចំណាយ")
plt.show()
```

Seaborn មិនត្រឹមតែសន្សំពេលវេលាទេ តែថែមទាំងធ្វើអោយការវិភាគទិន្នន័យរបស់អ្នក កាន់តែមានភាពស៊ីជម្រៅដោយសារតែប៉ារ៉ាម៉ែត្រ `hue` ដ៏អស្ចារ្យនេះ។
