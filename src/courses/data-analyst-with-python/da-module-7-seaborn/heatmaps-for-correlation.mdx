## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុង Module 5 យើងបានប្រើ `df.corr()` ដើម្បីចេញជាតារាង Correlation។ ប៉ុន្តែបើតារាងនោះមាន ២០ ជួរឈរ អ្នកនឹងត្រូវអានលេខចំនួន ៤០០ ក្រឡា! ភ្នែកយើងមិនអាចស្វែងរកទិន្នន័យសំខាន់ៗបានលឿនទេ បើមើលតែលេខសុទ្ធ។ 

**Heatmap (ក្រាហ្វិកកម្តៅ)** នឹងប្តូរលេខទាំងនោះទៅជា "ពណ៌"។ លេខកាន់តែធំ (ខិតជិត ១) ពណ៌កាន់តែដិត!

## 💻 ការបំបែកកូដ (Code Breakdown)

ឧបមាថាយើងកំពុងវិភាគទិន្នន័យផ្ទះលក់ (House Pricing)។

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# ទិន្នន័យផ្ទះ
data = {
    'ទំហំ (ម៉ែត្រការ៉េ)': [50, 100, 150, 200, 250],
    'ចំនួនបន្ទប់': [1, 2, 3, 4, 5],
    'អាយុកាលផ្ទះ': [10, 5, 20, 2, 15],
    'តម្លៃ ($)': [50000, 90000, 140000, 190000, 240000]
}
df = pd.DataFrame(data)

# ជំហានទី១៖ គណនា Correlation Matrix ជាមុនសិន
corr_matrix = df.corr()

# ជំហានទី២៖ គូរ Heatmap
plt.figure(figsize=(8, 6))

# កំណត់ cmap='coolwarm' ដើម្បីអោយពណ៌ ខៀវ (Negative) ស (Neutral) ក្រហម (Positive)
# annot=True ដើម្បីបង្ហាញតួលេខ
sns.heatmap(corr_matrix, annot=True, cmap='coolwarm', fmt=".2f", linewidths=0.5)

plt.title("Correlation Heatmap នៃទិន្នន័យផ្ទះ", fontsize=14)
plt.show()
```

### ការបកស្រាយ (Reading the Heatmap)

ពេលអ្នកមើល Heatmap នេះ អ្នកនឹងឃើញពណ៌ក្រហមឆ្អៅចំកណ្តាលរវាង `ទំហំ` និង `តម្លៃ` (លេខ 1.00) ដែលមានន័យថាវាមានទំនាក់ទំនងគ្នាខ្លាំងបំផុត (ផ្ទះធំ តម្លៃថ្លៃ)។ 

ចំណែកឯ `អាយុកាលផ្ទះ` និង `តម្លៃ` អាចនឹងមានពណ៌ខៀវ ឫ ស (ប្រហែល -0.1) មានន័យថា អាយុផ្ទះកាន់តែចាស់ មិនប្រាកដថាផ្ទះនោះថោក ឫ ថ្លៃនោះទេ។ 

ត្រឹមតែមួយភ្លែត Heatmap ជួយ Data Analyst អោយដឹងថា គួរយកជួរឈរណាខ្លះមកធ្វើការវិភាគបន្ត!
