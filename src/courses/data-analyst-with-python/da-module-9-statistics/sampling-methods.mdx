## 🌐 សេចក្តីផ្តើម (Overview)

នៅពេលអ្នកភ្លក់សម្លរ អ្នកមិនចាំបាច់ផឹកសម្លរនោះអស់មួយឆ្នាំង ដើម្បីដឹងថាវាប្រៃឫសាបនោះទេ! អ្នកគ្រាន់តែដួសមួយស្លាបព្រា (Sample) មកភ្លក់ទៅគឺដឹងហើយ ព្រោះមួយស្លាបព្រានោះវា "តំណាង (Represent)" អោយសម្លរទាំងមូល (Population)។

## 💻 ការអនុវត្តន៍ជាមួយកូដ (Code Breakdown)

### ១. Simple Random Sampling (យកសំណាកចៃដន្យសាមញ្ញ)

នេះជាវិធីដែលនិយមបំផុត គឺយកដោយចៃដន្យ (ប្រៀបដូចជាចាប់ឆ្នោតអញ្ចឹង) ធានាថាគ្រប់គ្នាមានឱកាសត្រូវបានជ្រើសរើសស្មើៗគ្នា។

```python
import pandas as pd
import numpy as np

# ឧបមាថាយើងមាន Database អតិថិជន ១០ ម៉ឺននាក់
# (នៅទីនេះយើងបង្កើតទិន្នន័យក្លែងក្លាយ ១ ម៉ឺនជួរ)
df_population = pd.DataFrame({
    'customer_id': range(1, 10001),
    'age': np.random.randint(18, 60, size=10000)
})

print("អតិថិជនសរុប (Population):", len(df_population))

# យក Sample ១០០ នាក់ដោយចៃដន្យ ប្រើ .sample() របស់ Pandas
# random_state ជួយអោយរាល់ពេល Run កូដ ចាប់បានមនុស្ស ១០០ នាក់ដដែល
df_sample = df_population.sample(n=100, random_state=42)

print("អតិថិជនដែលត្រូវបានជ្រើសរើស (Sample):", len(df_sample))
```

### ២. ហេតុអ្វីត្រូវយក Sample? (Central Limit Theorem)

ទ្រឹស្តីដ៏អស្ចារ្យបំផុតក្នុងស្ថិតិមានឈ្មោះថា "ទ្រឹស្តីបទលីមីតកណ្តាល (CLT)"។ វាចែងថា ទោះបីជាទិន្នន័យដើម (Population) មានរាងមិនមែនជាកណ្តឹង (Skewed) ក៏ដោយ ប្រសិនបើអ្នកចាប់យក Sample មកច្រើនដង ហើយគណនាមធ្យមភាគរបស់វានោះ លទ្ធផលនឹងក្លាយជា **Normal Distribution (រាងកណ្តឹង)** ជានិច្ច!

```python
# ១. គណនាមធ្យមភាគអាយុរបស់មនុស្សទាំង ១ ម៉ឺននាក់ (តម្លៃពិតប្រាកដ)
true_mean = df_population['age'].mean()
print("អាយុមធ្យមពិតប្រាកដ (Population Mean):", true_mean)

# ២. គណនាមធ្យមភាគអាយុរបស់មនុស្ស ១០០ នាក់ (តម្លៃប៉ាន់ស្មាន)
sample_mean = df_sample['age'].mean()
print("អាយុមធ្យមនៃសំណាក (Sample Mean):", sample_mean)
```
**លទ្ធផល:** អ្នកនឹងឃើញថា `sample_mean` គឺប្រហាក់ប្រហែលនឹង `true_mean` មែនទែន! (ឧ. ៣៨.៥ ធៀបនឹង ៣៨.៧)។ នេះបញ្ជាក់ថាអ្នកមិនចាំបាច់ខាតពេលវិភាគទិន្នន័យទាំង ១ ម៉ឺនជួរទេ ត្រឹម ១០០ ជួរក៏អ្នកអាចឆ្លើយប្រាប់ថៅកែបានយ៉ាងជឿជាក់ដែរ។ 

ប៉ុន្តែតើយើងអាចជឿជាក់បានប៉ុន្មានភាគរយទៅ? ចម្លើយគឺស្ថិតនៅក្នុងមេរៀនបន្ទាប់៖ **Confidence Interval**!
