## 🌐 សេចក្តីផ្តើម (Overview)

ក្នុងនាមជា Data Analyst អ្នកមិនត្រឹមតែរាយការណ៍ពីអ្វីដែលបានកើតឡើងពីម្សិលមិញទេ តែថៅកែចង់អោយអ្នក "ទស្សន៍ទាយ (Predict)" ថា តើថ្ងៃស្អែកអតិថិជនម្នាក់នេះមានភាគរយប៉ុន្មានដែលនឹងទិញទំនិញយើង? នេះហើយជា **ប្រូបាប៊ីលីតេ (Probability)**។

## 💻 រូបមន្តនិងការគណនា (Code Breakdown)

ប្រូបាប៊ីលីតេ (P) តែងតែមានតម្លៃចន្លោះពី **០ (មិនអាចកើតឡើងដាច់ខាត)** ដល់ **១ (កើតឡើង ១០០%)**។

```
P(ព្រឹត្តិការណ៍) = ចំនួនលទ្ធផលដែលយើងចង់បាន / ចំនួនលទ្ធផលដែលអាចកើតមានទាំងអស់
```
ឧទាហរណ៍៖ ទិញឆ្នោត ១ សន្លឹក ក្នុងចំណោម ១០០០ សន្លឹក។ P(ឈ្នះ) = 1/1000 = 0.001 (0.1%)។

### ការអនុវត្តជាមួយ Pandas (Empirical Probability)

ជាជាងការគណនាតាមរូបមន្តគណិតវិទ្យា Data Analyst គណនាប្រូបាប៊ីលីតេដោយផ្អែកលើ "ទិន្នន័យក្នុងអតីតកាល"។

ឧបមាថាយើងមានកំណត់ត្រាអតិថិជន ១០០០ នាក់។ 

```python
import pandas as pd

# បង្កើតទិន្នន័យសាកល្បង
df = pd.DataFrame({
    'ភេទ': ['ប្រុស', 'ស្រី', 'ស្រី', 'ប្រុស', 'ស្រី', 'ប្រុស', 'ស្រី', 'ស្រី', 'ប្រុស', 'ស្រី'],
    'ទិញទំនិញ': ['Yes', 'Yes', 'No', 'No', 'Yes', 'No', 'Yes', 'Yes', 'No', 'No']
})

# សំណួរទី១៖ តើប្រូបាប៊ីលីតេដែលអតិថិជនម្នាក់ដើរចូលហាង ហើយជា "មនុស្សស្រី" មានប៉ុន្មានភាគរយ?
# រាប់ចំនួនស្រី / ចំនួនមនុស្សសរុប
total_female = len(df[df['ភេទ'] == 'ស្រី'])
total_people = len(df)
p_female = total_female / total_people
print(f"P(Female) = {p_female * 100}%") # 60%

# សំណួរទី២ (Conditional Probability)៖ ប្រសិនបើដឹងថាគាត់ជា "មនុស្សស្រី" 
# តើប្រូបាបដែលគាត់នឹង "ទិញទំនិញ" មានប៉ុន្មានភាគរយ?
female_buyers = len(df[(df['ភេទ'] == 'ស្រី') & (df['ទិញទំនិញ'] == 'Yes')])
p_buy_given_female = female_buyers / total_female
print(f"P(Buy | Female) = {p_buy_given_female * 100}%") 
# ចម្លើយគឺ 66.67% (4 នាក់ក្នុងចំណោមស្រី 6 នាក់)
```

**Insights សម្រាប់អាជីវកម្ម:**
ដោយសារប្រូបាបដែល "មនុស្សស្រីទិញទំនិញ" មានរហូតដល់ 66.67% (ខណៈប្រុសមានត្រឹម 25%) នោះអ្នកគួរប្រាប់ក្រុម Marketing អោយចំណាយលុយផ្សាយពាណិជ្ជកម្ម តម្រង់គោលដៅទៅលើ "មនុស្សស្រី" ជាចម្បង ទើបចំណេញ!

ការយល់ពីប្រូបាប៊ីលីតេ គឺជាគ្រឹះដើម្បីយល់ពី **របាយទិន្នន័យ (Data Distribution)** នៅក្នុងមេរៀនបន្ទាប់។
