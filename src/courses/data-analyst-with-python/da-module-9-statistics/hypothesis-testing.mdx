## 🌐 សេចក្តីផ្តើម (Overview)

ឧបមាថាអ្នកទើបតែចេញយុទ្ធនាការ Marketing ថ្មី ហើយឃើញថាការលក់ខែនេះកើនឡើង ៥%។ តើអ្នកហ៊ានប្រាប់ថៅកែទេថា វាកើនឡើងដោយសារតែយុទ្ធនាការរបស់អ្នក? ចុះបើវាកើនឡើងដោយចៃដន្យ (ជួនកាលខែនេះអតិថិជនសំបូរលុយចាយ)?

អ្នកមិនអាចប្រើអារម្មណ៍មកកាត់ក្តីបានទេ អ្នកត្រូវប្រើ **Hypothesis Testing (ការធ្វើតេស្តសម្មតិកម្ម)**!

## 💻 គំនិតសំខាន់ៗទាំង ៣

មុននឹងសរសេរកូដ យើងត្រូវយល់ពាក្យបច្ចេកទេសទាំង ៣ នេះសិន។

### ១. Null Hypothesis (H0 - សម្មតិកម្មសូន្យ)
វាគឺជា "គំនិតចាស់/ស្ថានភាពដើម" ដែលតែងតែនិយាយថា **"គ្មានការប្រែប្រួលទេ"** ឬ **"អ្វីៗកើតឡើងដោយចៃដន្យ"**។
- H0: Marketing ថ្មីនេះ **មិនមានឥទ្ធិពល** ធ្វើអោយការលក់កើនទេ (កើនដោយចៃដន្យ)។

### ២. Alternative Hypothesis (H1 - សម្មតិកម្មផ្ទុយ)
វាគឺជាអ្វីដែលយើង (ក្នុងនាមជាអ្នកវិភាគ) ចង់បញ្ជាក់ថាវាពិត!
- H1: Marketing ថ្មីនេះ **ពិតជាមានឥទ្ធិពល** ធ្វើអោយការលក់កើនឡើងប្រាកដមែន!

### ៣. P-Value (ប្រូបាប៊ីលីតេនៃកំហុស)
P-Value ឆ្លើយសំណួរថា៖ *"ប្រសិនបើ H0 ជាការពិត (គឺគ្មានអ្វីប្រែប្រួលទេ) តើមានឱកាសប៉ុន្មានភាគរយ ដែលយើងទទួលបានទិន្នន័យ (កើនការលក់ ៥%) នេះ?"*
- **ច្បាប់មាស (Alpha = 0.05):** ប្រសិនបើ P-Value ចេញមកតូចជាង 0.05 (តិចជាង ៥%) នោះមានន័យថា អ្វីដែលយើងឃើញគឺពិបាកនឹងកើតឡើងដោយចៃដន្យណាស់។ ដូច្នេះយើង **ទាត់ចោល H0 (Reject H0)** ហើយទទួលស្គាល់ H1 ថាជាការពិត!

## 📊 ឧទាហរណ៍ជាក់ស្តែង (T-Test)

យើងនឹងប្រើ `T-Test` ដើម្បីប្រៀបធៀបមធ្យមភាគនៃក្រុមពីរ (ក្រុមចាស់ vs ក្រុមថ្មី)។

```python
import scipy.stats as stats
import numpy as np

# ទិន្នន័យការលក់ (១០ថ្ងៃ) មុនពេលមាន Marketing ថ្មី
sales_before = np.array([200, 210, 190, 205, 195, 200, 202, 198, 200, 190]) 
# ទិន្នន័យការលក់ (១០ថ្ងៃ) ក្រោយពេលមាន Marketing ថ្មី
sales_after = np.array([220, 230, 215, 225, 220, 240, 235, 220, 230, 225])

# ធ្វើការប្រៀបធៀបក្រុមទាំងពីរ ដោយប្រើ T-Test
t_stat, p_value = stats.ttest_ind(sales_after, sales_before)

print(f"P-Value គឺ: {p_value}")

if p_value < 0.05:
    print("Reject H0: យុទ្ធនាការ Marketing ថ្មី ពិតជាមានប្រសិទ្ធភាពមែន! (Statistically Significant)")
else:
    print("Accept H0: ការប្រែប្រួលអាចកើតឡើងដោយចៃដន្យ មិនទាន់អាចសន្និដ្ឋានថា Marketing ល្អទេ។")
```

**លទ្ធផល:**
P-Value នឹងចេញមកតូចខ្លាំងណាស់ (ឧ. `0.00001`) ដែលវាបញ្ជាក់ថាការលក់កើនឡើងដល់កម្រិត ២២០-២៤០ នេះ មិនមែនជារឿងចៃដន្យទេ។ យុទ្ធនាការរបស់អ្នកជោគជ័យហើយ! 

បច្ចេកទេសនេះ ត្រូវបានក្រុមហ៊ុនបច្ចេកវិទ្យាធំៗ យកទៅប្រើប្រាស់ក្នុងឈ្មោះថ្មីមួយហៅថា **A/B Testing** ដែលយើងនឹងរៀននៅមេរៀនបន្ទាប់!
