## 🌐 សេចក្តីផ្តើម (Overview)

អ្នកប្រហែលជាធ្លាប់លឺពាក្យថា "មធ្យមភាគ (Average)" តាំងពីនៅវិទ្យាល័យ។ នៅក្នុងការវិភាគទិន្នន័យ ការយល់ដឹងពីស្ថិតិ (Statistics) គឺជាភាពខុសគ្នារវាងអ្នកដែលអាចគ្រាន់តែសរសេរកូដ និងអ្នកដែលអាចធ្វើការសម្រេចចិត្តបែបវិទ្យាសាស្ត្រ (Data-Driven Decision)។

## 💻 ការគណនាស្ថិតិ (Code Breakdown)

**Descriptive Statistics** គឺជាក្បួនសម្រាប់ "សង្ខេប" និងពិពណ៌នាអំពីទិន្នន័យ។

### ១. រង្វាស់ទីតាំងកណ្តាល (Measures of Central Tendency)

តើទិន្នន័យរបស់យើងប្រមូលផ្តុំនៅត្រង់លេខប៉ុន្មាន?

```python
import pandas as pd
import numpy as np

# ប្រាក់ខែរបស់បុគ្គលិក ៥ នាក់
salaries = pd.Series([400, 450, 450, 500, 10000]) # 10000 គឺជាថៅកែ!

# ១. Mean (មធ្យមភាគ): បូកបញ្ចូលគ្នាចែកនឹងចំនួនអ្នក
print("Mean:", salaries.mean()) # លទ្ធផល: 2360

# ២. Median (មេដ្យាន): តម្រៀបពីតូចទៅធំ យកលេខកណ្តាលគេ
print("Median:", salaries.median()) # លទ្ធផល: 450 (ពិតប្រាកដជាង!)

# ៣. Mode (ម៉ូត): លេខដែលមានអ្នកបានច្រើនជាងគេ
print("Mode:", salaries.mode()[0]) # លទ្ធផល: 450
```

### ២. រង្វាស់នៃការពង្រាយ (Measures of Dispersion)

ចុះបើក្រុមហ៊ុនក មានមធ្យមភាគប្រាក់ខែ $500 ហើយក្រុមហ៊ុនខ ក៏មានមធ្យមភាគ $500 ដែរ។ តើវាដូចគ្នាទេ?
- ក្រុមហ៊ុន ក៖ អ្នកទាំងអស់គ្នាបាន $490, $500, $510 (ស្មើៗគ្នា)
- ក្រុមហ៊ុន ខ៖ មានអ្នកបាន $100 និងអ្នកបាន $900 (ខុសគ្នាដាច់)

យើងត្រូវប្រើ **Variance** និង **Standard Deviation (គម្លាតស្តង់ដារ)** ដើម្បីវាស់ថា តើលេខវាខុសគ្នាប៉ុណ្ណាពីមធ្យមភាគ!

```python
company_A = pd.Series([490, 500, 510])
company_B = pd.Series([100, 500, 900])

# គណនាគម្លាតស្តង់ដារ (Standard Deviation)
print("Std A:", company_A.std()) # លទ្ធផល: 10 (ប្រាក់ខែខុសគ្នាតិចតួច)
print("Std B:", company_B.std()) # លទ្ធផល: 400 (ប្រាក់ខែខុសគ្នាខ្លាំងណាស់!)
```
**Insights:** ក្នុងន័យធុរកិច្ច (Business) គម្លាតស្តង់ដារកាន់តែធំ មានន័យថា "ហានិភ័យ (Risk)" កាន់តែខ្ពស់។ បើអ្នកទិញភាគហ៊ុន ដែលមានប្រវត្តិឡើងចុះខ្លាំង (High Standard Deviation) អ្នកអាចចំណេញច្រើន ឫខាតច្រើន។

នៅក្នុង Pandas អ្នកគ្រាន់តែប្រើកូដមួយបន្ទាត់គឺ **`df.describe()`** នោះវានឹងគណនាស្ថិតិទាំងនេះអោយអ្នករួចជាស្រេច! នៅក្នុងមេរៀនបន្ទាប់ យើងនឹងរៀនពីអ្វីដែលមិនទាន់កើតឡើង នោះគឺ Probability (ប្រូបាប)!
