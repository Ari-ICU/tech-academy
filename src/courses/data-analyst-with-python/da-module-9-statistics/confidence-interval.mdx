## 🌐 សេចក្តីផ្តើម (Overview)

នៅពេលថៅកែសួរថា "តើអតិថិជនទិញអីវ៉ាន់ជាមធ្យមប៉ុន្មានដុល្លារ?"។ 
បើអ្នកឆ្លើយថា "$50" ហើយជាក់ស្តែងវាចេញមក $45 អ្នកនឹងត្រូវថៅកែស្តីបន្ទោស។
ប៉ុន្តែបើអ្នកឆ្លើយថា "ខ្ញុំជឿជាក់ 95% ថាវាចន្លោះពី $45 ទៅ $55" នោះអ្នកនឹងក្លាយជាទីប្រឹក្សាដ៏ឆ្លាតវៃ! នេះហៅថា **Confidence Interval (CI)**។

---

## 💻 ការគណនា CI (Code Breakdown)

យើងនឹងប្រើបណ្ណាល័យ **SciPy (Scientific Python)** ដែលជាបងប្អូនជីដូនមួយរបស់ NumPy សម្រាប់ការគណនាស្ថិតិស៊ីជម្រៅ។

```python
import numpy as np
import scipy.stats as stats

# ឧបមាថាយើងបានស្ទង់មតិអតិថិជន ១០០ នាក់ (Sample) អំពីការចំណាយរបស់ពួកគេ
np.random.seed(42)
spending_sample = np.random.normal(loc=50, scale=15, size=100) # មធ្យមគឺប្រហែល 50, គម្លាត 15

# ១. រកមធ្យមភាគ និងកំហុសស្តង់ដារ (Standard Error) នៃសំណាក
sample_mean = np.mean(spending_sample)
# Standard Error (SE) គឺកម្រិតរំញ័រនៃការប៉ាន់ស្មាន (បើ Sample កាន់តែធំ SE កាន់តែតូច)
se = stats.sem(spending_sample) 

# ២. គណនា 95% Confidence Interval
# df គឺ Degree of Freedom (ទំហំ Sample ដក 1)
confidence_level = 0.95
ci = stats.t.interval(confidence_level, df=len(spending_sample)-1, loc=sample_mean, scale=se)

print(f"Sample Mean គឺ: ${sample_mean:.2f}")
print(f"95% Confidence Interval គឺចន្លោះពី: ${ci[0]:.2f} ទៅ ${ci[1]:.2f}")
```

**លទ្ធផលដែលអាចចេញ:**
- Sample Mean: $48.44
- 95% CI: ចន្លោះពី $45.47 ទៅ $51.42

**ការបកស្រាយជូនថៅកែ:**
"ទោះបីជាការស្ទង់មតិលើមនុស្ស ១០០នាក់នេះ បង្ហាញថាមធ្យមភាគការចំណាយគឺ $48.44 ក៏ពិតមែន ប៉ុន្តែផ្អែកលើស្ថិតិ ខ្ញុំអាចធានាបាន 95% ថាបើគិតអតិថិជនសរុប (Population) គឺពួកគេនឹងចំណាយចន្លោះពី $45.47 ទៅ $51.42។ យើងអាចប្រើតួលេខទាបបំផុត ($45.47) ជាមូលដ្ឋានក្នុងការគ្រោងទុកចំណូល ដើម្បីកុំអោយខាតបង់។"

**ចំណាំ:** បើអ្នកស្ទង់មតិមនុស្សដល់ទៅ ៥០០០ នាក់ (Sample ធំ) នោះ CI នឹងរួមតូច (ឧ. ចន្លោះពី $49.5 ទៅ $50.5) ដែលមានន័យថាការប៉ាន់ស្មានរបស់អ្នក កាន់តែច្បាស់លាស់ (Precise) ទៅកៀកនឹងតម្លៃពិតប្រាកដ!
