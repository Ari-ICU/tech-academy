## 🌐 សេចក្តីផ្តើម (Overview)

ទិន្នន័យដោយគ្មានស្ថិតិ គឺគ្រាន់តែជាបញ្ជីលេខដ៏គួរឱ្យធុញប៉ុណ្ណោះ។ ស្ថិតិគឺជាភាសាដែលអនុញ្ញាតឱ្យទិន្នន័យ "និយាយប្រាប់រឿងរ៉ាវ" (Data Storytelling)។ នៅក្នុងការងារវិភាគទិន្នន័យអាជីព ថៅកែរបស់អ្នកនឹងពឹងផ្អែកលើអ្នក ដើម្បីបកស្រាយថាតើការកើនឡើងនៃការលក់ខែនេះ គឺជារឿងពិតប្រាកដ ឬគ្រាន់តែជារឿងចៃដន្យ (Statistical Significance)?

## 💡 គំនិតគោល (The Core Idea)

### យល់ដឹងពីការបែងចែក (Distribution)

ការមើលត្រឹមតែ "មធ្យមភាគ" គឺមិនគ្រប់គ្រាន់ទេ! អ្នកត្រូវមើលរូបរាងទាំងមូលនៃទិន្នន័យ (ឧ. តាមរយៈ Histogram)។
- **Normal Distribution (រាងកណ្តឹង):** ទិន្នន័យភាគច្រើនប្រមូលផ្តុំនៅកណ្តាល ជុំវិញមធ្យមភាគ។
- **Skewed Distribution:** ទិន្នន័យផ្អៀងទៅឆ្វេង ឫស្តាំ (មាន Outliers ច្រើន)។

### ការជ្រើសរើសរវាង Mean និង Median

```python
import numpy as np
import pandas as pd

salaries = [300, 350, 400, 320, 380, 15000] # 15000 គឺជា Outlier
df = pd.DataFrame({'Salary': salaries})

print("Mean:", df['Salary'].mean())     # ចេញលទ្ធផលខ្ពស់ខ្លាំង
print("Median:", df['Salary'].median()) # ចេញលទ្ធផលឆ្លុះបញ្ចាំងពីភាពពិត
```
