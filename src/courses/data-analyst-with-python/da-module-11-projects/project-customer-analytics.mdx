## 💻 គម្រោង៖ ការបែងចែកអតិថិជន (RFM Analysis)

**RFM** មកពីពាក្យ៖
- **R (Recency):** តើគាត់ទិញចុងក្រោយបំផុតពេលណា? (ទើបទិញថ្មីៗ គឺល្អ)
- **F (Frequency):** តើគាត់ទិញញឹកញាប់ប៉ុណ្ណា? (ទិញច្រើនដង គឺល្អ)
- **M (Monetary):** តើគាត់ចំណាយលុយសរុបប៉ុន្មាន? (ចំណាយច្រើន គឺល្អ)

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# ១. ទិន្នន័យប្រវត្តិទិញរបស់អតិថិជន ៥ នាក់
data = {
    'CustomerID': ['C001', 'C002', 'C003', 'C004', 'C005'],
    'Days_Since_Last_Purchase': [5, 120, 2, 300, 15], # Recency (តូចកាន់តែល្អ)
    'Total_Purchases': [20, 2, 50, 1, 10],            # Frequency
    'Total_Spent': [1500, 50, 5000, 10, 400]          # Monetary
}
df = pd.DataFrame(data)

# ២. ការបែងចែកក្រុម (Segmentation Logic)
def get_segment(row):
    if row['Days_Since_Last_Purchase'] < 30 and row['Total_Spent'] > 1000:
        return 'VIP Customers'
    elif row['Days_Since_Last_Purchase'] > 100 and row['Total_Purchases'] <= 2:
        return 'Lost Customers'
    else:
        return 'Regular Customers'

# អនុវត្តលក្ខខណ្ឌទៅកាន់ DataFrame (ប្រើ .apply())
df['Segment'] = df.apply(get_segment, axis=1)

print("--- បញ្ជីក្រុមអតិថិជន ---")
print(df[['CustomerID', 'Segment']])

# ៣. គូរក្រាហ្វិកមើលចំនួនអតិថិជនតាមក្រុម
plt.figure(figsize=(8, 5))
sns.countplot(data=df, x='Segment', palette='pastel')
plt.title('Customer Segmentation (ការបែងចែកអតិថិជន)')
plt.ylabel('ចំនួនអតិថិជន')
plt.show()

# ៤. មើលចំណូលពីក្រុមនីមួយៗ
revenue_by_segment = df.groupby('Segment')['Total_Spent'].sum().reset_index()
plt.figure(figsize=(8, 5))
plt.pie(revenue_by_segment['Total_Spent'], labels=revenue_by_segment['Segment'], 
        autopct='%1.1f%%', colors=['#ff9999','#66b3ff','#99ff99'])
plt.title('ចំណែកនៃចំណូល (Revenue by Segment)')
plt.show()
```

### 📝 អនុសាសន៍ផ្នែកទីផ្សារ (Marketing Strategy)

ផ្អែកលើការបែងចែកនេះ អ្នកអាចរៀបចំយុទ្ធសាស្ត្របានយ៉ាងច្បាស់លាស់៖
1. **VIP Customers (អ្នកចំណាយច្រើន ហើយទើបទិញថ្មីៗ):** ផ្តល់កាដូ (Gift) ឫ កាតសមាជិក (Loyalty Program) ដើម្បីអោយពួកគេមានអារម្មណ៍ថាជាមនុស្សសំខាន់។ កុំទាន់អោយ Discount ធំៗ ព្រោះពួកគេមានលុយទិញពេញថ្លៃស្រាប់ហើយ។
2. **Regular Customers:** ផ្ញើសារណែនាំផលិតផលថ្មីៗ (Cross-selling) ដើម្បីអោយពួកគេទិញញឹកញាប់ជាងមុន។
3. **Lost Customers (បាត់មុខយូរ):** ផ្ញើគូប៉ុងបញ្ចុះតម្លៃពិសេស (Win-back Coupon 50%) តាមអ៊ីមែល ដើម្បីហៅពួកគេអោយត្រលប់មកទិញម្តងទៀត។
