## 🛠️ គម្រោងអនុវត្តន៍ (Project Walkthrough)

### ១. សំណួរអាជីវកម្ម (Business Questions)
1. តើប្រាក់ចំណូលសរុបប្រចាំខែនីមួយៗមានចំនួនប៉ុន្មាន?
2. តើទីក្រុងណាដែលបញ្ជាទិញច្រើនជាងគេ?

### ២. កូដគំរូសម្រាប់ចាប់ផ្តើម (Starter Code)

```python
import pandas as pd
import matplotlib.pyplot as plt

# ១. អានទិន្នន័យ
df = pd.read_csv("sales_data.csv")

# ២. សម្អាតទិន្នន័យ
df = df.dropna()
df['Order Date'] = pd.to_datetime(df['Order Date'])
df['Month'] = df['Order Date'].dt.month

# ៣. វិភាគ
monthly_sales = df.groupby('Month')['Total Price'].sum()

# ៤. បង្ហាញជាក្រាហ្វិក
monthly_sales.plot(kind='bar', color='skyblue')
plt.title("ចំណូលប្រចាំខែ")
plt.xlabel("ខែ")
plt.ylabel("ប្រាក់ចំណូល ($)")
plt.show()
```

អ្នកអាចយកកូដគំរូនេះទៅសាកល្បងជាមួយនឹងសំណុំទិន្នន័យ (Dataset) ផ្ទាល់ខ្លួនរបស់អ្នកបាន។ ការអនុវត្តផ្ទាល់គឺជាមធ្យោបាយតែមួយគត់ ដើម្បីក្លាយជា Data Analyst ដ៏ឆ្នើម!
