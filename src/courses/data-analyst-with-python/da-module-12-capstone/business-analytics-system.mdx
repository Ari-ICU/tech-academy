## 🌐 សេចក្តីផ្តើម (Overview)

អបអរសាទរដែលអ្នកបានធ្វើដំណើរមកដល់ចុងបញ្ចប់នៃវគ្គសិក្សា **Data Analyst with Python**! នេះមិនមែនជាទីបញ្ចប់ទេ តែជាការចាប់ផ្តើមនៃអាជីពថ្មីរបស់អ្នក។ នៅក្នុង **Capstone Project** នេះ អ្នកនឹងធ្វើការដោយឯករាជ្យ ដើម្បីកសាង **Online Store Data Analytics Platform** មួយដ៏ពេញលេញ។ នេះគឺជាស្នាដៃ (Portfolio) ដែលអ្នកអាចយកទៅបង្ហាញដល់និយោជកពេលសម្ភាសន៍ការងារបាន!

## 🛠️ តម្រូវការគម្រោង (Project Requirements)

### សេណារីយ៉ូ (The Scenario)
អ្នកទើបតែត្រូវបានជួលអោយធ្វើជា Data Analyst សម្រាប់ក្រុមហ៊ុនលក់ទំនិញអនឡាញមួយ។ ប្រធានផ្នែកលក់បានផ្តល់ទិន្នន័យ (Database ឫ CSV) ដែលមានផ្ទុកប្រតិបត្តិការរាប់សែនក្នុងរយៈពេល ៣ ឆ្នាំចុងក្រោយ ហើយសុំអោយអ្នករៀបចំរបាយការណ៍ទូលំទូលាយមួយ។

### ភារកិច្ចរបស់អ្នក (Your Tasks)

1. **ប្រមូលទិន្នន័យ (Data Collection):** អានទិន្នន័យពីឯកសារ CSV និង SQL Database បញ្ចូលគ្នាទៅក្នុង Pandas DataFrame។
2. **សម្អាតទិន្នន័យ (Data Cleaning):**
   - ស្វែងរក និងលុប/ជំនួសទិន្នន័យដែលបាត់បង់ (Missing Values)។
   - បំប្លែងប្រភេទឯកតា (Data Types) អោយបានត្រឹមត្រូវ ជាពិសេសជួរឈរ 'កាលបរិច្ឆេទ' (Datetime)។
3. **វិភាគសេដ្ឋកិច្ច (Exploratory Data Analysis):**
   - គណនាចំណូលប្រចាំខែ (Monthly Revenue Trend)។
   - ស្វែងរក Top 10 ផលិតផលដែលលក់ដាច់ជាងគេ។
   - វិភាគអតិថិជន (Customer Segmentation) តាមរយៈការចំណាយ។
4. **រូបភាពនីយកម្ម (Data Visualization):** ប្រើប្រាស់ Matplotlib និង Seaborn ដើម្បីគូរក្រាហ្វិកយ៉ាងតិច ៥ ដែលមានការរចនាច្បាស់លាស់។
5. **របាយការណ៍ (Reporting):** សរសេររបាយការណ៍សង្ខេប (Executive Summary) បង្ហាញពីការរកឃើញសំខាន់ៗ និងផ្តល់អនុសាសន៍ (Actionable Insights) ទៅកាន់ថ្នាក់ដឹកនាំ។

*សំណាងល្អជាមួយគម្រោងរបស់អ្នក! ការខិតខំប្រឹងប្រែងរបស់អ្នកចាប់ពីថ្ងៃនេះ នឹងហុចផលនៅថ្ងៃអនាគតជាមិនខាន។*
