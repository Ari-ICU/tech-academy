## 💻 អ្វីទៅជា Matplotlib?

**Matplotlib** គឺជាបណ្ណាល័យ (Library) បង្កើតក្រាហ្វិកដ៏ចាស់វស្សា និងមានឥទ្ធិពលបំផុតរបស់ Python។ វាត្រូវបានបង្កើតឡើងតាំងពីឆ្នាំ ២០០៣ ដើម្បីជំនួសកម្មវិធី MATLAB។

ទោះបីជាបច្ចុប្បន្នមានបណ្ណាល័យថ្មីៗច្រើន (ដូចជា Seaborn ឫ Plotly) ក៏ដោយ ក៏ Matplotlib នៅតែជា "គ្រឹះ" ដ៏សំខាន់បំផុត ព្រោះបណ្ណាល័យថ្មីៗទាំងនោះសុទ្ធតែប្រើប្រាស់ Matplotlib នៅពីក្រោយខ្នង (Under the hood)។

### ការហៅមកប្រើប្រាស់ (Importing)

ដោយសារ Matplotlib ជាបណ្ណាល័យដ៏ធំ យើងកម្រនឹង Import វាទាំងស្រុងណាស់។ យើងច្រើនតែ Import យកតែផ្នែកតូចមួយរបស់វាឈ្មោះថា **`pyplot`** ដែលជាកញ្ចប់ឧបករណ៍ងាយស្រួលគូរក្រាហ្វិកបំផុត។ ឈ្មោះកាត់ជាសកលរបស់វាគឺ **`plt`**។

```python
# ហៅ Pandas និង NumPy មកដូចធម្មតា
import pandas as pd
import numpy as np

# ហៅ pyplot ពី Matplotlib ហើយតាងវាថា plt
import matplotlib.pyplot as plt

# កូដវេទមន្តនេះ (Magic Command) គឺសម្រាប់តែ Jupyter Notebook ប៉ុណ្ណោះ
# វាជួយអោយក្រាហ្វិកលោតចេញមកក្នុង Notebook តែម្តង ដោយមិនបាច់បើកផ្ទាំងថ្មី
%matplotlib inline
```

នៅក្នុងមេរៀនបន្ទាប់ យើងនឹងចាប់ផ្តើមគូរក្រាហ្វិកដំបូងបង្អស់របស់យើង គឺក្រាហ្វិកបន្ទាត់ (Line Chart) និង ក្រាហ្វិកសសរ (Bar Chart)!
