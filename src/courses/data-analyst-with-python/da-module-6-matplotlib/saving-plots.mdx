## 🌐 សេចក្តីផ្តើម (Overview)

អ្នកបានខិតខំប្រឹងប្រែងយ៉ាងខ្លាំង ដើម្បីសំអាតទិន្នន័យ និងតុបតែងក្រាហ្វិកអោយស្អាត។ ប៉ុន្តែបើសិនជាអ្នកយកទូរស័ព្ទដៃ មកថតអេក្រង់កុំព្យូទ័រ (Screenshot) នោះគុណភាពរូបនឹងអន់ខ្លាំងណាស់ ពេលដាក់ក្នុង Projector អង្គប្រជុំ។ Matplotlib អនុញ្ញាតអោយអ្នក Save ក្រាហ្វិកក្នុងគុណភាពខ្ពស់កម្រិត 4K បាន!

## 💻 ការបំបែកកូដ (Code Breakdown)

```python
import matplotlib.pyplot as plt

# គូរក្រាហ្វិកងាយៗ
plt.plot([1, 2, 3], [10, 20, 15], marker='o')
plt.title("ឧទាហរណ៍ក្រាហ្វិក")
plt.xlabel("X Axis")

# ចំណុចសំខាន់! យើង Save មុនពេល Show
# dpi=300 (Dots Per Inch) គឺជាស្តង់ដារសម្រាប់បោះពុម្ព (High Quality)
# bbox_inches='tight' ធានាថាវានឹងមិនកាត់ដាច់អក្សរនៅតាមគែមៗ
plt.savefig("my_beautiful_chart.png", dpi=300, bbox_inches='tight')

# ប្រសិនបើអ្នកចង់បានឯកសារ PDF (អាច Zoom អត់បែក)
plt.savefig("my_beautiful_chart.pdf")

# បន្ទាប់ពី Save រួចរាល់ សឹមបង្ហាញវានៅលើអេក្រង់!
plt.show()
```

### ការដោះស្រាយបញ្ហា (Troubleshooting)

ប្រសិនបើអ្នកទទួលបានឯកសាររូបភាព `png` តែបើកមកឃើញ **សក្បុស (ទទេ)** សូមត្រួតពិនិត្យមើលកូដឡើងវិញ! អ្នកប្រាកដជាបានសរសេរ `plt.show()` មុន `plt.savefig()` ហើយ! គ្រាន់តែប្តូរទីតាំងវា នោះបញ្ហានឹងត្រូវបានដោះស្រាយ។

នៅក្នុងវគ្គបន្ទាប់ យើងនឹងយកចំណេះដឹងពី Module ទី ៦ ទាំងមូល មកបង្កើតជារបាយការណ៍លក់ (Sales Dashboard) ដ៏អស្ចារ្យមួយ!
