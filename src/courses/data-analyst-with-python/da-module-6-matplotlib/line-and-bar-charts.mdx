## 🌐 សេចក្តីផ្តើម (Overview)

ទោះបីជាពិភពលោកជឿនលឿនយ៉ាងណាក៏ដោយ **Line Chart** និង **Bar Chart** នៅតែជាស្តេចនៃការធ្វើរបាយការណ៍។ វាងាយស្រួលមើល ងាយស្រួលយល់ និងមិនទាមទារការពន្យល់ច្រើន។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ក្រាហ្វិកបន្ទាត់ (Line Chart)

Line Chart ស័ក្តិសមបំផុតសម្រាប់ទិន្នន័យដែលមានការប្រែប្រួលតាមពេលវេលា (Time Series) ដូចជា ចំណូលប្រចាំខែ ឫសីតុណ្ហភាពប្រចាំថ្ងៃ។

```python
import matplotlib.pyplot as plt

# ទិន្នន័យ (អ័ក្ស X ជាខែ, អ័ក្ស Y ជាចំណូល)
months = ['Jan', 'Feb', 'Mar', 'Apr', 'May']
revenue = [1000, 1200, 1100, 1500, 1800]

# គូរក្រាហ្វិកបន្ទាត់ដោយប្រើ .plot()
plt.plot(months, revenue)

# តុបតែងវាបន្តិចកុំអោយទទេស្អាតពេក
plt.title("ចំណូលប្រចាំខែ (Monthly Revenue)")
plt.xlabel("ខែ (Month)")
plt.ylabel("ចំណូលគិតជាដុល្លារ ($)")

# បង្ហាញក្រាហ្វិក
plt.show()
```

### ២. ក្រាហ្វិកសសរ (Bar Chart)

Bar Chart ស័ក្តិសមសម្រាប់ការ "ប្រៀបធៀប (Comparison)" ទិន្នន័យប្រភេទអក្សរផ្សេងៗគ្នា។ ឧទាហរណ៍៖ ការលក់តាមសាខា ឫ ការលក់តាមប្រភេទទំនិញ។

```python
# ទិន្នន័យ
products = ['Coffee', 'Tea', 'Soda', 'Water']
sales_qty = [250, 180, 300, 400]

# គូរក្រាហ្វិកសសរដោយប្រើ .bar()
# កំណត់ពណ៌ (color) អោយវាស្អាតបន្តិច
plt.bar(products, sales_qty, color='skyblue')

# តុបតែង
plt.title("ចំនួនលក់តាមប្រភេទទំនិញ (Sales by Product)")
plt.xlabel("ប្រភេទទំនិញ")
plt.ylabel("ចំនួនកែវដែលលក់បាន")

# បង្ហាញក្រាហ្វិក
plt.show()
```
