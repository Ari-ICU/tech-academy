## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងពិភព Excel អ្នកវាយលេខ វានឹងដឹងថាជាលេខ។ ប៉ុន្តែពេលនាំចូលមក Pandas ប្រសិនបើមានអតិថិជនម្នាក់វាយអាយុខ្លួនឯងថា "25 ឆ្នាំ" នោះ Pandas នឹងចាត់ទុកជួរឈរ "អាយុ" ទាំងមូលជា "អក្សរ (Object)"។ ពេលអ្នកយកវាទៅគណនាមធ្យមភាគ (`mean()`) វានឹងលោត Error ភ្លាម!

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ពិនិត្យមើល Data Types

```python
import pandas as pd

# ទិន្នន័យដែលអានចេញពី CSV ជារឿយៗមានបញ្ហាបែបនេះ
data = {'អាយុ': ['25', '30', '22'], 'ប្រាក់ខែ': ['$500', '$800', '$450']}
df = pd.DataFrame(data)

# ពិនិត្យមើល Type របស់វា
print(df.dtypes)
# លទ្ធផល: អាយុ (object), ប្រាក់ខែ (object)
# object មានន័យថាជា String (អក្សរ)!
```

### ២. ការបំប្លែងសាមញ្ញ (`astype`)

សម្រាប់ជួរឈរ "អាយុ" វាជាលេខសុទ្ធស្រាប់ហើយ គ្រាន់តែវាពាក់អាវជាអក្សរ (String)។ យើងអាចដោះអាវវាបានដោយប្រើ `.astype()`។

```python
# បំប្លែងអក្សរ '25' ទៅជា លេខ 25 (integer)
df['អាយុ'] = df['អាយុ'].astype(int)

print(df.dtypes)
# ឥឡូវ អាយុ ក្លាយជា int64 ហើយអាចយកទៅបូកដកបាន!
```

### ៣. ការបំប្លែងទិន្នន័យស្មុគស្មាញ (លុបអក្សរមុនបំប្លែង)

ចំណែកឯជួរឈរ "ប្រាក់ខែ" មានជាប់សញ្ញា `$500`។ បើអ្នកបញ្ជាអោយកុំព្យូទ័របំប្លែងទៅជាលេខ (`astype(float)`) វានឹង Error ព្រោះវាមិនស្គាល់សញ្ញា `$`។ អ្នកត្រូវ "លុប" សញ្ញានោះចោលសិន!

```python
# ជំហានទី១៖ ប្រើ .str.replace() ដើម្បីប្តូរសញ្ញា $ ទៅជាចន្លោះទទេ (លុបចោល)
df['ប្រាក់ខែ'] = df['ប្រាក់ខែ'].str.replace('$', '')

# ពេលនេះទិន្នន័យទៅជា ['500', '800', '450']

# ជំហានទី២៖ បំប្លែងវាទៅជា លេខទសភាគ (float)
df['ប្រាក់ខែ'] = df['ប្រាក់ខែ'].astype(float)

print(df['ប្រាក់ខែ'].mean()) # ឥឡូវអាចគណនាមធ្យមភាគបានហើយ!
```

ក្បួននេះត្រូវបានប្រើប្រាស់ ១០០% នៅក្នុងការងារពិត! ពេលខ្លះអ្នកត្រូវលុបសញ្ញាក្បៀស (`,`) ចេញពីលេខ (ឧ. `1,000`) មុននឹងបំប្លែងវាទៅជា float ផងដែរ។
