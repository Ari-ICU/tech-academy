## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងពិភពពិត ទិន្នន័យមិនដែលល្អឥតខ្ចោះនោះទេ។ ជារឿយៗ អ្នកប្រើប្រាស់មិនបានបំពេញព័ត៌មានគ្រប់ជ្រុងជ្រោយ ធ្វើឱ្យទិន្នន័យមានតម្លៃទទេ (NaN ឫ Null)។ ប្រសិនបើអ្នកមិនដោះស្រាយវាទេ ការវិភាគ និងការគណនាស្ថិតិរបស់អ្នកនឹងខុសឆ្គងទាំងស្រុង។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការស្វែងរកទិន្នន័យបាត់បង់

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    'Name': ['Sok', 'Sao', 'Bopha', 'Minea'],
    'Age': [25, np.nan, 22, 30],
    'Salary': [500, 600, np.nan, 800]
})

# រាប់ចំនួន NaN ក្នុងជួរឈរនីមួយៗ
print(df.isnull().sum())
```

### ២. ការដោះស្រាយដោយលុបចោល (`dropna`)

```python
# លុបជួរដេកណាដែលមាន NaN
clean_df = df.dropna()
print(clean_df)
```

### ៣. ការដោះស្រាយដោយជំនួស (`fillna`)

```python
# ជំនួសអាយុដែលបាត់ ដោយអាយុមធ្យមភាគ
mean_age = df['Age'].mean()
df['Age'] = df['Age'].fillna(mean_age)
print(df)
```
