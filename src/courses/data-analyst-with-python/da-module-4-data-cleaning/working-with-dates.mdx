## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងទិន្នន័យលក់ដូរ ពេលវេលា (Time) គឺជារឿងសំខាន់បំផុត! "តើខែណាលក់ដាច់ជាងគេ?"។ ប៉ុន្តែនៅពេលដែល Pandas អានឯកសារ CSV វាចាត់ទុកជួរឈរ "01/12/2023" ជាអក្សរធម្មតា (String) ដែលធ្វើអោយយើងមិនអាចស្រង់យកតែ "ខែ 12" ចេញមកបានទេ។ យើងត្រូវបំប្លែងវាទៅជា **Datetime Object** សិន។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការបំប្លែងទៅជា Datetime

```python
import pandas as pd

# ទិន្នន័យកាលបរិច្ឆេទដែលអានមកជាប់ជា អក្សរ (String)
data = {'កាលបរិច្ឆេទ': ['2023-12-01', '2023-12-15', '2024-01-05']}
df = pd.DataFrame(data)

# បំប្លែងវាទៅជា Datetime Object
df['កាលបរិច្ឆេទ'] = pd.to_datetime(df['កាលបរិច្ឆេទ'])

# ឥឡូវ Type របស់វាគឺ datetime64! មិនមែន object ទៀតទេ
print(df.dtypes)
```

### ២. ការទាញយក ឆ្នាំ ខែ ថ្ងៃ ដាច់ដោយឡែកពីគ្នា

នៅពេលវាប្រែក្លាយទៅជា Datetime ហើយ នោះ Pandas ដឹងយ៉ាងច្បាស់ថា ណាជាខែ ណាជាឆ្នាំ។ យើងអាចប្រើ `.dt` ដើម្បីទាញយកវាមកបង្កើតជាជួរឈរថ្មី!

```python
# ទាញយក "ឆ្នាំ" មកបង្កើតជាជួរឈរថ្មី
df['ឆ្នាំ'] = df['កាលបរិច្ឆេទ'].dt.year

# ទាញយក "ខែ" 
df['ខែ'] = df['កាលបរិច្ឆេទ'].dt.month

# ទាញយក "ថ្ងៃ"
df['ថ្ងៃ'] = df['កាលបរិច្ឆេទ'].dt.day

# ពិសេសជាងនេះ! រកឈ្មោះថ្ងៃ (ច័ន្ទ, អង្គារ...)
df['ឈ្មោះថ្ងៃ'] = df['កាលបរិច្ឆេទ'].dt.day_name()

print(df)
```
**លទ្ធផល:**
```text
  កាលបរិច្ឆេទ  ឆ្នាំ  ខែ  ថ្ងៃ  ឈ្មោះថ្ងៃ
0 2023-12-01  2023  12   1     Friday
1 2023-12-15  2023  12  15     Friday
2 2024-01-05  2024   1   5     Friday
```

ឥឡូវនេះ អ្នកអាចប្រើប្រាស់មុខងារ `GroupBy` ទៅលើជួរឈរ "ខែ" ដើម្បីរកចំណូលប្រចាំខែ (Monthly Revenue) បានយ៉ាងងាយស្រួល!
