## 🌐 សេចក្តីផ្តើម (Overview)

នៅពេលអតិថិជនបំពេញទម្រង់ (Form) តាមអ៊ីនធឺណិត ម្នាក់ៗវាយតាមចំណូលចិត្ត។ អ្នកខ្លះវាយអក្សរធំទាំងអស់ ("APPLE") អ្នកខ្លះវាយអក្សរតូច ("apple") អ្នកខ្លះដៃរហ័សវាយមាន Space នៅខាងមុខទៀត (" apple ")។ ពេលអ្នកយកវាទៅធ្វើ GroupBy កុំព្យូទ័រនឹងគិតថាវាជាទំនិញ ៣ ប្រភេទផ្សេងគ្នា!

## 💻 ការបំបែកកូដ (Code Breakdown)

យើងមានតារាង `df` ដែលកត់ត្រាការទិញទូរស័ព្ទ៖
| អតិថិជន | ម៉ាក |
| :--- | :--- |
| សុខ | iPhone |
| សៅ | iphone |
| វ៉ាន់ |  Iphone  |

### ១. បង្រួបបង្រួមអក្សរធំ/តូច (`lower` & `upper`)

```python
import pandas as pd

data = {'ម៉ាក': ['iPhone', 'iphone', ' Iphone ']}
df = pd.DataFrame(data)

# ប្រសិនបើយើង GroupBy ឥឡូវនេះ វានឹងចេញ ៣ ម៉ាកដាច់ដោយឡែកពីគ្នា!

# ជំហានទី១៖ ប្តូរវាទៅជាអក្សរតូចទាំងអស់ (lower case)
df['ម៉ាក'] = df['ម៉ាក'].str.lower()
```

### ២. កាត់ចោលចន្លោះទទេដែលលើស (`strip`)

ទោះបីប្តូរជាអក្សរតូចក៏ដោយ ពាក្យ `" iphone "` (របស់វ៉ាន់) នៅតែខុសពីគេ ព្រោះវាមាន Space នៅខាងមុខ និងខាងក្រោយ។ យើងប្រើ `.strip()` ដើម្បីកាត់វាចោល (ដូចមុខងារ `TRIM()` ក្នុង Excel ដែរ)។

```python
# ជំហានទី២៖ កាត់ Space ក្បាល និង កន្ទុយ
df['ម៉ាក'] = df['ម៉ាក'].str.strip()

print(df['ម៉ាក'].values)
# លទ្ធផល: ['iphone' 'iphone' 'iphone']
```

ឥឡូវនេះម៉ាកទាំង ៣ គឺដូចគ្នាទាំងស្រុងបេះបិទ! បើអ្នកយកវាទៅ GroupBy Pandas នឹងរាប់បញ្ចូលថាមានការទិញ "iphone" ចំនួន ៣ គ្រឿងយ៉ាងត្រឹមត្រូវ។

**គន្លឹះអ្នកជំនាញ (Pro Tip):** នៅក្នុងការងារជាក់ស្តែង យើងតែងតែសរសេរមុខងារទាំងនេះតភ្ជាប់គ្នា (Chaining) តែម្តង ដើម្បីចំណេញបន្ទាត់កូដ៖
```python
# កាត់ Space ផង ប្តូរជាអក្សរតូចផង ក្នុងបន្ទាត់តែមួយ!
df['ម៉ាក'] = df['ម៉ាក'].str.strip().str.lower()
```
