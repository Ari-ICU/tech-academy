## 🌐 សេចក្តីផ្តើម (Overview)

បញ្ហាមួយទៀតដែលឧស្សាហ៍ជួបប្រទះ គឺ "ទិន្នន័យស្ទួន"។ ឧទាហរណ៍៖ អតិថិជនម្នាក់ចុចប៊ូតុង "ទិញ" រួចអ៊ីនធឺណិតគាំង គាត់ក៏ចុចម្តងទៀត។ ពេលនោះ Database នឹងកត់ត្រាការទិញនោះ ២ ដង។ បើអ្នកមិនលុបវាចោលទេ ចំណូលក្រុមហ៊ុននឹងកើនឡើងក្លែងក្លាយ!

## 💻 ការបំបែកកូដ (Code Breakdown)

ឧបមាថាយើងមាន DataFrame `df` ដូចខាងក្រោម៖
| វិក្កយបត្រ | អតិថិជន | តម្លៃ |
| :--- | :--- | :--- |
| 001 | សុខ | 50 |
| 002 | សៅ | 20 |
| 001 | សុខ | 50 | <-- (នេះស្ទួននឹងជួរទី១ ទាំងស្រុង!)

### ១. ការស្វែងរកទិន្នន័យស្ទួន (`duplicated`)

មុននឹងលុប អ្នកគួរតែមើលសិនថាវាពិតជាស្ទួនមែនឫអត់។

```python
import pandas as pd

# ឧបមាថា df ត្រូវបានបង្កើតរួច
# ពិនិត្យមើលថាតើមានជួរណាដែលស្ទួនដែរឬទេ? (បញ្ចេញជា True/False)
print(df.duplicated())

# រាប់ចំនួនជួរដែលស្ទួនសរុប (ជួយអោយដឹងថាមានប៉ុន្មានកំហុស)
print("ចំនួនជួរស្ទួនសរុប:", df.duplicated().sum()) # លទ្ធផល: 1
```

### ២. ការលុបចោលទាំងស្រុង (`drop_duplicates`)

```python
# លុបជួរដែលស្ទួន ហើយរក្សាទុកតែជួរដែលនៅខាងលើគេ (keep='first')
clean_df = df.drop_duplicates()

print(clean_df)
# លទ្ធផលនឹងសល់តែ ២ ជួរខាងលើប៉ុណ្ណោះ!
```

### ៣. ការលុបស្ទួនដោយមើលលើជួរឈរជាក់លាក់ (Subset)

ចុះបើមានករណី៖
| វិក្កយបត្រ | អតិថិជន | ម៉ោង |
| :--- | :--- | :--- |
| 001 | សុខ | 08:00 |
| 001 | សុខ | 08:05 |

ជួរទាំងពីរនេះ "ម៉ោង" មិនដូចគ្នាទេ ដូច្នេះ `drop_duplicates()` ធម្មតានឹងមិនលុបវាទេ ព្រោះចាត់ទុកថាជាទិន្នន័យពីរផ្សេងគ្នា។ ប៉ុន្តែយើងដឹងថា "លេខវិក្កយបត្រ" មិនអាចជាន់គ្នាទេ! យើងអាចប្រាប់ Pandas អោយពិនិត្យស្ទួនតែលើជួរឈរ "វិក្កយបត្រ" ប៉ុណ្ណោះ។

```python
# ស្វែងរកការស្ទួន ដោយផ្អែកលើជួរឈរ 'វិក្កយបត្រ' តែមួយគត់
# ហើយរក្សាទុកកំណត់ត្រាចុងក្រោយបង្អស់ (ប្រហែលម៉ោង 08:05 ជាការទិញជោគជ័យចុងក្រោយ)
final_df = df.drop_duplicates(subset=['វិក្កយបត្រ'], keep='last')

print(final_df)
```

ការលុបស្ទួន គឺជាជំហានទី២ នៃការសំអាតទិន្នន័យ បន្ទាប់ពីការដោះស្រាយ Missing Data!
