## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុង Pandas តម្លៃដែលបាត់បង់ត្រូវបានបង្ហាញជាអក្សរ **`NaN` (Not a Number)** ឬ **`None`**។ អ្នកមិនអាចយកវាទៅគណនាបានទេ។ ដូច្នេះអ្នកត្រូវធ្វើការសម្រេចចិត្ត៖ តើត្រូវ **លុបវាចោល** ឬ **ចាក់បំពេញ** វា?

---

## 💻 ការបំបែកកូដ (Code Breakdown)

ឧបមាថាយើងមានតារាង `df` ដូចខាងក្រោម៖
| ឈ្មោះ | អាយុ | ប្រាក់ខែ |
| :--- | :--- | :--- |
| សុខ | 25 | 500 |
| សៅ | NaN | 800 |
| វ៉ាន់ | 22 | NaN |

### ១. ការស្វែងរកទិន្នន័យដែលបាត់ (`isnull`)

មុននឹងដោះស្រាយ អ្នកត្រូវរកវាអោយឃើញសិន។

```python
import pandas as pd

# (កូដបង្កើត DataFrame ដូចខាងលើ)
# ...

# ពិនិត្យមើលថាតើក្រឡាណាខ្លះជា NaN (បញ្ចេញជា True/False)
print(df.isnull())

# រាប់ចំនួន NaN ក្នុងជួរឈរនីមួយៗ (សាហាវ និងប្រើញឹកញាប់បំផុត!)
print(df.isnull().sum())
```
**លទ្ធផល:**
```text
ឈ្មោះ       0
អាយុ        1   <-- បាត់ ១ កន្លែង
ប្រាក់ខែ    1   <-- បាត់ ១ កន្លែង
dtype: int64
```

### ២. ការលុបចោល (`dropna`)

ប្រសិនបើទិន្នន័យដែលបាត់មានតិចតួច (ឧទាហរណ៍ក្រោម ២%) អ្នកអាចលុបវាចោលទាំងជួរតែម្តង ដើម្បីកុំអោយឈឺក្បាល។

```python
# លុបចោលជួរដេកណាដែលមាន NaN សូម្បីតែមួយក្រឡា
clean_df = df.dropna()

print(clean_df) 
# លទ្ធផល: សល់តែ 'សុខ' ម្នាក់គត់ដែលទិន្នន័យពេញលេញ!
```

### ៣. ការចាក់បំពេញ (`fillna`)

ការលុបចោលច្រើនពេក ធ្វើអោយខាតទិន្នន័យ។ វិធីល្អបំផុត គឺ "ចាក់បំពេញ" កន្លែងទទេនោះ។

```python
# វិធីទី១៖ ចាក់បំពេញដោយលេខដែលយើងកំណត់ (ឧ. លេខ 0)
filled_zeros = df.fillna(0)

# វិធីទី២ (អ្នកជំនាញ)៖ ចាក់បំពេញអាយុទទេ ដោយ "អាយុមធ្យម (Mean)" របស់បុគ្គលិកផ្សេង
mean_age = df["អាយុ"].mean() # គណនាមធ្យមភាគសិន (25+22)/2 = 23.5

# បញ្ចូលលេខ 23.5 ទៅកន្លែងដែលអាយុស្មើ NaN
df["អាយុ"] = df["អាយុ"].fillna(mean_age)

print(df)
```

ឥឡូវនេះ "សៅ" ត្រូវបានកុំព្យូទ័រសន្មតថាមានអាយុ ២៣.៥ ឆ្នាំ! នេះហៅថាបច្ចេកទេស **Data Imputation**។
