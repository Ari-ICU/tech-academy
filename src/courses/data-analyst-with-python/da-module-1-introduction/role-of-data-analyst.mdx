## 🌐 សេចក្តីផ្តើម (Overview)

"ទិន្នន័យគឺជាប្រេងកាតនៅសតវត្សរ៍ទី ២១" ។ ប៉ុន្តែប្រេងកាតឆៅ មិនអាចចាក់ចូលឡានបានទេ វាត្រូវការអ្នកចម្រាញ់។ នៅក្នុងពិភពទិន្នន័យ យើងមានតួអង្គធំៗ ៣ ដែលធ្វើការរួមគ្នា ដើម្បីប្រែក្លាយទិន្នន័យឆៅ ទៅជាប្រាក់ចំណេញរបស់ក្រុមហ៊ុន។

---

## 👨‍💻 តួអង្គសំខាន់ៗទាំង ៣ ក្នុងពិភពទិន្នន័យ

### ១. Data Engineer (អ្នកសាងសង់)
- **តួនាទី:** ប្រមូលទិន្នន័យពីប្រភពផ្សេងៗ (Facebook, Website, Mobile App) ហើយសង់ប្រព័ន្ធ (Pipelines) ដើម្បីដឹកជញ្ជូនទិន្នន័យទាំងនោះមករក្សាទុកនៅកន្លែងតែមួយ (Data Warehouse) យ៉ាងមានសុវត្ថិភាព។
- **ជំនាញ:** SQL កម្រិតខ្ពស់, Python, Cloud (AWS/GCP), ETL Tools។

### ២. Data Analyst (អ្នកស៊ើបអង្កេត - **តួនាទីរបស់អ្នក!**)
- **តួនាទី:** យកទិន្នន័យដែល Engineer បានរៀបចំ រួចយកមកសំអាត វិភាគ និងរកមើល "អត្ថន័យ" ដែលលាក់កំបាំង។ បន្ទាប់មក យកលទ្ធផលទៅបង្ហាញថ្នាក់ដឹកនាំ (Dashboards) ដើម្បីជួយពួកគេក្នុងការសម្រេចចិត្ត។
- **ជំនាញ:** Excel, SQL, Python (Pandas/Matplotlib), BI Tools (Tableau/Power BI)។

### ៣. Data Scientist (អ្នកព្យាករណ៍)
- **តួនាទី:** ស្រដៀងនឹង Data Analyst ដែរប៉ុន្តែពួកគេផ្តោតលើការសរសេរកូដ Machine Learning (AI) ដើម្បី "ទស្សន៍ទាយ (Predict)" អនាគត។ ឧទាហរណ៍៖ ទស្សន៍ទាយថាអតិថិជនណានឹងឈប់ប្រើប្រាស់សេវាកម្ម។
- **ជំនាញ:** Python កម្រិតខ្ពស់, Math/Statistics, Machine Learning, Deep Learning។

## 📊 ទំនួលខុសត្រូវប្រចាំថ្ងៃរបស់ Data Analyst

ប្រសិនបើអ្នកធ្វើការជា Data Analyst នៅក្រុមហ៊ុនលក់ទំនិញ នេះគឺជាអ្វីដែលអ្នកត្រូវធ្វើ៖
1. **ឆ្លើយសំណួររបស់ថ្នាក់ដឹកនាំ:** "ហេតុអ្វីបានជាការលក់ធ្លាក់ចុះនៅខែមុន?"
2. **ទាញទិន្នន័យ (Data Extraction):** សរសេរ SQL ដើម្បីទាញទិន្នន័យការលក់ចេញពី Database។
3. **សំអាតទិន្នន័យ (Data Cleaning):** លុបទិន្នន័យស្ទួន ឫទិន្នន័យដែលមិនពេញលេញចោល។
4. **រុករក (EDA):** ប្រើប្រាស់ Python (Pandas) ដើម្បីរកមើលថាតើទំនិញប្រភេទណាដែលលក់មិនដាច់។
5. **របាយការណ៍ (Reporting):** បង្កើតតារាង (Dashboard) ក្នុង Power BI បង្ហាញពីមូលហេតុនៃការធ្លាក់ចុះ និងសរសេរជាអនុសាសន៍។

ការងារជា Data Analyst មិនមែនត្រឹមតែការសរសេរកូដទេ វាគឺជាសិល្បៈនៃការប្រាប់រឿងរ៉ាវ (Storytelling) តាមរយៈតួលេខ!
