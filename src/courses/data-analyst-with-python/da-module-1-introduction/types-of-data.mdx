## 🌐 សេចក្តីផ្តើម (Overview)

មុននឹងអ្នកអាចវិភាគទិន្នន័យ អ្នកត្រូវដឹងសិនថាទិន្នន័យនោះមានមុខមាត់បែបណា! នៅក្នុងពិភពបច្ចេកវិទ្យា ទិន្នន័យមិនមែនមានត្រឹមតែក្នុងតារាង Excel នោះទេ។ វាត្រូវបានបែងចែកជា ៣ ប្រភេទធំៗ ផ្អែកលើ "របៀបរៀបរយ" របស់វា។

---

## 📊 ប្រភេទទាំង ៣ នៃទិន្នន័យ

### ១. ទិន្នន័យមានរចនាសម្ព័ន្ធ (Structured Data)
នេះគឺជាប្រភេទ "កូនសិស្សល្អ" ។ វាមានរបៀបរៀបរយ មានជួរឈរ (Columns) និងជួរដេក (Rows) ច្បាស់លាស់។ វាស្រួលស្វែងរក និងស្រួលវិភាគបំផុត។
- **ឧទាហរណ៍:** តារាងឈ្មោះបុគ្គលិក (មានប្រអប់ ឈ្មោះ, អាយុ, ប្រាក់ខែ), ទិន្នន័យក្នុង Excel, ទិន្នន័យក្នុង SQL Database (MySQL, PostgreSQL)។
- **ឧបករណ៍វិភាគ:** SQL, Pandas, Excel។

```text
| ឈ្មោះ  | អាយុ | ប្រាក់ខែ |
|-------|------|----------|
| សុខ   | 25   | $500     |
| សៅ   | 30   | $800     |
```

### ២. ទិន្នន័យពាក់កណ្តាលរចនាសម្ព័ន្ធ (Semi-structured Data)
វាអត់មានទម្រង់ជាតារាងស្អាតបាតទេ ប៉ុន្តែវាមានរចនាសម្ព័ន្ធផ្ទាល់ខ្លួនតាមរយៈ "ស្លាក (Tags)" ឬ "សោរ (Keys)" ដើម្បីបញ្ជាក់អត្ថន័យ។ វាត្រូវបានគេនិយមប្រើបំផុតពេលបញ្ជូនទិន្នន័យតាមអ៊ីនធឺណិតរវាង App និង Server។
- **ឧទាហរណ៍:** ឯកសារ JSON (ពេញនិយមបំផុតបច្ចុប្បន្ន), XML, HTML។
- **ឧបករណ៍វិភាគ:** MongoDB, Python (Dictionary, JSON module)។

```json
{
  "employee": {
    "name": "សុខ",
    "age": 25,
    "salary": 500
  }
}
```

### ៣. ទិន្នន័យឥតរចនាសម្ព័ន្ធ (Unstructured Data)
នេះគឺជាប្រភេទ "ក្មេងទំនើង"។ វាអត់មានទម្រង់ អត់មានក្បួនខ្នាត អត់មានតារាងទេ។ វាគឺជាទិន្នន័យឆៅៗដែលពិបាកនឹងអោយកុំព្យូទ័រយល់បំផុត ប៉ុន្តែវាមានចំនួនច្រើនបំផុតនៅលើពិភពលោក។
- **ឧទាហរណ៍:** រូបភាព (JPG), វីដេអូ (MP4), សំឡេងកត់ត្រា, អត្ថបទសារ (Emails, Tweets, PDF documents)។
- **ឧបករណ៍វិភាគ:** Machine Learning, Deep Learning (Computer Vision, Natural Language Processing), Data Lakes។

ក្នុងនាមជា **Data Analyst** ការងារប្រចាំថ្ងៃរបស់អ្នកគឺផ្តោតលើ **Structured Data** (៨០%) និង **Semi-structured Data** (២០%) ជាចម្បង។ ចំណែក Unstructured Data ច្រើនតែទុកអោយ Data Scientist ជាអ្នកដោះស្រាយ!
