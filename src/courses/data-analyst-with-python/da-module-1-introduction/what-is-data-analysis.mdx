## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងយុគសម័យឌីជីថល ក្រុមហ៊ុននីមួយៗមានទិន្នន័យរាប់លាន។ ប៉ុន្តែទិន្នន័យទទេរៗ គឺគ្មានប្រយោជន៍ទេ! **Data Analyst (អ្នកវិភាគទិន្នន័យ)** គឺជាអ្នកដែលបំប្លែងទិន្នន័យរញ៉េរញ៉ៃទាំងនោះ ឱ្យទៅជាព័ត៌មានមានប្រយោជន៍ ដើម្បីជួយឱ្យក្រុមហ៊ុនធ្វើការសម្រេចចិត្តបានត្រឹមត្រូវ។ មេរៀននេះនឹងបង្ហាញផ្លូវអ្នកទៅកាន់អាជីពជា Data Analyst។

---

## 📚 រៀនពាក្យបច្ចេកទេស (Definitions)

- **Data Analysis (ការវិភាគទិន្នន័យ):** ដំណើរការនៃការត្រួតពិនិត្យ សម្អាត បំប្លែង និងធ្វើគំរូទិន្នន័យ ដើម្បីរកមើលព័ត៌មានមានប្រយោជន៍ សន្និដ្ឋាន និងគាំទ្រដល់ការសម្រេចចិត្ត។
- **Data Analyst:** បុគ្គលដែលមានជំនាញក្នុងការប្រមូល និងបកស្រាយទិន្នន័យ ដើម្បីដោះស្រាយបញ្ហាអាជីវកម្មជាក់លាក់ណាមួយ។
- **Jupyter Notebook:** កម្មវិធីសរសេរកូដដែលអនុញ្ញាតឱ្យអ្នកដំណើរការកូដ Python ជាកង់ៗ និងមើលលទ្ធផលរួមជាមួយក្រាហ្វិកបានភ្លាមៗ (ពេញនិយមបំផុតសម្រាប់ Data Science)។

## 💡 គំនិតគោល (The Core Idea)

### វដ្តជីវិតនៃការវិភាគទិន្នន័យ (Data Analysis Lifecycle)

ការវិភាគទិន្នន័យមិនមែនគ្រាន់តែជាការអង្គុយសរសេរកូដនោះទេ វាទាមទារនូវលំដាប់លំដោយច្បាស់លាស់៖

1. **Ask (សួរសំណួរ):** តើក្រុមហ៊ុនចង់ដឹងអ្វី? (ឧ. ហេតុអ្វីបានជាអតិថិជនឈប់ទិញឥវ៉ាន់យើងខែនេះ?)
2. **Prepare (ប្រមូលទិន្នន័យ):** ស្វែងរកទិន្នន័យដែលពាក់ព័ន្ធ (ពី Database ឫ ឯកសារ Excel)។
3. **Process (សម្អាតទិន្នន័យ):** កែតម្រូវទិន្នន័យដែលខុសឆ្គង បាត់បង់ ឫស្ទួន (នេះប្រើពេលច្រើនជាងគេ!)។
4. **Analyze (វិភាគ):** ប្រើប្រាស់ស្ថិតិ និងកូដដើម្បីរកមើលលំនាំ (Patterns) និងនិន្នាការ (Trends)។
5. **Share (ចែករំលែក):** បង្កើតតារាង (Dashboards) និងក្រាហ្វិក ដើម្បីបង្ហាញលទ្ធផលទៅកាន់ថ្នាក់ដឹកនាំ។
6. **Act (អនុវត្ត):** ថ្នាក់ដឹកនាំយកលទ្ធផលនោះទៅធ្វើការសម្រេចចិត្ត (ឧ. បញ្ចុះតម្លៃ ឫប្តូរយុទ្ធសាស្ត្រលក់)។
