## 💻 គម្រោង៖ របាយការណ៍បំណុលអតិថិជន

យើងមានតារាង ២ នៅក្នុង Database របស់ធនាគារ៖
1. **`Clients` (ព័ត៌មានអតិថិជន):** `client_id`, `full_name`, `city`
2. **`Loans` (កម្ចី):** `loan_id`, `client_id`, `loan_amount`, `status` (Active ឫ Paid)

ដើម្បីឆ្លើយតបនឹងសំណើរបស់ប្រធាន អ្នកត្រូវសរសេរកូដ SQL ដូចខាងក្រោម៖

```sql
-- ១. ជ្រើសរើស ឈ្មោះ និង បូកសរុបចំនួនប្រាក់កម្ចី (AS តាងឈ្មោះជួរឈរថ្មី)
SELECT 
    C.full_name, 
    SUM(L.loan_amount) AS total_debt
    
-- ២. កំណត់តារាងដើម (Clients) តាងដោយ C
FROM Clients C

-- ៣. ភ្ជាប់ជាមួយតារាងកម្ចី (Loans) តាងដោយ L
JOIN Loans L
    ON C.client_id = L.client_id
    
-- ៤. ច្រោះយកតែកម្ចីណាដែលនៅសកម្ម (មិនទាន់សងអស់)
WHERE L.status = 'Active'

-- ៥. ចងក្រងបូកសរុប តាមឈ្មោះអតិថិជនម្នាក់ៗ
GROUP BY C.full_name

-- ៦. ច្រោះយកតែអ្នកដែលបូកសរុបទៅ ជំពាក់លើសពី ៥ ម៉ឺនដុល្លារ
HAVING SUM(L.loan_amount) > 50000

-- ៧. រៀបលំដាប់ពីធំមកតូច (អ្នកជំពាក់ច្រើននៅលេខ ១)
ORDER BY total_debt DESC

-- ៨. (ជាជម្រើស) បើចង់បានតែ Top 10 អ្នកជំពាក់ធំជាងគេ
LIMIT 10;
```
