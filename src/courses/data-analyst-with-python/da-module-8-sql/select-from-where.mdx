## 🌐 សេចក្តីផ្តើម (Overview)

បើប្រៀបធៀបទៅនឹង Pandas, កូដ SQL មើលទៅស្រឡះភ្នែកជាង និងស្រដៀងទៅនឹងរបៀបដែលយើងនិយាយស្តីប្រចាំថ្ងៃ។ រូបមន្តមន្តអាគមរបស់វាគឺ **SELECT ... FROM ... WHERE ...** ។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

ឧបមាថាយើងមានតារាងឈ្មោះ `Customers` នៅក្នុង Database ដែលមានជួរឈរ: `id`, `name`, `city`, `age`។

### ១. ទាញយកទិន្នន័យទាំងអស់ (The SELECT * Statement)

សញ្ញាផ្កាយ `*` មានន័យថា "អ្វីៗទាំងអស់ (Everything/All Columns)"។

```sql
/* ទាញយកគ្រប់ជួរឈរទាំងអស់ ពីតារាង Customers */
SELECT * 
FROM Customers;
```

### ២. ទាញយកតែជួរឈរដែលត្រូវការ (Selecting Specific Columns)

នៅក្នុងការងារពិត តារាងមួយអាចមាន ១០០ ជួរឈរ។ ការប្រើ `SELECT *` នឹងធ្វើអោយ Database គាំង! យើងគួរយកតែអ្វីដែលយើងចង់វិភាគ។

```sql
/* យកតែឈ្មោះ និងទីក្រុងប៉ុណ្ណោះ (វាដូចគ្នានឹង df[['name', 'city']] របស់ Pandas ដែរ) */
SELECT name, city 
FROM Customers;
```

### ៣. ការច្រោះទិន្នន័យដោយប្រើ WHERE (Filtering Rows)

ចុះបើថៅកែចង់បានតែ "អតិថិជនរស់នៅភ្នំពេញ ដែលមានអាយុលើសពី ១៨ ឆ្នាំ"?

```sql
SELECT name, city, age
FROM Customers
WHERE city = 'Phnom Penh' AND age > 18;
```

**សញ្ញាប្រៀបធៀបក្នុង SQL:**
- `=` ស្មើ (ចំណាំ៖ SQL ប្រើសញ្ញាស្មើតែមួយគត់ មិនមែន `==` ដូច Python ទេ)
- `!=` ឬ `<>` មិនស្មើ
- `>` ធំជាង, `<` តូចជាង
- `>=` ធំជាងឫស្មើ
- `AND`, `OR`, `NOT` ប្រើសម្រាប់លក្ខខណ្ឌច្រើន។

**ឧទាហរណ៍មួយទៀត (រកអតិថិជនដែលមិននៅភ្នំពេញ):**
```sql
SELECT name, city
FROM Customers
WHERE city != 'Phnom Penh';
```

ពាក្យបញ្ជា `SELECT`, `FROM`, និង `WHERE` គឺជា "នំប៉័ង និងប៊័រ (Bread and Butter)" របស់ Data Analyst ក្នុងការទាញទិន្នន័យប្រចាំថ្ងៃ!
