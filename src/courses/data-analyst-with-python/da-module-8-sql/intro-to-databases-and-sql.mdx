## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុង Module មុនៗ យើងប្រើប្រាស់ឯកសារ CSV សម្រាប់រៀន។ ប៉ុន្តែនៅក្នុងក្រុមហ៊ុនពិតប្រាកដ គ្មាននរណារក្សាទុកទិន្នន័យអតិថិជនរាប់លាននាក់នៅក្នុងឯកសារ Excel ឫ CSV នោះទេ (វាអត់សុវត្ថិភាព ហើយបើកអត់ចេញទេព្រោះវាធំពេក)។ 

ពួកគេរក្សាទុកវានៅក្នុង **ប្រព័ន្ធគ្រប់គ្រងទិន្នន័យ (Database)** ដូចជា MySQL, PostgreSQL, ឬ SQL Server។

## 💻 អ្វីទៅជា SQL?

**SQL (Structured Query Language)** អានថា "ស៊ីឃួល (Sequel)" គឺជាភាសាពិសេសមួយ ដែលបង្កើតឡើងដើម្បី "និយាយ" ជាមួយ Database។

ក្នុងនាមជា Data Analyst អ្នកមិនបាច់ចេះសរសេរកូដបង្កើត Database ឫបង្កើត Server អ្វីនោះទេ (នោះជាតួនាទីរបស់ Data Engineer)។ តួនាទីតែមួយគត់របស់អ្នកគឺប្រើ SQL ដើម្បី **ទាញយក (Extract / Query)** ទិន្នន័យចេញពី Database នោះ យកមកវិភាគនៅក្នុង Pandas ឫ Power BI។

### តើទិន្នន័យនៅក្នុង Database មានរាងដូចម្តេច?

វាមានរាងដូចជា "តារាង Excel" អញ្ចឹង (ហៅថា Table)! គ្រាន់តែថានៅក្នុង Database មួយ មានតារាងរាប់រយដែល "ភ្ជាប់គ្នា (Relational)"។
- តារាង `Customers` (ផ្ទុកឈ្មោះ លេខទូរស័ព្ទ)
- តារាង `Orders` (ផ្ទុកទិន្នន័យការទិញ)
- តារាង `Products` (ផ្ទុកឈ្មោះទំនិញ និងតម្លៃ)

### កម្មវិធីសម្រាប់អនុវត្ត (Tools)
ដើម្បីរៀន SQL អ្នកអាចប្រើប្រាស់កម្មវិធីដូចជា **DBeaver** ឫ **pgAdmin**។ ប៉ុន្តែនៅក្នុងវគ្គនេះ យើងនឹងសរសេរកូដ SQL ផ្ទាល់ៗ ដើម្បីទាញទិន្នន័យ។ កូដ SQL គឺស្រួលអានដូចជាភាសាអង់គ្លេសធម្មតាអញ្ចឹង!

ឧទាហរណ៍៖
```sql
-- "សូមយក (SELECT) គ្រប់យ៉ាង (*) ពីតារាង (FROM) អតិថិជន"
SELECT * FROM Customers;
```

ត្រៀមខ្លួនហើយឬនៅ? តោះទៅរៀនពាក្យបញ្ជា (Commands) ដ៏មានឥទ្ធិពលបំផុតទាំង ៤ របស់ SQL នៅមេរៀនបន្ទាប់!
