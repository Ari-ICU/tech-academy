## 🌐 សេចក្តីផ្តើម (Overview)

ទោះបីជាអ្នករៀនជាមួយឯកសារ CSV ច្រើនក៏ដោយ ប៉ុន្តែនៅក្នុងក្រុមហ៊ុនពិតប្រាកដ ទិន្នន័យត្រូវបានរក្សាទុកយ៉ាងសុវត្ថិភាពនៅក្នុង **SQL Databases** ។ មេរៀននេះនឹងបង្ហាញពីរបៀបក្លាយជា "អ្នកបកប្រែ" រវាង Database និង Pandas DataFrame ដើម្បីអ្នកអាចវិភាគទិន្នន័យបាន។

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការតភ្ជាប់ និងអានទិន្នន័យ (Using `sqlite3` and `pandas`)

```python
import sqlite3
import pandas as pd

# ១. បង្កើតការតភ្ជាប់ទៅកាន់ Database (Connection)
conn = sqlite3.connect("company_data.db")

# ២. សរសេរកូដ SQL (Query)
query = """
SELECT customer_id, name, total_spent
FROM customers
WHERE total_spent > 1000
"""

# ៣. ទាញទិន្នន័យចូលមក Pandas DataFrame តែម្តង!
df = pd.read_sql(query, conn)

print(df.head())

# ៤. បិទការតភ្ជាប់ពេលប្រើរួច
conn.close()
```
ជាមួយកូដប៉ុន្មានបន្ទាត់នេះ អ្នកអាចទាញយកទិន្នន័យរាប់លានជួរមកវិភាគដោយប្រើថាមពលរបស់ Pandas បានយ៉ាងងាយស្រួល!
