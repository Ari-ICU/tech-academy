## �� Overview

Large Language Models are the technology behind ChatGPT, Claude, Gemini, and GitHub Copilot. Understanding how they work — not just how to use them — lets you prompt them effectively, understand their limitations, and build applications on top of them.


Large Language Models (LLMs) គឺជាចំណុចសំខាន់នៅក្នុងកម្មវិធីសិក្សានេះ។ វាផ្ដល់នូវបច្ចេកទេសស្នូលសម្រាប់អ្នកដើម្បីពង្រឹងចំណេះដឹង និងការអនុវត្តជាក់ស្ដែង។

## 💡 គំនិតសំខាន់

An LLM is trained on trillions of tokens of text to predict the next word. After seeing enough text, the model develops a rich internal representation of language, facts, reasoning patterns, and code. At inference time, it generates text token by token, sampling from a probability distribution at each step.

The surprising result: a model trained purely to predict the next word becomes capable of translation, summarisation, code generation, and complex reasoning.

## 📖 ការសិក្សាស៊ីជម្រៅ

### Autoregressive Language Modelling

The model learns to maximise:

$$\mathcal{L} = \sum_{t=1}^{T} \log P(x_t \mid x_1, x_2, \ldots, x_{t-1};\, \theta)$$

where $x_1, \ldots, x_T$ are tokens in the training corpus.

### Tokenisation

Text is split into **tokens** — roughly 3/4 of a word on average. `"DataScience"` → `["Data", "Science"]`. Token limits matter: GPT-4 context = 128k tokens ≈ 100,000 words.

### Key LLM Parameters

| Parameter | Effect |
|---|---|
| **Temperature** | Higher = more random/creative; 0 = greedy/deterministic |
| **Top-p (nucleus sampling)** | Sample from smallest set of tokens whose cumulative probability exceeds p |
| **Max tokens** | Maximum length of generated response |
| **System prompt** | Instructions that shape the model's persona and behaviour |

Sentiment: NEGATIVE

## ✅ ចំណុចសំខាន់ៗដែលត្រូវចាំ

LLMs generate text by predicting the next token autoregressively, trained on massive text corpora. **Tokenisation** determines how text is chunked — understanding token counts helps you work within context limits. **Zero-shot** prompting works for simple tasks; **few-shot** examples dramatically improve complex tasks. **Chain-of-thought** prompting elicits step-by-step reasoning. **Temperature** controls randomness — use low values for factual tasks, higher for creative ones. The **system prompt** is the most powerful way to shape model behaviour consistently.
