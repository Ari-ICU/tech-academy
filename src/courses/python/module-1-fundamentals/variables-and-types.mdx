## 🤔 ហេតុអ្វីយើងត្រូវការ Variables?

មុននឹងឈានទៅដល់ការប្រកាស Variable សូមសួរខ្លួនឯងថា តើយើងសរសេរកូដដោយគ្មាន Variables បានដែរឬទេ?
ស្រមៃថាអ្នកសរសេរកម្មវិធីមួយដោយមិនប្រើ Variables៖

```python
print("Sokha")
print("Sokha")
print("Sokha")
print("Sokha")
```

ប្រសិនបើអ្នកចង់ប្តូរឈ្មោះ អ្នកត្រូវតែតាមកែវាគ្រប់បន្ទាត់ទាំងអស់។ 
ប៉ុន្តែប្រសិនបើអ្នកប្រើ Variables៖

```python
name = "Sokha"

print(name)
print(name)
print(name)
print(name)
```

ពេលនេះ ប្រសិនបើអ្នកចង់ប្តូរឈ្មោះ អ្នកគ្រាន់តែកែតែតម្លៃមួយកន្លែង វានឹងធ្វើបច្ចុប្បន្នភាពនៅគ្រប់ទីកន្លែងដែលប្រើប្រាស់វា។

> **Variables ធ្វើឱ្យកូដរបស់អ្នកងាយស្រួលប្រើឡើងវិញ (Reusable) ងាយស្រួលអាន (Readable) និងងាយស្រួលថែរក្សា (Maintainable)។**

---

## 🧠 របៀបដែល Variables រក្សាទុកទិន្នន័យក្នុង Memory

អ្នកទើបចាប់ផ្ដើមរៀនដំបូងភាគច្រើនគិតថា variables **មានផ្ទុក** នូវតម្លៃ (Contain values)។ 
ការគិតបែបនេះមិនត្រឹមត្រូវទាំងស្រុងនោះទេ។ 

គំរូផ្នត់គំនិត (Mental Model) ដ៏ល្អបំផុតគឺ៖

```text
Variable
   │
   ▼
+-------+        +----------------+
| name  | -----> |    "Sokha"     |
+-------+        +----------------+
```

Variable គឺរក្សាទុកត្រឹមតែ **សេចក្តីយោង (Reference)** ទៅកាន់ Object នៅក្នុងអង្គចងចាំ (Memory) ប៉ុណ្ណោះ។
ការយល់ដឹងពីចំណុចនេះ នឹងជួយឱ្យអ្នកងាយស្រួលយល់នៅពេលសិក្សាពី Lists និង Objects នៅពេលក្រោយ។

---

## ⚖️ ការពន្យល់ពីសញ្ញាស្មើ (Assignment Operator)

អ្នកសិក្សាជាច្រើនយល់ច្រឡំអំពីសញ្ញា `=`:

```python
age = 25
```

នៅក្នុង Python កូដនេះ **មិនមែន** មានន័យថា៖
> "age ស្មើនឹង 25"

ប៉ុន្តែវាមានន័យថា៖
> **"សូមយកតម្លៃ `25` ទៅដាក់ចូលក្នុង variable ដែលមានឈ្មោះថា `age`។"**

ការប្រកាសតម្លៃ (Assignment) គឺខុសពីសមីការគណិតវិទ្យា។

---

## 📦 អ្វីៗទាំងអស់នៅក្នុង Python សុទ្ធតែជា Object

ជំនួសឱ្យការគិតត្រឹមតែថាវាជាទិន្នន័យ សូមចាំថាអ្វីៗទាំងអស់នៅក្នុង Python គឺជា **Object**។

- លេខ `10` គឺជា Integer Object។
- អត្ថបទ `"Hello"` គឺជា String Object។
- សូម្បីតែ `True` ក៏ជា Boolean Object ដែរ។

ការយល់ដឹងពីចំណុចនេះ ជួយរៀបចំអ្នកសម្រាប់មេរៀន Object-Oriented Programming (OOP) នាពេលអនាគត។

## 📚 ប្រភេទ Data Types សំខាន់ៗ

នៅទីនេះ គឺជា Data Types ទូទៅដែលអ្នកនឹងជួបប្រទះក្នុង Python៖

| ប្រភេទ (Type) | ឧទាហរណ៍      | អាចកែប្រែបាន (Mutable) |
| -------- | ------------ | ------- |
| int      | `10`           | ❌       |
| float    | `3.14`         | ❌       |
| bool     | `True`         | ❌       |
| str      | `"Hello"`      | ❌       |
| list     | `[1, 2, 3]`    | ✅       |
| tuple    | `(1, 2)`       | ❌       |
| set      | `{1, 2}`       | ✅       |
| dict     | `{"name": "A"}`| ✅       |
| NoneType | `None`         | ❌       |

អ្នកមិនចាំបាច់យល់លម្អិតពីវាទាំងអស់នៅពេលនេះទេ គ្រាន់តែដឹងថាពួកវាមានវត្តមានគឺគ្រប់គ្រាន់ហើយ។

## 🔄 ការពន្យល់ពី Dynamic Typing

ជំនួសឱ្យការពន្យល់ត្រឹមថា "Python កំណត់ប្រភេទដោយស្វ័យប្រវត្តិ" សូមមើលឧទាហរណ៍នេះ៖

```python
age = 20
print(type(age))  # លទ្ធផល: <class 'int'>

age = "Twenty"
print(type(age))  # លទ្ធផល: <class 'str'>
```

នៅពេលឃើញបែបនេះ សិស្សនឹងចាប់អារម្មណ៍ថា៖ 
**Variable តែមួយ អាចចង្អុលទៅកាន់ Data Type ខុសៗគ្នាបានយ៉ាងងាយស្រួល។**

## 📏 ក្បួនក្នុងការដាក់ឈ្មោះ Variables (Naming Convention)

ការដាក់ឈ្មោះ Variables គួរអនុវត្តតាមស្តង់ដារឧស្សាហកម្ម។ Python ណែនាំឱ្យប្រើប្រាស់ទម្រង់ **snake_case** (អក្សរតូចទាំងអស់ ដកឃ្លាដោយសញ្ញា `_`)។

✅ ល្អ
```python
student_name = "Sokha"
total_price = 150.5
```

❌ មិនល្អ
```python
StudentName = "Sokha"  # មិនគួរប្រើ CamelCase
x1 = "Sokha"           # ឈ្មោះមិនច្បាស់លាស់
data123456 = 150.5     # ឈ្មោះគ្មានអត្ថន័យ
```

## 텅 ការពន្យល់ពីប្រភេទ None

វគ្គសិក្សាជាច្រើនតែងរំលងចំណុចនេះ។

```python
user = None
```

**None** មានន័យថា៖
> **"មិនទាន់មានតម្លៃនៅឡើយទេ។"**

វាត្រូវបានប្រើប្រាស់យ៉ាងទូលំទូលាយនៅក្នុងកូដ Python ជាក់ស្តែង។

## 🔒 Mutable ទល់នឹង Immutable (ការណែនាំខ្លីៗ)

អ្នកគួរដឹងថា Data Types ចែកចេញជាពីរក្រុមធំៗ៖

**Immutable (មិនអាចកែប្រែបានបន្ទាប់ពីបង្កើតរួច)**
- `int`, `float`, `bool`, `str`, `tuple`

**Mutable (អាចកែប្រែបាន)**
- `list`, `dict`, `set`

ចំណេះដឹងនេះនឹងមានប្រយោជន៍ខ្លាំងនៅពេលអ្នករៀនដល់មេរៀន List និង Dictionary។

## 🖼️ គំនូសតាងអង្គចងចាំ (Memory Diagram)

មើលឧទាហរណ៍នេះ៖

```python
age = 25
```

នៅក្នុង Memory វាមានដំណើរការបែបនេះ៖

```text
Memory (អង្គចងចាំ)

+-----------+
| 25 (int)  |
+-----------+
      ▲
      │
     age
```

## 👯 ការប្រកាសអថេរច្រើនក្នុងពេលតែមួយ (Multiple Assignment)

នេះគឺជាទម្រង់ដ៏ពេញនិយមមួយនៅក្នុង Python៖

```python
x, y = 10, 20

print(x)
print(y)
```

អ្នកថែមទាំងអាចប្តូរតម្លៃគ្នា (Swap variables) ដោយមិនបាច់ប្រើអថេរទី៣ (Temp) បានយ៉ាងងាយស្រួល៖

```python
x = 10
y = 20

x, y = y, x  # ឥឡូវនេះ x=20 និង y=10
```

## 🛑 អថេរថេរ (Constants)

ទោះបីជា Python មិនមាន Constants ផ្លូវការ (អថេរដែលមិនអាចប្តូរតម្លៃបាន) ក៏ដោយ ក៏មានក្បួនសរសេរដែលអ្នកសរសេរកម្មវិធីតែងអនុវត្ត៖

```python
PI = 3.14159
MAX_USERS = 100
```

ការប្រើប្រាស់ **អក្សរធំទាំងអស់ (Uppercase)** មានន័យថា៖
> **"សូមកុំកែប្រែតម្លៃរបស់វាអី។"**

---

## 🔄 ការបំប្លែងប្រភេទ Data (Type Conversion Preview)

ការបំប្លែង Data Type គឺសំខាន់ណាស់នៅពេលអ្នកធ្វើការជាមួយទិន្នន័យ៖

```python
age = "20"
print(type(age))  # ជាប្រភេទ str

# បំប្លែងពីអត្ថបទ (str) ទៅជាលេខ (int)
age = int(age)
print(type(age))  # ឥឡូវនេះវាជាប្រភេទ int វិញ
```

នេះបញ្ជាក់ពីមូលហេតុដែលយើងចាំបាច់ត្រូវស្វែងយល់ពី Type Conversion នៅក្នុងការងារ Data Science។

## 🌐 ការអនុវត្តជាក់ស្តែង (Real-world Example)

ជំនួសឱ្យការត្រឹមលើកឧទាហរណ៍ជាអថេរតូចៗ តោះមើលឧទាហរណ៍ដែលស្រដៀងទៅនឹងការងារ Data Science កម្រិតខ្ពស់ (ដូចជានៅពេលប្រើ Pandas):

```python
student = {
    "name": "Sokha",
    "age": 20,
    "height": 1.72,
    "passed": True
}
```

នៅក្នុងទិន្នន័យ `student` នេះ រាល់តម្លៃនីមួយៗគឺមាន Data Type ផ្ទាល់ខ្លួនរបស់វា (`str`, `int`, `float`, `bool`)។ នេះជាការរៀបចំផ្លូវឆ្ពោះទៅកាន់ការវិភាគទិន្នន័យ។

## 📝 សំណួរសម្ភាសន៍ទូទៅ (Common Interview Question)

សំណួរ៖ តើកូដខាងក្រោមនេះនឹងបង្ហាញលទ្ធផលអ្វី?

```python
x = 10
y = x
x = 20

print(y)
```

**ចម្លើយ:** `10`

**ហេតុអ្វី?** ពីព្រោះពេលយើងសរសេរ `y = x` យើងបានភ្ជាប់សេចក្តីយោងរបស់ `y` ទៅកាន់តម្លៃ `10` ដែល `x` ធ្លាប់ចង្អុលទៅ។ នៅពេលយើងប្តូរ `x = 20` វាមិនមានផលប៉ះពាល់ដល់សេចក្តីយោងរបស់ `y` ឡើយ។ នេះគឺជាមូលដ្ឋានគ្រឹះនៃរបៀបដែល Memory ដំណើរការក្នុង Python។
