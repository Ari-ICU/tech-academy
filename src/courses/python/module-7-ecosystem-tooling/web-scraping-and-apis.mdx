## 🌐 Overview

កម្មវិធី Python របស់អ្នកប្រៀបបាននឹងខួរក្បាលដ៏ឆ្លាតវៃមួយ ប៉ុន្តែវានៅតែខ្វាក់ និងថ្លង់ ប្រសិនបើវាមិនអាចទាក់ទងជាមួយពិភពខាងក្រៅបាន។ អុីនធឺណិតគឺជាឃ្លាំងទិន្នន័យដ៏ធំបំផុតរបស់មនុស្សជាតិ។
នៅក្នុងមេរៀនចុងក្រោយនេះ យើងនឹងបំពាក់ "ភ្នែក" និង "ត្រចៀក" ដល់កម្មវិធីរបស់អ្នក! យើងនឹងរៀនពីរបៀបនិយាយជាមួយ **APIs** (ភាសាផ្លូវការដែលកុំព្យូទ័រនិយាយគ្នា) និងបច្ចេកទេស **Web Scraping** (ការលួចទាញយកអត្ថបទពីវេបសាយដែលគ្មាន API ឱ្យប្រើប្រាស់)។

## 📚 Definitions

- **API (Application Programming Interface):** ផ្លូវកាត់ដែលវេបសាយបង្កើតឡើងសម្រាប់ឱ្យកម្មវិធីរបស់អ្នកអាចមកទាញយកទិន្នន័យបានដោយស្របច្បាប់ និងមានសណ្តាប់ធ្នាប់ (ភាគច្រើនបញ្ចេញទិន្នន័យជាទម្រង់ JSON)។
- **JSON (JavaScript Object Notation):** ទម្រង់ទិន្នន័យដែលពេញនិយមបំផុតលើអុីនធឺណិត មើលទៅដូចបេះបិទទៅនឹង Python Dictionary (`{"name": "Sok", "age": 20}`)។
- **Web Scraping:** បច្ចេកទេសក្នុងការសរសេរកូដដើម្បីចូលទៅបើកវេបសាយ រួចកាយយកទិន្នន័យ (ដូចជាតម្លៃទូរស័ព្ទ ឬចំណងជើងព័ត៌មាន) ចេញពីកូដ HTML ដោយស្វ័យប្រវត្តិ។
- **`requests`:** បណ្ណាល័យសម្រាប់ហៅទៅកាន់ URL ដើម្បីទាញយកទិន្នន័យ។
- **BeautifulSoup (`bs4`):** បណ្ណាល័យសម្រាប់ជួយស្រាវជ្រាវ និងទាញយកអក្សរចេញពីកូដ HTML យ៉ាងងាយស្រួល។

## 💡 The Core Idea

ស្រមៃថា **អ្នកកំពុងចង់ដឹងតម្លៃមាសប្រចាំថ្ងៃ**។
- **ការប្រើ API:** គឺដូចជាអ្នកខលទូរស័ព្ទទៅសួរធនាគារដោយផ្ទាល់។ បុគ្គលិកធនាគារ (API) នឹងឆ្លើយប្រាប់អ្នកយ៉ាងខ្លីថា "ថ្ងៃនេះមាស ១តម្លឹង តម្លៃ ២៥០០ដុល្លារ" (រហ័ស ស្អាត និងច្បាស់លាស់)។
- **ការធ្វើ Web Scraping:** ឧបមាថាធនាគារអត់មានលេខទូរស័ព្ទទេ។ អ្នកត្រូវតែបើកឡានទៅធនាគារ អានសេចក្តីប្រកាសដែលបិទលើជញ្ជាំងទាំងមូល រួចរកមើលពាក្យ "តម្លៃមាស" ដោយខ្លួនឯង។ (កូដ HTML របស់វេបសាយគឺប្រៀបដូចជាជញ្ជាំងដែលពោរពេញដោយអក្សររញ៉េរញ៉ៃ)។

## 💻 Code Breakdown

ជាដំបូង ត្រូវប្រាកដថាអ្នកបានដំឡើងបណ្ណាល័យទាំងពីរនេះ: 
`pip install requests beautifulsoup4`

### ១. ការទាញយកទិន្នន័យពី API យ៉ាងងាយស្រួល

យើងនឹងប្រើប្រាស់ API ឥតគិតថ្លៃមួយឈ្មោះថា JSONPlaceholder ដែលមានទិន្នន័យ Post ក្លែងក្លាយ។

```python
import requests

# ១. កំណត់ URL របស់ API (Endpoint)
api_url = "https://jsonplaceholder.typicode.com/posts/1"

# ២. ហៅ (GET Request) ទៅកាន់ URL នោះ
print("កំពុងទាក់ទងទៅម៉ាស៊ីនមេ...")
response = requests.get(api_url)

# ៣. ពិនិត្យមើលថាតើជោគជ័យឬអត់ (200 គឺជោគជ័យ)
if response.status_code == 200:
    # ៤. បំប្លែងទិន្នន័យដែលទាញបាន ទៅជា Python Dictionary
    data = response.json()
    
    print("\n--- លទ្ធផលទទួលបាន ---")
    print(f"ចំណងជើង: {data['title']}")
    print(f"ខ្លឹមសារ: {data['body']}")
else:
    print(f"បរាជ័យ! លេខកូដបញ្ហា: {response.status_code}")
```

### ២. ការធ្វើ Web Scraping (ពេលគ្មាន API)

ឧបមាថាអ្នកចង់ទាញយកចំណងជើងព័ត៌មានពីវេបសាយផ្ទាល់ ព្រោះគេមិនមាន API ឱ្យយើងប្រើទេ។ យើងនឹងប្រើ BeautifulSoup ដើម្បីទាញយកវាចេញពីកូដ HTML។

```python
import requests
from bs4 import BeautifulSoup

# ១. គោលដៅ: យកទំព័រ HTML ទាំងមូលពីវេបសាយ Wikipedia (អត្ថបទនិយាយពី Python)
url = "https://en.wikipedia.org/wiki/Python_(programming_language)"
response = requests.get(url)

# ២. បញ្ជូនកូដ HTML ដ៏រញ៉េរញ៉ៃ (response.text) ទៅឱ្យអ្នកឯកទេស BeautifulSoup
# "html.parser" គឺជាវិធីសាស្ត្រក្នុងការអានកូដ
soup = BeautifulSoup(response.text, "html.parser")

# ៣. ប្រើប្រាស់ BeautifulSoup ដើម្បីស្រាវជ្រាវរកអ្វីដែលយើងចង់បាន
# ឧទាហរណ៍: យើងចង់បានចំណងជើងធំបំផុត (h1 tag) ដែលមាន id="firstHeading"
title_element = soup.find("h1", id="firstHeading")
print(f"ចំណងជើងអត្ថបទ: {title_element.text}")

# ឧទាហរណ៍: យើងចង់យកអត្ថបទកថាខណ្ឌ (p tag) ទី១
# (យើងប្រើ find_all ដើម្បីរកគ្រប់ p tag ហើយយកទីតាំងទី២ ព្រោះទី១ជួនកាលជាអក្សរទទេ)
paragraphs = soup.find_all("p")
first_paragraph = paragraphs[1].text
print(f"\nសេចក្តីផ្តើម:\n{first_paragraph}")
```

    url = "https://books.toscrape.com/catalogue/a-light-in-the-attic_1000/index.html"

    # យើងប្រើ Header នេះដើម្បីបន្លំខ្លួនថាជា Browser (Google Chrome) កំពុងបើកធម្មតា។
    headers = {
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.124 Safari/537.36"
    }
    
    try:
        response = requests.get(url, headers=headers)
        soup = BeautifulSoup(response.text, "html.parser")
        
        # ស្វែងរកតម្លៃ តាមរយៈ Class របស់វា (<p class="price_color">£51.77</p>)
        price_tag = soup.find("p", class_="price_color")
        
        if price_tag:
            # លុបសញ្ញាផោន (£) ចេញ រួចប្តូរជាលេខ Float
            price_str = price_tag.text.replace('£', '')
            price = float(price_str)
            
            print(f"តម្លៃសៀវភៅបច្ចុប្បន្នគឺ: £{price}")
            
            # ដាក់លក្ខខណ្ឌបញ្ចុះតម្លៃ
            if price < 40.0:
                print("🚨 ឱកាសល្អ! តម្លៃចុះក្រោម £40 ហើយ! ទិញឥឡូវនេះ!")
                # នៅទីនេះ អ្នកអាចសរសេរកូដផ្ញើសារ (Telegram Bot) ទៅខ្លួនឯងបាន
            else:
                print("តម្លៃនៅថ្លៃនៅឡើយ រង់ចាំបន្តទៀត...")
    except Exception as e:
        print(f"មានបញ្ហា: {e}")

# ដំណើរការកម្មវិធី
check_price()

## ❌ Common Mistakes

- **ធ្វើ Web Scraping លើវេបសាយដែលប្រើ JavaScript ខ្លាំង:** បណ្ណាល័យ `requests` អាចអានបានតែកូដ HTML សុទ្ធប៉ុណ្ណោះ។ បើវេបសាយនោះត្រូវការពេល Load វិលៗ (ប្រើ React/Vue.js) ដើម្បីបង្ហាញទិន្នន័យ នោះ `requests` នឹងទាញបានតែទំព័រទទេស្អាត។ ក្នុងករណីនេះ អ្នកត្រូវប្តូរទៅប្រើបណ្ណាល័យទំនើបៗដូចជា **`Selenium`** ឬ **`Playwright`** ដែលអាចបញ្ជា Browser ផ្ទាល់។
- **មិនព្រមប្រើ `headers` ពេលហៅ Requests:** វេបសាយធំៗ (ដូចជា Amazon ឬ Facebook) មានប្រព័ន្ធការពារ (Anti-bot)។ បើអ្នកហៅ API ដោយមិនដាក់ `User-Agent` ក្នុង Headers គេនឹងដឹងថាអ្នកជា Python Script ហើយ Block ភ្លាម។
- **ពឹងផ្អែកលើ HTML រចនាសម្ព័ន្ធវេបសាយខ្លាំងពេក:** កូដ Web Scraping របស់អ្នកអាចនឹងខូចនៅថ្ងៃស្អែក ប្រសិនបើម្ចាស់វេបសាយប្តូរឈ្មោះ Class ឬ Design របស់គេបន្តិចបន្តួច។ ហេតុនេះហើយបានជាគេតែងតែព្យាយាមស្វែងរក API ប្រើជាមុនសិន មុននឹងសម្រេចចិត្តធ្វើ Web Scraping។

## ✅ Key Takeaways

- តែងតែស្វែងរក **API** ជាមុនសិន! វាលឿន ងាយស្រួល ស្របច្បាប់ និងបញ្ចេញទិន្នន័យទម្រង់ **JSON** ដែលកូដ Python (Dictionaries) អានយល់ភ្លាមៗ។
- ប្រើប្រាស់បណ្ណាល័យ **`requests`** ដើម្បីទាក់ទងជាមួយអុីនធឺណិត (GET, POST)។
- បើគ្មាន API ទេ សូមប្រើប្រាស់ **`BeautifulSoup`** ដើម្បីកកាយយកទិន្នន័យចេញពីកូដ HTML (Web Scraping)។
- កុំភ្លេចគោរពក្រមសីលធម៌ដោយកុំទាញយកទិន្នន័យញឹកញាប់ពេក និងដាក់ `User-Agent` ដើម្បីកុំឱ្យគេបិទការភ្ជាប់របស់អ្នក។
