## 🌐 Overview

ទិន្នន័យនៅលើអុីនធឺណិតពោរពេញទៅដោយអត្ថបទរាយប៉ាយ។ តើអ្នកធ្វើដូចម្តេចដើម្បីទាញយកលេខទូរស័ព្ទទាំងអស់ចេញពីអត្ថបទមួយទំព័រ? បើអ្នកប្រើ `.split()` វានឹងស្មុគស្មាញខ្លាំងណាស់! 
ដំណោះស្រាយគឺ **Regular Expressions (Regex)** ដែលជាភាសាពិសេសមួយសម្រាប់ស្វែងរកលំនាំ (Patterns)។ បូករួមជាមួយនឹង **`datetime`** សម្រាប់ការគ្រប់គ្រងកាលបរិច្ឆេទ អ្នកនឹងមានសមត្ថភាពអាចសម្អាត និងវិភាគទិន្នន័យប្រចាំថ្ងៃបានយ៉ាងជំនាញ។

---

## 📚 Definitions

- **Regex (Regular Expression):** ជាភាសា ឬក្បួនច្បាប់សម្រាប់ពណ៌នាពីលំនាំនៃអត្ថបទ (Text Pattern) ឧទាហរណ៍: "លេខ៣ខ្ទង់ ដកឃ្លា លេខ៣ខ្ទង់ទៀត" គឺជាលំនាំនៃលេខទូរស័ព្ទ។
- **`re` module:** ម៉ូឌុលរបស់ Python ដែលអនុញ្ញាតឱ្យយើងប្រើប្រាស់ Regex។
- **`datetime` module:** ម៉ូឌុលសម្រាប់គ្រប់គ្រងកាលបរិច្ឆេទ (ឆ្នាំ-ខែ-ថ្ងៃ) និងម៉ោង (ម៉ោង-នាទី-វិនាទី)។
- **`strftime` (String Format Time):** បំប្លែង Object ពេលវេលា ទៅជាអក្សរស្អាតៗ (ឧ. "12-May-2024")។
- **`strptime` (String Parse Time):** បំប្លែងអក្សរ "12-May-2024" ត្រឡប់ទៅជា Object ពេលវេលាវិញ។

---

## 💡 The Core Idea

ស្រមៃថា **Regex គឺជាឆ្កែហិតក្លិន**។
- អ្នកអាចយកអាវរបស់អ្នកបាត់ខ្លួន (Pattern) ឱ្យឆ្កែហិត។ បន្ទាប់មកឆ្កែនោះនឹងរត់ចូលទៅក្នុងហ្វូងមនុស្សរាប់ពាន់នាក់ (អត្ថបទដ៏វែង) ហើយរកឃើញអ្នកនោះដោយច្បាស់លាស់។ Regex គឺបែបនេះឯង វាអាចរកឃើញអុីមែល ឬលេខទូរស័ព្ទដែលលាក់ខ្លួនក្នុងអត្ថបទរាប់ម៉ឺនពាក្យ ត្រឹមមួយប៉ព្រិចភ្នែក។

ស្រមៃថា **Datetime គឺជាម៉ាស៊ីនពេលវេលា**។
- ពេលវេលាមិនមែនជាលេខធម្មតាទេ។ អ្នកមិនអាចយក ថ្ងៃទី៣១ បូក ១ ស្មើ ថ្ងៃទី៣២ នោះទេ។ `datetime` យល់ដឹងពីប្រតិទិន ឆ្នាំបង្អួច (Leap year) និងម៉ោងសកលយ៉ាងច្បាស់។ ពេលអ្នកប្រាប់វាឱ្យបូក ៣០ថ្ងៃទៅលើថ្ងៃទី ១៥ កុម្ភៈ វានឹងគណនាចេញលទ្ធផលត្រឹមត្រូវជានិច្ច។

## 📖 In Depth

**និមិត្តសញ្ញា Regex ពេញនិយម:**
- `\d`: លេខ (0-9)
- `\w`: អក្សរ លេខ ឬសញ្ញា `_`
- `\s`: ចន្លោះទទេ (Space, Tab, Enter)
- `.`: តួអក្សរណាមួយក៏បាន (លើកលែងតែចុះបន្ទាត់)
- `+`: មាន ១ ឬច្រើនដង (ឧ. `\d+` មានន័យថា លេខមួយខ្ទង់ ឬច្រើនខ្ទង់ជាប់គ្នា)
- `*`: មាន ០ ឬច្រើនដង
- `[]`: ជម្រើស (ឧ. `[aeiou]` គឺស្រៈណាមួយក្នុងចំណោមនេះ)
- `^`: ផ្តើមដោយ... 
- `$`: បញ្ចប់ដោយ...

**ទម្រង់ Datetime ពេញនិយម:**
- `%Y`: ឆ្នាំមាន ៤ ខ្ទង់ (2024)
- `%m`: ខែមាន ២ ខ្ទង់ (01 ដល់ 12)
- `%d`: ថ្ងៃទី (01 ដល់ 31)
- `%H`: ម៉ោងទម្រង់ ២៤ម៉ោង

## 💻 Code Breakdown

```python
# ឧទាហរណ៍ទី១: ការប្រើប្រាស់ Regex ដើម្បីស្វែងរកលេខទូរស័ព្ទ និងអុីមែល
import re

text = "ទាក់ទងមកខ្ញុំតាមលេខ 012-345-678 ឬផ្ញើអុីមែលមក john.doe@example.com ដើម្បីដឹងបន្ថែម។ លេខតេលេក្រាមគឺ 098 765 432។"

# Pattern សម្រាប់លេខទូរស័ព្ទ (ឧ. លេខ៣ខ្ទង់ សញ្ញាដកឬចន្លោះ លេខ៣ខ្ទង់ សញ្ញាដកឬចន្លោះ លេខ៣ខ្ទង់)
# \d{3} មានន័យថា លេខ ៣ ខ្ទង់។ [- ] មានន័យថា សញ្ញាដក ឬចន្លោះទទេ
phone_pattern = r"\d{3}[- ]\d{3}[- ]\d{3}"
phones = re.findall(phone_pattern, text)
print(f"លេខទូរស័ព្ទដែលរកឃើញ: {phones}")

# Pattern សម្រាប់អុីមែល (អក្សរឬលេខ + @ + អក្សរ + . + អក្សរ)
email_pattern = r"[\w\.-]+@[\w\.-]+\.\w+"
emails = re.findall(email_pattern, text)
print(f"អុីមែលដែលរកឃើញ: {emails}")
```
**ការពន្យល់:** ការប្រើប្រាស់អក្សរ `r` នៅពីមុខ String (`r"..."`) ហៅថា Raw String។ វាប្រាប់ Python កុំឱ្យបកប្រែនិមិត្តសញ្ញាពិសេសដូចជា `\n`។ គេតែងតែប្រើវាសម្រាប់ការសរសេរ Regex។

```python
# ឧទាហរណ៍ទី២: ការប្តូរទម្រង់ (Format) ម៉ោង និងកាលបរិច្ឆេទ
from datetime import datetime

# យកម៉ោងបច្ចុប្បន្ន
now = datetime.now()
print(f"Object ម៉ោងដើម: {now}")

# បំប្លែងទៅជាអក្សរ (strftime = string format time)
formatted_date = now.strftime("%d/%m/%Y, ម៉ោង %H:%M:%S")
print(f"ទម្រង់ងាយអាន: {formatted_date}")

# បំប្លែងអក្សរ ត្រឡប់ទៅជា Object ម៉ោងវិញ (strptime = string parse time)
date_string = "25-December-2024"
parsed_date = datetime.strptime(date_string, "%d-%B-%Y")
print(f"ថ្ងៃបុណ្យណូអែលគឺខែទី: {parsed_date.month}")
```

```python
# ឧទាហរណ៍ទី៣: ការគណនាពេលវេលាជាមួយ Timedelta
from datetime import datetime, timedelta

today = datetime.now()
print(f"ថ្ងៃនេះ: {today.strftime('%Y-%m-%d')}")

# បង្កើតរយៈពេល ៧ ថ្ងៃ
one_week = timedelta(days=7)

# គណនាថ្ងៃអនាគត និងថ្ងៃអតីតកាល
next_week = today + one_week
last_week = today - one_week

print(f"សប្តាហ៍ក្រោយ: {next_week.strftime('%Y-%m-%d')}")
print(f"សប្តាហ៍មុន: {last_week.strftime('%Y-%m-%d')}")

# រកចំនួនថ្ងៃរវាងកាលបរិច្ឆេទពីរ
new_year = datetime(today.year + 1, 1, 1) # ថ្ងៃទី 1 ខែ 1 ឆ្នាំក្រោយ
days_left = (new_year - today).days
print(f"សល់ {days_left} ថ្ងៃទៀតទើបចូលឆ្នាំសកល!")
```

## 🌐 ការអនុវត្តជាក់ស្តែង (Real-world Application)

**ការសម្អាតទិន្នន័យកាលបរិច្ឆេទ (Data Cleaning Tool)**

ពេលអ្នកទាញយកទិន្នន័យពីប្រភពផ្សេងៗ ជារឿយៗពួកគេសរសេរកាលបរិច្ឆេទរញ៉េរញ៉ៃ (ឧ. អ្នកខ្លះសរសេរ "2024/05/12", អ្នកខ្លះសរសេរ "12-05-2024")។ យើងអាចប្រើ Regex ដើម្បីរកមើលទម្រង់ រួចប្រើ Datetime ដើម្បីបំប្លែងវាឱ្យទៅជាស្តង់ដារតែមួយ៖

```python
import re
from datetime import datetime

def standardize_dates(date_list):
    standardized = []
    
    # ស្វែងរកទម្រង់ YYYY/MM/DD ឬ YYYY-MM-DD
    pattern_ymd = r"^(\d{4})[/-](\d{2})[/-](\d{2})$"
    # ស្វែងរកទម្រង់ DD/MM/YYYY ឬ DD-MM-YYYY
    pattern_dmy = r"^(\d{2})[/-](\d{2})[/-](\d{4})$"

    for dt_str in date_list:
        if re.match(pattern_ymd, dt_str):
            # បើត្រូវនឹងទម្រង់ YYYY/MM/DD
            dt_obj = datetime.strptime(dt_str.replace('/', '-'), "%Y-%m-%d")
        elif re.match(pattern_dmy, dt_str):
            # បើត្រូវនឹងទម្រង់ DD/MM/YYYY
            dt_obj = datetime.strptime(dt_str.replace('/', '-'), "%d-%m-%Y")
        else:
            print(f"មិនស្គាល់ទម្រង់: {dt_str}")
            continue
            
        # បំប្លែងទៅជាស្តង់ដារតែមួយ ISO (YYYY-MM-DD)
        standardized.append(dt_obj.strftime("%Y-%m-%d"))
        
    return standardized

# សាកល្បង
messy_dates = ["2024/11/25", "15-08-2023", "2022-01-05", "30/12/2024", "ថ្ងៃស្អែក"]
clean_dates = standardize_dates(messy_dates)
print(f"ទិន្នន័យដែលបានសម្អាត: {clean_dates}")
```

## ❌ Common Mistakes

- **មិនព្រមប្រើប្រាស់ Raw String (`r"..."`) សម្រាប់ Regex:** បើអ្នកសរសេរ `pattern = "\n"` Python នឹងគិតថាវាជាការចុះបន្ទាត់។ តែបើអ្នកសរសេរ `r"\n"` Python នឹងរក្សាវាជាតួអក្សរ `\` និង `n` សម្រាប់ឱ្យ Regex ស្វែងរក។
- **ច្រឡំ `strftime` និង `strptime`:** 
  - `strftime` គឺ Object -> String (Format ឱ្យស្អាត)
  - `strptime` គឺ String -> Object (Parse ដើម្បីយកទៅគណនា)
- **Regex ស្មុគស្មាញពេក (Regex Soup):** ពេលខ្លះការសរសេរ Regex វែងពេក ធ្វើឱ្យអ្នកផ្សេង (ឬសូម្បីតែអ្នកខ្លួនឯងនៅ១ខែក្រោយ) មើលលែងយល់។ បើអាច គួរបំបែក Regex ជាចំណែកតូចៗ ឬប្រើ String methods ធម្មតា (`.startswith()`, `.endswith()`) បើសិនជាកិច្ចការនោះសាមញ្ញ។

---

## ✅ Key Takeaways

- **Regex (ម៉ូឌុល `re`)** ជាឧបករណ៍ដ៏អស្ចារ្យសម្រាប់ការស្វែងរកលំនាំ (Pattern matching) និងការទាញយកទិន្នន័យដែលលាក់ខ្លួននៅក្នុងអត្ថបទវែងៗ។
- ប្រើប្រាស់ **Raw Strings (`r""`)** ជានិច្ចនៅពេលសរសេរ Regex ដើម្បីជៀសវាងបញ្ហា Escape characters។
- ប្រើម៉ូឌុល **`datetime`** ដើម្បីគ្រប់គ្រង និងគណនាពេលវេលាឱ្យបានត្រឹមត្រូវ ជាជាងការតអក្សរដោយខ្លួនឯង។
- ប្រើ **`timedelta`** នៅពេលអ្នកចង់បូកឬដករយៈពេលពីកាលបរិច្ឆេទណាមួយ។
