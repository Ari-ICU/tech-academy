## 🌐 Overview

តើអ្នកធ្លាប់ឆ្ងល់ទេថា គេធ្វើម៉េចទើបអាចការពារទំព័រវេបសាយ (Webpages) រាប់រយទំព័រមិនឱ្យអ្នកអត់មានគណនីចូលមើលបាន ដោយមិនបាច់សរសេរកូដ `if not logged_in` ឡើងវិញរាប់រយដងនោះ?
ចម្លើយគឺ **Decorators**! Decorators គឺជា "សំបកវេចខ្ចប់" ដ៏ឆ្លាតវៃដែលអាចបន្ថែមសមត្ថភាពថ្មី (ដូចជាការឆែកគណនី ឬការវាស់ពេលវេលារត់កូដ) ទៅលើអនុគមន៍ចាស់របស់អ្នកដោយគ្រាន់តែប្រើសញ្ញា `@` មួយតួ។ ដើម្បីយល់ពី Decorators យើងត្រូវយល់ពីអាថ៌កំបាំងមួយសិន នោះគឺ **Closures**។

---

## 📚 Definitions

- **First-Class Functions:** ក្នុង Python អនុគមន៍ គឺជាវត្ថុ (Objects) ដូចជាលេខ ឬអក្សរដែរ។ យើងអាចផ្ញើវាទៅអនុគមន៍ផ្សេង ឬប្រគល់វាចេញមកវិញ (Return) ក៏បាន។
- **Higher-Order Function:** អនុគមន៍ដែលទទួលយកអនុគមន៍មួយទៀតជា Argument ឬប្រគល់អនុគមន៍ចេញមកវិញ។
- **Closure (ក្លូស័រ):** ជាអនុគមន៍ខាងក្នុង ដែល "ចងចាំ" និងមានសិទ្ធិប្រើប្រាស់អថេរពីអនុគមន៍ខាងក្រៅ ទោះបីជាអនុគមន៍ខាងក្រៅនោះបានបញ្ចប់ការងារទៅហើយក្តី។
- **Decorator:** ជា Higher-Order Function ដែលទទួលយកអនុគមន៍មួយមកវេចខ្ចប់ បន្ថែមមុខងារថ្មី រួចប្រគល់អនុគមន៍នោះត្រឡប់ទៅវិញ។ យើងតែងប្រើសញ្ញា `@` ដើម្បីហៅវា។

---

## 💡 The Core Idea

ស្រមៃថាអ្នកមាន **កាដូមួយ (អនុគមន៍ដើម)**។
- **Higher-Order Function:** គឺដូចជាសេវាកម្មវេចខ្ចប់កាដូ។ គេយកកាដូរបស់អ្នកទៅ។
- **Closure:** គឺដូចជាខ្សែបូ ឬប្រអប់ស្អាតៗដែលគេយកមករុំកាដូរបស់អ្នក ដោយរក្សាកាដូនៅខាងក្នុងដដែល។
- **Decorator (`@`):** គឺជាស្ទីកឃ័រដែលអ្នកបិទពីលើកាដូ ដើម្បីប្រាប់ជាងវេចខ្ចប់ថា "ជួយរុំកាដូនេះឱ្យស្អាតផង មុននឹងប្រគល់ឱ្យខ្ញុំវិញ"។ នៅទីបំផុត អ្នកទទួលបានកាដូដដែល ប៉ុន្តែមានមុខមាត់ស្អាតជាងមុន។

---

## 📖 In Depth

**ការយល់ដឹងពី First-Class Functions:**
អ្នកអាចសរសេរ `x = print` រួចហៅ `x("សួស្តី")` បានយ៉ាងធម្មតា ព្រោះ `print` ជាអនុគមន៍ ហើយអនុគមន៍ក៏ជាវត្ថុ!

**របៀបដំណើរការរបស់ Closure:**
1. បង្កើតអនុគមន៍ A (ក្រៅ)។
2. បង្កើតអថេរ `msg` ក្នុងអនុគមន៍ A។
3. បង្កើតអនុគមន៍ B (ក្នុង) នៅក្នុងអនុគមន៍ A។ អនុគមន៍ B ប្រើ `msg` នេះ។
4. អនុគមន៍ A ប្រគល់ (return) អនុគមន៍ B ទាំងមូលចេញមកក្រៅ។
5. ពេលអ្នកហៅ B នៅខាងក្រៅ វាមានសមត្ថភាពអាន `msg` បាន ទោះបីជា A បានស្លាប់បាត់ទៅហើយក៏ដោយ!

```python
# ឧទាហរណ៍ទី១: Closure (ការចងចាំទិន្នន័យ)
def multiplier_maker(n):
    # អថេរ 'n' ស្ថិតក្នុងបរិស្ថានរបស់ multiplier_maker
    
    def multiplier(x):
        # អនុគមន៍ខាងក្នុងនេះប្រើប្រាស់ 'n' (នេះហៅថា Closure)
        return x * n
        
    # ប្រគល់អនុគមន៍ខាងក្នុងចេញទៅក្រៅ
    return multiplier

# បង្កើតអនុគមន៍ថ្មីដែលគុណនឹង 3 (n=3 ត្រូវបានចងចាំក្នុង memory)
times_three = multiplier_maker(3)

print(times_three(10)) # លទ្ធផល: 30
print(times_three(5))  # លទ្ធផល: 15
```

# ឧទាហរណ៍ទី២: ការបង្កើត Decorator ដោយខ្លួនឯង
# Decorator ជាអនុគមន៍ដែលទទួលយកអនុគមន៍ផ្សេង (func) ជា Argument
def my_custom_decorator(func):
    # បង្កើតអនុគមន៍វេចខ្ចប់ (wrapper) នៅខាងក្នុង
    def wrapper():
        print("១. កំពុងរៀបចំអ្វីៗមុនពេលអនុគមន៍ដើមដំណើរការ...")

    return wrapper # ប្រគល់អនុគមន៍វេចខ្ចប់ត្រឡប់ទៅវិញ

# របៀបប្រើប្រាស់ Decorator (ប្រើសញ្ញា @)
@my_custom_decorator

```python
# ឧទាហរណ៍ទី៣: Decorator ដែលមាន Arguments (ការប្រើ *args, **kwargs)
def timer_decorator(func):
    import time
    
    # ប្រើ *args, **kwargs ដើម្បីឱ្យអាចវេចខ្ចប់អនុគមន៍ដែលមាន parameter ប៉ុន្មានក៏បាន
    def wrapper(*args, **kwargs):
        start_time = time.time()
        
        result = func(*args, **kwargs) # ហៅកូដដើម
        
        end_time = time.time()
        print(f"អនុគមន៍ {func.__name__} ចំណាយពេល {end_time - start_time:.4f} វិនាទី")
        
        return result
        
    return wrapper

@timer_decorator
def calculate_sum(n):
    return sum(range(n))

print(calculate_sum(1000000))
# លទ្ធផលនឹងបង្ហាញតួលេខសរុប ព្រមទាំងពេលវេលាដែលវាចំណាយ!
```

## 🌐 ការអនុវត្តជាក់ស្តែង (Real-world Application)

**ប្រព័ន្ធការពារការទាញយកទិន្នន័យ (Rate Limiter Decorator)**

នៅក្នុង Web Scraping ឬ Data Engineering បើអ្នកហៅ API ញឹកញាប់ពេក (ឧ. 1000 ដងក្នុងមួយវិនាទី) គេនឹង Block IP របស់អ្នក។ យើងអាចប្រើ Decorator ដើម្បីបង្អង់កូដដោយស្វ័យប្រវត្តិ៖

```python
import time

def rate_limiter(delay_seconds):
    """Decorator Factory ដែលអាចទទួល Argument ពីខាងក្រៅបាន"""
    def decorator(func):
        def wrapper(*args, **kwargs):
            print(f"[Rate Limit] រង់ចាំ {delay_seconds} វិនាទីសិន...")
            time.sleep(delay_seconds)
            return func(*args, **kwargs)
        return wrapper
    return decorator

# ប្រើ Decorator ដែលយើងសរសេរ ដោយប្រាប់វាឱ្យចាំ ២វិនាទី រាល់ពេលទាញទិន្នន័យម្តង
@rate_limiter(delay_seconds=2)
def fetch_api_data(url):
    print(f"កំពុងទាញយកទិន្នន័យពី: {url}")
    return {"status": "success", "data": "..."}

# សាកល្បងប្រើ
print("ទាញយកលើកទី១:")
fetch_api_data("api.example.com/users")

print("\nទាញយកលើកទី២:")
fetch_api_data("api.example.com/posts")
```
នេះជាភាពស្រស់ស្អាតនៃ Decorators! កូដ `fetch_api_data` គឺស្រឡះល្អ (គ្មាន `time.sleep()`) ហើយយើងអាចយក `@rate_limiter` ទៅបិទពីលើអនុគមន៍ណាក៏បាន។

## ❌ Common Mistakes

- **ភ្លេច Return អនុគមន៍ `wrapper` ត្រឡប់មកវិញ:**
  ប្រសិនបើអ្នកសរសេរ Decorator ហើយភ្លេចបន្ទាត់ចុងក្រោយ `return wrapper` នោះពេលអ្នកប្រើសញ្ញា `@` អនុគមន៍ដើមរបស់អ្នកនឹងក្លាយជា `None`។
- **ភ្លេចប្រើ `*args` និង `**kwargs` ក្នុង `wrapper`:**
  បើ `wrapper` របស់អ្នកគ្មាន Arguments ទេ `def wrapper():` នោះវាអាចវេចខ្ចប់បានតែអនុគមន៍ដែលអត់មាន Arguments ប៉ុណ្ណោះ។ ដើម្បីឱ្យវាអាចវេចខ្ចប់អនុគមន៍គ្រប់ប្រភេទបាន ត្រូវសរសេរ `def wrapper(*args, **kwargs):` ជានិច្ច។
- **ការបាត់បង់ឈ្មោះអនុគមន៍ដើម (`__name__`):** ពេលវេចខ្ចប់រួច អនុគមន៍ដើមនឹងប្តូរឈ្មោះទៅជា "wrapper"។ បើចង់រក្សាឈ្មោះដើម គេប្រើកូដពិសេសពី standard library គឺ `@wraps(func)` ពីម៉ូឌុល `functools`។

---

## ✅ Key Takeaways

- **Closures** គឺជាអនុគមន៍ដែលចងចាំតម្លៃអថេរ ទោះបីជាអ្នកបង្កើតវាបានចាកចេញក៏ដោយ។
- **Decorators** គឺជា Higher-Order Functions ដែលយកអនុគមន៍មួយមកវេចខ្ចប់ ដើម្បីបន្ថែមមុខងារ ដោយមិនបាច់កែប្រែកូដដើម។
- និមិត្តសញ្ញា **`@decorator_name`** គ្រាន់តែជាការសរសេរកាត់ ជំនួសឱ្យការសរសេរ `my_func = decorator_name(my_func)`។
- ប្រើប្រាស់ `*args, **kwargs` នៅក្នុង `wrapper` function ជានិច្ច ដើម្បីឱ្យ Decorator របស់អ្នកអាចប្រើបានជាមួយអនុគមន៍គ្រប់ប្រភេទ។
