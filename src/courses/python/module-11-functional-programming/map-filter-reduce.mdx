## 🌐 Overview

តើអ្នកធ្លាប់ធុញទ្រាន់នឹងការសរសេរ `for loop` វែងៗគ្រាន់តែដើម្បីគុណលេខទាំងអស់នឹង ២ ដែរឬទេ? នៅក្នុងពិភពនៃការសរសេរកម្មវិធី មានសាលាគំនិតមួយហៅថា **Functional Programming** ដែលលើកទឹកចិត្តឱ្យយើងប្រើប្រាស់កូដដែលខ្លី និងផ្តោតលើ "អ្វីដែលត្រូវធ្វើ" ជាជាង "របៀបធ្វើ"។
អនុគមន៍ ៣ យ៉ាងគឺ `map()`, `filter()`, និង `reduce()` គឺជាតារាឆ្នើមនៃសាលាគំនិតនេះ។ ពួកវាអនុញ្ញាតឱ្យអ្នកធ្វើការផ្លាស់ប្តូរ ត្រង និងគណនាទិន្នន័យរាប់ម៉ឺនជួរ ត្រឹមតែកូដមួយបន្ទាត់!

## 📚 Definitions

- **Functional Programming:** ជាទស្សនៈវិជ្ជាសរសេរកូដដែលផ្តោតលើការប្រគល់តម្លៃចេញពីអនុគមន៍ ដោយមិនកែប្រែទិន្នន័យដើម (No Side Effects)។
- **`map(function, iterable)`:** អនុវត្តអនុគមន៍មួយ ទៅលើគ្រប់ធាតុទាំងអស់នៅក្នុងបញ្ជី ហើយប្រគល់បញ្ជីថ្មីត្រឡប់មកវិញ។
- **`filter(function, iterable)`:** ប្រើអនុគមន៍ដែលប្រគល់តម្លៃ True/False ដើម្បីត្រងយកតែធាតុណាដែលត្រូវនឹងលក្ខខណ្ឌ។
- **`reduce(function, iterable)`:** ប្រើអនុគមន៍ (ដែលទទួល Arguments ២) ដើម្បីផ្គួបធាតុពីឆ្វេងទៅស្តាំ រហូតសល់តម្លៃតែមួយ។ ត្រូវទាញយកពី `functools`។

---

## 💡 The Core Idea

ស្រមៃថាអ្នកមាន **កន្ត្រកផ្លែប៉ោម១០០ផ្លែ** (List of data):
- **`map` គឺដូចជាម៉ាស៊ីនកាត់:** វាយកផ្លែប៉ោមទាំង១០០ ឆ្លងកាត់ម៉ាស៊ីន ហើយអ្នកទទួលបាន **ចំណិតផ្លែប៉ោមចំនួន១០០** (ចំនួននៅដដែល តែទម្រង់ប្តូរ)។
- **`filter` គឺដូចជាម៉ាស៊ីនរែង:** អ្នកចាក់ផ្លែប៉ោមទាំង១០០ ចូលទៅក្នុងរែងដែលតម្រូវឱ្យផ្លែធំទើបធ្លាក់ចូល។ អ្នកទទួលបានត្រឹមតែ **ផ្លែប៉ោមធំៗ ៤០ផ្លែ** (ចំនួនថយចុះ តែទម្រង់នៅដដែល)។
- **`reduce` គឺដូចជាម៉ាស៊ីនកៀបទឹកផ្លែឈើ:** អ្នកដាក់ផ្លែប៉ោមទាំង១០០ចូលម៉ាស៊ីន ហើយនៅទីបំផុតអ្នកទទួលបាន **ទឹកផ្លែប៉ោមមួយកែវធំ** (បង្រួមគ្រប់យ៉ាងទៅជាលទ្ធផលតែមួយ)។

## 📖 In Depth

**ហេតុអ្វីត្រូវប្រើវា? បើអ្នកអាចប្រើ List Comprehension បាន?**
ជាការពិត នៅក្នុងការងារទូទៅ List Comprehension `[x*2 for x in nums]` គឺពេញនិយមជាង `map` ព្រោះវាងាយអានជាង។ ប៉ុន្តែនៅពេលអ្នកប្រើប្រាស់វាជាមួយអនុគមន៍ធំៗដែលសរសេររួចស្រាប់ ឬនៅពេលអ្នកសរសេរកម្មវិធីតាមទម្រង់ Functional សុទ្ធសធ នោះ `map` និង `filter` មានប្រសិទ្ធភាពខ្លាំង (ជាពិសេសប្រើជាមួយ `lambda`)។

ចំណាំសំខាន់: ទាំង `map()` និង `filter()` ប្រគល់លទ្ធផលមកជា **Iterators (Lazy Objects)** មិនមែនជា List ទេ។ អ្នកត្រូវគ្របវាដោយ `list(...)` ទើបអាចមើលឃើញទិន្នន័យពិតប្រាកដ ឬប្រើវាក្នុងការ Loop។

## 💻 Code Breakdown

```python
# ឧទាហរណ៍ទី១: ការប្រើប្រាស់ map() 
names = ["sok", "sao", "mesa"]

# ១. ប្រើប្រាស់អនុគមន៍ធម្មតា
def capitalize_name(name):
    return name.title()

# អនុវត្ត capitalize_name ទៅលើរាល់ឈ្មោះទាំងអស់
formatted_names = list(map(capitalize_name, names))
print(f"Map ជាមួយអនុគមន៍ធម្មតា: {formatted_names}")

# ២. វិធីខ្លីបំផុត (ប្រើរួមជាមួយ Lambda)
# យើងយកឈ្មោះ x នីមួយៗ ទៅប្តូរជាអក្សរធំ
upper_names = list(map(lambda x: x.upper(), names))
print(f"Map ជាមួយ Lambda: {upper_names}")
```
**ការពន្យល់:** បើអ្នកមិនដាក់ `list(...)` ពីមុខ `map` ទេ នោះអ្នកនឹងឃើញត្រឹមតែ `<map object at 0x...>` ព្រោះវាជា Lazy Object ដែលរង់ចាំទាល់តែអ្នកត្រូវការ ទើបវាគណនាឱ្យ។

```python
# ឧទាហរណ៍ទី២: ការប្រើប្រាស់ filter() 
scores = [45, 90, 32, 85, 77, 21, 100]

# ត្រងយកតែសិស្សដែលប្រឡងជាប់ (ពិន្ទុ >= 50)
# filter នឹងទុកតែលេខណាដែលធ្វើឱ្យ lambda ក្លាយជា True ប៉ុណ្ណោះ
passed_scores = list(filter(lambda x: x >= 50, scores))

print(f"ពិន្ទុដើម: {scores}")
print(f"អ្នកប្រឡងជាប់: {passed_scores}")
```

```python
# ឧទាហរណ៍ទី៣: ការប្រើប្រាស់ reduce()
from functools import reduce

prices = [10, 20, 30, 40]

# គណនាតម្លៃសរុប (Sum)
# ដំណើរការ: 
# ១. យក 10+20=30
# ២. យក 30(លទ្ធផល) + 30=60
# ៣. យក 60(លទ្ធផល) + 40=100
total_price = reduce(lambda a, b: a + b, prices)

print(f"តម្លៃទំនិញទាំងអស់គឺ: ${total_price}")

# គណនាតម្លៃធំបំផុត (Max) ដោយមិនប្រើអនុគមន៍ max()
highest_price = reduce(lambda a, b: a if a > b else b, prices)
print(f"ទំនិញថ្លៃជាងគេមានតម្លៃ: ${highest_price}")
```

## 🌐 ការអនុវត្តជាក់ស្តែង (Real-world Application)

**ការសម្អាត និងគណនាទិន្នន័យបុគ្គលិក (Data Processing Pipeline)**

នៅក្នុងគម្រោងពិត យើងតែងតែផ្សំ `filter`, `map`, និង `reduce` បញ្ចូលគ្នាដើម្បីបង្កើតជាខ្សែសង្វាក់ (Pipeline) ដំណើរការទិន្នន័យ។

```python
from functools import reduce

# ទិន្នន័យបុគ្គលិក (ឈ្មោះ, អាយុ, ប្រាក់ខែ)
employees = [
    {"name": "Sok", "age": 25, "salary": 300},
    {"name": "Sao", "age": 18, "salary": 200},
    {"name": "Mesa", "age": 30, "salary": 500},
    {"name": "Bopha", "age": 22, "salary": 250}
]

# គោលដៅ: រកប្រាក់ខែសរុប របស់បុគ្គលិកដែលអាយុចាប់ពី ២២ ឆ្នាំឡើងទៅ

# ជំហានទី១: ត្រងយកតែបុគ្គលិកអាយុ >= 22 (ប្រើ filter)
adults = filter(lambda emp: emp['age'] >= 22, employees)

# ជំហានទី២: ទាញយកតែតួលេខប្រាក់ខែ (ប្រើ map)
salaries = map(lambda emp: emp['salary'], adults)

# ជំហានទី៣: បូកសរុបប្រាក់ខែទាំងអស់ (ប្រើ reduce)
total_expense = reduce(lambda a, b: a + b, salaries)

print(f"ការចំណាយលើប្រាក់ខែសរុបសម្រាប់បុគ្គលិកពេញវ័យគឺ: ${total_expense}")
```

## ❌ Common Mistakes

- **ភ្លេចប្រើ `list()` គ្របពីលើ `map` ឬ `filter`:** ពេលសរសេរ `result = map(len, ["A", "BB"])` រួច `print(result)` អ្នកនឹងមិនឃើញ `[1, 2]` ទេ តែឃើញ `<map object...>`។ ត្រូវចាំថា `map` និង `filter` ត្រឡប់មកវិញជា Iterators។
- **ព្យាយាមប្រើ `reduce` ដោយមិនបាន Import:** ក្នុង Python 2 វាមានស្រាប់ តែ Python 3 តម្រូវឱ្យសរសេរ `from functools import reduce` ជានិច្ច មុននឹងប្រើ។
- **សរសេរ Lambda ស្មុគស្មាញពេកនៅក្នុង `map/filter`:** បើកូដក្នុង Lambda របស់អ្នកមានការប្រៀបធៀបវែងឆ្ងាយ អ្នកគួរបង្កើតវាជាអនុគមន៍ `def` ធម្មតាវិញ ដើម្បីឱ្យងាយស្រួលអាន (Code Readability)។

---

## ✅ Key Takeaways

- ប្រើ **`map(func, list)`** ដើម្បីកែប្រែទិន្នន័យគ្រប់ធាតុនៅក្នុង List។
- ប្រើ **`filter(func, list)`** ដើម្បីលុបចោលទិន្នន័យដែលមិនស្របតាមលក្ខខណ្ឌ។
- ប្រើ **`reduce(func, list)`** ពី `functools` ដើម្បីបូកបញ្ចូល ឬបង្រួមទិន្នន័យទាំងមូលទៅជាតម្លៃតែមួយ។
- បច្ចេកទេសទាំង៣នេះ តែងតែត្រូវបានប្រើប្រាស់រួមគ្នាជាមួយអនុគមន៍អនាមិក (Lambda Functions) ដើម្បីសរសេរកូដមួយបន្ទាត់ដ៏មានអានុភាព។
