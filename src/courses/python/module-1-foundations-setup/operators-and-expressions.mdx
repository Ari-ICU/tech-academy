## 🎯 ហេតុអ្វីយើងត្រូវការ Operators?

បើគ្មាន Variables កម្មវិធីមិនអាចចងចាំអ្វីបានទេ។
ចំណែកឯបើគ្មាន **Operators** វិញ កម្មវិធីមិនអាចធ្វើការសម្រេចចិត្ត ឬគណនាអ្វីបានឡើយ!

Operators គឺជា "ម៉ាស៊ីន" ដែលបង្កើតទិន្នន័យថ្មីចេញពីទិន្នន័យចាស់៖
* **ម៉ាស៊ីនគិតលេខ** ត្រូវការ `+`, `-`, `*`, `/`

ជារួម Operators គឺជាកិរិយាសព្ទនៃភាសាកម្មវិធី (The Verbs of Programming)។

## 🧠 គ្រប់ Expressions តែងតែផ្តល់តម្លៃមួយ (Everything Produces a Value)

ចំណុចដ៏សំខាន់បំផុតដែលអ្នកត្រូវយល់ដឹងពីដំបូងគឺ៖
**រាល់ Expression (កន្សោម) ទាំងអស់ ទីបំផុតនឹងក្លាយទៅជាតម្លៃតែមួយ (One Value)។**

ឧទាហរណ៍៖
```python
5 + 3
```
↓
```text
8
```
---
```python
10 > 5
```
↓
```text
True
```
---
```python
"Hello" + " Python"
```
↓
```text
Hello Python
```
---
សូម្បីតែ៖
```python
True and False
```
↓
```text
False
```

ការសរសេរកម្មវិធី ភាគច្រើនគឺគ្រាន់តែជាការផ្គុំបញ្ចូលគ្នានូវ Expressions ដើម្បីបង្កើតតម្លៃថ្មីប៉ុណ្ណោះ។

## 🧮 Arithmetic Operators (ប្រមាណវិធីនព្វន្ធ)

ទាំងនេះគឺជាសញ្ញាដែលយើងប្រើប្រាស់សម្រាប់ការគណនាគណិតវិទ្យាធម្មតា៖

| Operator | ឈ្មោះ (Name) | ឧទាហរណ៍ | លទ្ធផល |
|----------|-------------|----------|-------|
| `+` | បូក (Addition) | `5 + 3` | `8` |
| `-` | ដក (Subtraction) | `5 - 3` | `2` |
| `*` | គុណ (Multiplication) | `5 * 3` | `15` |
| `/` | ចែក (Division) | `5 / 2` | `2.5` |
| `//` | ចែកយកលេខគត់ (Floor Division) | `5 // 2` | `2` |
| `%` | ចែកយកសំណល់ (Modulo) | `5 % 2` | `1` |
| `**` | ស្វ័យគុណ (Exponentiation) | `5 ** 2` | `25` |

## ⚖️ Comparison Operators (សញ្ញាប្រៀបធៀប)

ប្រើសម្រាប់ប្រៀបធៀបតម្លៃពីរ។ លទ្ធផលរបស់វាតែងតែជា Boolean (`True` ឬ `False`) ជានិច្ច!

| Operator | អត្ថន័យ | ឧទាហរណ៍ | លទ្ធផល |
|----------|---------|----------|-------|
| `==` | ស្មើគ្នា | `5 == 5` | `True` |
| `!=` | មិនស្មើគ្នា | `5 != 3` | `True` |
| `>` | ធំជាង | `5 > 3` | `True` |
| `<` | តូចជាង | `5 < 3` | `False` |
| `>=` | ធំជាង ឬស្មើ | `5 >= 5` | `True` |
| `<=` | តូចជាង ឬស្មើ | `5 <= 3` | `False` |

---

## 🧠 Logical Operators (តក្កវិជ្ជា)

ប្រើសម្រាប់ភ្ជាប់លក្ខខណ្ឌច្រើនចូលគ្នា។

| Operator | មុខងារ | ឧទាហរណ៍ | លទ្ធផល |
|----------|--------|----------|-------|
| `and` | ពិតលុះត្រាតែពិត **ទាំងពីរ** | `True and False` | `False` |
| `or` | ពិតនៅពេលមានពិត **យ៉ាងហោចណាស់មួយ** | `True or False` | `True` |
| `not` | បញ្ច្រាសការពិត | `not True` | `False` |

## 🥇 Operator Precedence (អាទិភាពនៃការគណនា)

នៅពេលកូដរបស់អ្នកមានសញ្ញាច្រើន តើ Python គណនាមួយណាមុន? នេះគឺជាលំដាប់អាទិភាព (ពីខ្ពស់មកទាប)៖

1. `()` - វង់ក្រចក (Parentheses) តែងតែគណនាមុនគេ!
2. `**` - ស្វ័យគុណ (Exponentiation)
3. `*`, `/`, `//`, `%` - គុណ ចែក និងសំណល់
4. `+`, `-` - បូក និងដក
5. `<`, `<=`, `>`, `>=`, `==`, `!=` - ការប្រៀបធៀប
6. `not`, `and`, `or` - តក្កវិជ្ជា

**ឧទាហរណ៍៖**
```python
5 + 3 * 2
```
**ដំណើរការគណនា៖** គុណមានអាទិភាពខ្ពស់ជាងបូក។ ដូច្នេះវាគណនា `3 * 2 = 6` មុន ទើបយកទៅបូកនឹង `5` ស្មើ `11`។

```python
(5 + 3) * 2
```
**ដំណើរការគណនា៖** វង់ក្រចកមានអាទិភាពខ្ពស់បំផុត។ ដូច្នេះវាគណនា `5 + 3 = 8` មុន ទើបយកទៅគុណនឹង `2` ស្មើ `16`។

## ⚖️ Unary ទល់នឹង Binary Operators

អ្នករៀនដំបូងភាគច្រើនគិតថា រាល់ Operator ទាំងអស់តែងតែត្រូវការ Operands (តម្លៃ) ចំនួន ២ ដើម្បីដំណើរការ។

**Binary Operators** (ត្រូវការតម្លៃ ២):
```python
5 + 2
```

**Unary Operators** (ត្រូវការតម្លៃតែ ១ ប៉ុណ្ណោះ):
```python
-5
```
ឬ Logical NOT:
```python
not True
```

ការយល់ដឹងពី Unary Operators នឹងជួយអ្នកឱ្យងាយយល់នៅពេលរៀនដល់លេខអវិជ្ជមាន និងការបញ្ច្រាសតក្កវិជ្ជា (Logical Negation)។

## 🧮 ភាពខុសគ្នារវាងការចែក `//` និង `/` 

អ្នកសិក្សាជាច្រើនតែងឆ្ងល់ថា ហេតុអ្វីបានជា៖
```python
7 / 2
```
↓
```text
3.5
```
ប៉ុន្តែ៖
```python
7 // 2
```
↓
```text
3
```

សូមមើលការពន្យល់ជារូបភាពនេះ៖
```text
7 ÷ 2

ស្មើ 3 សល់ 1

ប្រើប្រាស់ /

↓

3.5

ប្រើប្រាស់ // (យកតែលេខគត់)

↓

3
```

## 🔄 អាថ៌កំបាំងនៃ Modulo (`%`)

Modulo (`%`) សមនឹងទទួលបានការសិក្សាដោយឡែក ព្រោះវាមានប្រយោជន៍ខ្លាំងណាស់។ វាបញ្ចេញនូវ **សំណល់ (Remainder)** នៃការចែក។

**ស្វែងរកលេខគូ (Even number):**
```python
8 % 2
```
↓
```text
0
```

**ស្វែងរកលេខសេស (Odd number):**
```python
7 % 2
```
↓
```text
1
```

**នាឡិកា (Clock):** ម៉ោង ១៥ (រសៀល) ប្រៀបដូចជាម៉ោង ៣
```python
15 % 12
```
↓
```text
3
```

**ហេតុអ្វី Modulo មានវត្តមានគ្រប់ទីកន្លែង?**
ដោយសារតែវាត្រូវបានប្រើសម្រាប់៖
* ប្រតិទិន (Calendars)
* នាឡិកា (Clocks)
* ការបែងចែកទំព័រ (Pagination)
* ក្បួនដោះស្រាយវិលជុំ (Cyclic algorithms)
* ការធ្វើ Hashing (ក្នុង Cybersecurity និង Database)

## 🔗 Chained Comparisons (ការប្រៀបធៀបតភ្ជាប់គ្នា)

Python មានលក្ខណៈពិសេសមួយខុសពីភាសាដទៃទៀត។

ជំនួសឱ្យការសរសេរកូដវែងឆ្ងាយ៖
```python
(age >= 18) and (age <= 60)
```

Python អនុញ្ញាតឱ្យអ្នកសរសេរតភ្ជាប់គ្នាបានយ៉ាងខ្លី៖
```python
18 <= age <= 60
```
នេះធ្វើឱ្យកូដមើលទៅស្រដៀងនឹងគណិតវិទ្យា ដែលអ្នកសរសេរកម្មវិធីគ្រប់រូបសុទ្ធតែចូលចិត្ត។

## 📦 Membership Operators

ដោយសារតែវាជាមូលដ្ឋានគ្រឹះដ៏សំខាន់ យើងសូមណែនាំវាឱ្យអ្នកស្គាល់នៅទីនេះ៖

ពិនិត្យមើលអក្សរក្នុងអត្ថបទ៖
```python
"a" in "apple"
```
↓
```text
True
```

ពិនិត្យមើលលេខក្នុងបញ្ជី៖
```python
3 in [1, 2, 3]
```
↓
```text
True
```

```python
10 not in [1, 2, 3]
```
↓
```text
True
```

Operators ទាំងនេះត្រូវបានប្រើប្រាស់យ៉ាងច្រើនសន្ធឹកសន្ធាប់ក្នុង Data Science និង Web Development។

## 💻 Bitwise Operators (សេចក្តីផ្តើម)

ទោះបីជាអ្នកមិនទាន់ត្រូវប្រើវាស៊ីជម្រៅនៅពេលនេះក៏ដោយ ក៏អ្នកគួរសម្គាល់សញ្ញាទាំងនេះទុក៖

| Operator | អត្ថន័យ |

| `&`        | AND         |

សញ្ញាទាំងនេះភាគច្រើនត្រូវបានប្រើក្នុង Systems Programming, Machine Learning ក្នុងកម្រិតទាប (Low-level), និងការធ្វើឱ្យកូដដើរលឿន (Optimization)។

## ⚖️ ការកំណត់តម្លៃ ទល់នឹង ភាពស្មើគ្នា (Assignment vs Equality)

នេះគឺជាចំណុចដែលអ្នករៀនដំបូងតែងតែយល់ច្រឡំខ្លាំងជាងគេបំផុត!

```python
x = 5
```
មានន័យថា៖ **"សូមរក្សាទុកលេខ 5"**។

ចំណែកឯ៖
```python
x == 5
```
មានន័យថា៖ **"សូមសួរមើលថា តើ x ពិតជាស្មើនឹង 5 ឬអត់?"**។

ត្រូវចងចាំភាពខុសគ្នានេះឱ្យបានច្បាស់។

## 🚀 ការប្រើប្រាស់ Augmented Assignment

ជំនួសឱ្យការប្រើប្រាស់វាដោយមិនដឹងមូលហេតុ អ្នកត្រូវយល់ពីគោលបំណងរបស់វា។

ជំនួសឱ្យការសរសេរ៖
```python
score = score + 10
```

សូមប្រើប្រាស់៖
```python
score += 10
```
វាជួយឱ្យកូដ **ខ្លីជាងមុន (Cleaner)** និង **មានលក្ខណៈជា Python ជាងមុន (More Pythonic)**។

## 🥇 Operator Associativity (ទិសដៅនៃការគណនា)

វគ្គសិក្សាជាច្រើនតែងតែមើលរំលងចំណុចនេះ។

ឧទាហរណ៍៖
```python
20 - 5 - 2
```

Python នឹងគណនាតាមលំដាប់នេះ៖
```text
(20 - 5) - 2
```
↓
```text
13
```

នៅពេលដែល Operators មានអាទិភាព (Precedence) ស្មើគ្នា ដូចជាសញ្ញាដកជាប់ៗគ្នា Python នឹងធ្វើការគណនា **ពីឆ្វេងទៅស្តាំ (Left-to-Right Evaluation)**។

## 🔀 Boolean Truth Tables (តារាងពិត)

ការចងចាំតាមរយៈរូបភាព និងតារាង គឺងាយស្រួលជាង។ (T = True, F = False)

**តារាង AND (ត្រូវតែពិតទាំងសងខាងទើបពិត)**
| A | B | លទ្ធផល |
| - | - | ------ |
| T | T | T      |
| T | F | F      |
| F | T | F      |
| F | F | F      |

**តារាង OR (មានពិតតែមួយ ក៏ចាត់ទុកថាពិត)**
| A | B | លទ្ធផល |
| - | - | ------ |
| T | T | T      |
| T | F | T      |
| F | T | T      |
| F | F | F      |

**តារាង NOT (បញ្ច្រាសការពិត)**
| A | លទ្ធផល |
| - | ------ |
| T | F      |
| F | T      |

## ⚡ ភាពឆ្លាតវៃនៃ Short-Circuit (បន្ថែម)

កាលពីមុនអ្នកបានដឹងពី Short-Circuit ក្នុងការសន្សំពេលវេលា។ ឥឡូវតោះមើលពីរបៀបដែល Programmer ជំនាញៗប្រើប្រាស់វា៖

```python
name = ""

name and print("Hello")
```
**លទ្ធផល៖** គ្មានអ្វីកើតឡើងទេ។ (ព្រោះ `name` ជា Falsy ដូច្នេះ Python ឈប់គណនា `print()`)

```python
name or print("Please enter a name")
```
**លទ្ធផល៖**
```text
Please enter a name
```
(ព្រោះ `name` ជា Falsy ដូច្នេះ Python ត្រូវទៅពិនិត្យមើលផ្នែកខាងស្តាំ ហើយក៏ដំណើរការ `print()`)។ នេះគឺជាទម្លាប់សរសេរកូដមួយ (Python Idiom) ដែលអ្នកតែងតែជួបប្រទះ។

---

## 🧠 `is` ទល់នឹង `==` កម្រិតស៊ីជម្រៅ

ជំនួសឱ្យការពន្យល់ត្រឹមតែ List តោះមើលប្រភេទ Immutable Types៖

```python
x = 10
y = 10

print(x == y) # True
print(x is y) # True (ព្រោះ Python រក្សាទុកលេខតូចៗក្នុង Memory តែមួយ)
```

**ច្បាប់មាសដែលត្រូវចាំ៖**
កុំប្រើ `is` សម្រាប់ប្រៀបធៀបតួលេខ (Numbers) ឬអត្ថបទ (Strings) ឡើយ។
ត្រូវប្រើ៖
```python
==
```
សូមរក្សាទុក៖
```python
is
```
ជាពិសេសសម្រាប់ប្រើជាមួយ៖
```python
None
```
ឧទាហរណ៍៖
```python
if user is None:
```

## ⚠️ បម្រាមដ៏សំខាន់មួយ (Important Warning)

ចូរកុំប្រៀបធៀបលេខទសភាគ (Floating-point) ដោយផ្ទាល់!

សាកល្បងរត់កូដនេះ៖
```python
0.1 + 0.2 == 0.3
```

លទ្ធផល៖
```text
False
```

វានឹងធ្វើឱ្យអ្នករៀនដំបូងភ្ញាក់ផ្អើលជាខ្លាំង! នេះគឺជាការបើកទ្វារឆ្ពោះទៅកាន់ការពិភាក្សាអំពី ភាពជាក់លាក់នៃ Floating-Point (Floating-point precision) ដែលយើងនឹងជួបគ្នានៅមេរៀនក្រោយៗទៀត។

## 📊 តារាងសេចក្តីសង្ខេប (Summary Table)

| ប្រភេទ Operator | ឧទាហរណ៍ | មុខងារ |
|--------|---------|---------|
| Arithmetic | `+`, `-`, `*`, `/`, `//`, `%`, `**` | ធ្វើការគណនាគណិតវិទ្យា |
| Comparison | `==`, `!=`, `>`, `<`, `>=`, `<=` | ប្រៀបធៀបតម្លៃ បញ្ចេញ `True` ឬ `False` |
| Identity | `is`, `is not` | ពិនិត្យមើលអត្តសញ្ញាណនៅក្នុង Memory |
| Logical | `and`, `or`, `not` | ភ្ជាប់លក្ខខណ្ឌច្រើនចូលគ្នា |
| Assignment | `=`, `+=`, `-=`, `*=`, `/=` | រក្សាទុក ឬធ្វើបច្ចុប្បន្នភាពតម្លៃ |
| Membership | `in`, `not in` | ពិនិត្យមើលវត្តមាននៃទិន្នន័យណាមួយ |
