## 🌐 សេចក្តីផ្តើម (Overview)

ហេតុអ្វីបានជាមេរៀនខ្លះគេប្រាប់ថា Algorithm មួយនេះល្អជាងមួយនោះ? ចម្លើយគឺស្ថិតនៅលើ "ល្បឿននៃការកើនឡើង" (Growth Rate)។ ការដាក់ក្រាហ្វិក២ ប្រកួតគ្នាលើផ្ទាំងតែមួយ ជួយអោយយើងមើលឃើញភាពខុសគ្នានេះយ៉ាងច្បាស់។

## 💻 ការបំបែកកូដ (Code Breakdown)

តោះប្រកួតគ្នារវាង Linear ($y = x$) និង Quadratic ($y = x^2$) ចន្លោះពី ០ ដល់ ២០។

```python
import numpy as np
import matplotlib.pyplot as plt

# បង្កើតចំណុចពី 0 ដល់ 20
x = np.linspace(0, 20, 100)

# អនុគមន៍ទី ១ (Linear)
y1 = x 

# អនុគមន៍ទី ២ (Quadratic)
y2 = x ** 2 

# គូរវានៅលើផ្ទាំងតែមួយ
plt.plot(x, y1, label="y = x (កំណើនថេរ)", color="blue")
plt.plot(x, y2, label="y = x^2 (កំណើនលឿន)", color="red")

# ដាក់ពត៌មានលម្អិត
plt.title("ការប្រៀបធៀបល្បឿនកំណើន")
plt.xlabel("ចំនួនទិន្នន័យ (x)")
plt.ylabel("ពេលវេលាដំណើរការ (y)")

# បង្ហាញប្រអប់ចំណាំ (Legend) ដើម្បីប្រាប់ថាពណ៌ណាជារបស់អ្នកណា
plt.legend()
plt.grid(True)
plt.show()
```

អ្នកនឹងឃើញថា ក្រាហ្វិកពណ៌ក្រហម ($y=x^2$) ស្ទុះឡើងទៅលើលឿនជាងពណ៌ខៀវឆ្ងាយណាស់។ នេះជាមូលហេតុដែលយើងតែងតែព្យាយាមសរសេរកូដអោយដើរតាមកំណើន Linear ជៀសវាងកំណើន Quadratic នៅក្នុងសៀវភៅ Computer Science!
