## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងគណិតវិទ្យា ក្រាហ្វិកមិនមែនគ្រាន់តែជាគំនូរទេ វាគឺជារូបភាពតំណាងឱ្យទិន្នន័យពិតប្រាកដ។ តើអ្នកនៅចាំម៉ោងរៀនគូរក្រាហ្វិកប៉ារ៉ាបូល ($y = x^2$) ដែលអ្នកត្រូវគូសតារាងតម្លៃ $x$ និង $y$ រួចចុចចំណុចម្តងមួយៗនៅលើក្រដាសទេ? ឥឡូវនេះ Python អាចធ្វើវាបានក្នុងរយៈពេលតិចជាង ១ វិនាទី!

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការបង្កើត "តារាងតម្លៃ" ជាមួយ NumPy

មុននឹងគូរ យើងត្រូវការចំណុចជាច្រើន (Points)។ `np.linspace` ជួយបង្កើតចំណុចទាំងនោះដោយស្វ័យប្រវត្តិ។

```python
import numpy as np

# បង្កើតចំណុច x ចំនួន ១០០ គ្រាប់ ចន្លោះពី -5 ទៅ 5
x = np.linspace(-5, 5, 100)

# គណនា y សម្រាប់គ្រប់ចំណុច x ទាំងអស់ (ដោយស្វ័យប្រវត្តិ)
y = x ** 2
```

### ២. ការគូរខ្សែកោងជាមួយ Matplotlib

```python
import matplotlib.pyplot as plt

# បញ្ជាអោយគូរចំណុច (x, y) ភ្ជាប់គ្នា
plt.plot(x, y)

# ដាក់ចំណងជើង
plt.title("ក្រាហ្វិកប៉ារ៉ាបូល y = x^2")
plt.xlabel("អ័ក្ស X")
plt.ylabel("អ័ក្ស Y")

# បង្ហាញក្រាហ្វិក
plt.grid(True) # ដាក់ក្រឡា
plt.show()
```
