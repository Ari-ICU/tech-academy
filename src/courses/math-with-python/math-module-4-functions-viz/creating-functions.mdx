## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងគណិតវិទ្យា ពេលយើងមានរូបមន្ត $f(x) = x^2$ យើងអាចជំនួសលេខចូលបានគ្រប់ពេល ដូចជា $f(2)=4, f(5)=25$។ នៅក្នុងការសរសេរកូដ យើងក៏មិនចង់សរសេររូបមន្ត $x^2$ ដដែលៗរាល់ដងដែលយើងចង់គណនាវាដែរ។ នោះហើយជាពេលដែល `def` ចូលមកដើរតួ!

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការបង្កើត Function សាមញ្ញ (Linear)

ឧបមាថាយើងចង់បង្កើតអនុគមន៍គណនាប្រាក់ខែសរុប (ប្រាក់ខែគោល $500$ បូកប្រាក់ថែមម៉ោង $10$ ក្នុងមួយម៉ោង):
$$ f(x) = 10x + 500 $$

```python
# បង្កើតអនុគមន៍ឈ្មោះ calculate_salary ដោយទទួលអថេរ x (ចំនួនម៉ោង)
def calculate_salary(x):
    y = (10 * x) + 500
    return y

# ហៅវាមកប្រើប្រាស់
print("បើថែមម៉ោង ២ ម៉ោង:", calculate_salary(2))  # 520
print("បើថែមម៉ោង ១០ ម៉ោង:", calculate_salary(10)) # 600
```

### ២. អនុគមន៍ដែលមានប៉ារ៉ាម៉ែត្រច្រើន (Multiple Variables)

ចុះបើប្រាក់ខែគោលមិនថេរ? គណិតវិទ្យា: $f(x, b) = 10x + b$

```python
def calculate_salary_advanced(x, b):
    return (10 * x) + b

# ប្រាក់ខែគោល 300$, ថែមម៉ោង 5 ម៉ោង
my_salary = calculate_salary_advanced(5, 300)
print("ប្រាក់ខែសរុប:", my_salary) # 350
```

### ៣. អនុគមន៍គណិតវិទ្យាស្មុគស្មាញ (Quadratic)

$$ f(x) = x^2 - 4x + 4 $$

```python
def f(x):
    return (x ** 2) - (4 * x) + 4

print("f(2) = ", f(2)) # 0
```
ការបំប្លែងរូបមន្តទៅជា Function គឺជាជំហានដំបូងមុននឹងយើងអាចគូរវាជាក្រាហ្វិកបាននៅក្នុងមេរៀនបន្ទាប់!
