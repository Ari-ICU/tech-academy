## 🌐 សេចក្តីផ្តើម (Overview)

ស្រមៃថាអ្នកកំពុងបើកឡាន។ "ចម្ងាយ" ដែលអ្នកបើកបាន គឺជាអនុគមន៍ធម្មតា។ ចំណែក "ល្បឿនកុងទ័រឡាន" ដែលប្រែប្រួលគ្រប់វិនាទី នោះហើយគឺជា **ដេរីវេ (Derivative)**។ នៅក្នុង Machine Learning យើងប្រើដេរីវេ ដើម្បីដឹងថាត្រូវកែប្រែទម្ងន់ (Weights) លឿនឫយឺតប៉ុណ្ណា ទើបធ្វើអោយកំហុសថយចុះ។

## 💻 ការបំបែកកូដ (Code Breakdown)

### ការគណនាដេរីវេដោយប្រើ SymPy

ឧបមាថាយើងមានអនុគមន៍ $f(x) = x^3 - 3x^2 + 5$។

```python
import sympy as sp

x = sp.symbols('x')
f = x**3 - 3*x**2 + 5

# ១. គណនាដេរីវេទី ១ (f')
f_prime = sp.diff(f, x)
print("ដេរីវេទី ១ គឺ:", f_prime)
# លទ្ធផល: 3*x**2 - 6*x

# គណនាតម្លៃជម្រាលត្រង់ x = 4
slope_at_4 = f_prime.subs(x, 4)
print("ជម្រាលត្រង់ x=4 គឺ:", slope_at_4) 
# លទ្ធផល: 24 (ចំណោតខ្លាំងណាស់!)

# ២. គណនាដេរីវេទី ២ (f'') គឺការធ្វើដេរីវេលើដេរីវេទី១
f_double_prime = sp.diff(f_prime, x)
# ឫអាចសរសេរ sp.diff(f, x, 2)
print("ដេរីវេទី ២ គឺ:", f_double_prime)
# លទ្ធផល: 6*x - 6
```

ការរកដេរីវេដោយដៃមានរូបមន្តរាប់សិបដែលត្រូវទន្ទេញ។ តែជាមួយ SymPy អ្នកគ្រាន់តែហៅមុខងារ `diff()` ប៉ុណ្ណោះ វាអាចធ្វើដេរីវេបានគ្រប់រូបមន្តទាំងអស់!
