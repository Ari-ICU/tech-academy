## 🌐 សេចក្តីផ្តើម (Overview)

បើ **ដេរីវេ** គឺជាការបំបែករបស់ធំមួយអោយទៅជាចំណែកតូចៗ ដើម្បីរកមើល "ល្បឿន" នោះ **អាំងតេក្រាល** គឺជាការយកចំណែកតូចៗរាប់លាននោះ មកផ្គុំចូលគ្នាវិញ ដើម្បីរកមើល "ចំនួនសរុប" ឫ "ផ្ទៃក្រឡា"។ ពួកវាគឺជាអនុគមន៍ច្រាសគ្នាបេះបិទ!

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. អាំងតេក្រាលមិនកំណត់ (Indefinite Integral)

ការរកអនុគមន៍ដើម (មុខងារច្រាសនៃដេរីវេ)។
```python
import sympy as sp

x = sp.symbols('x')

# អនុគមន៍ f(x) = 2x
f = 2*x

# គណនាអាំងតេក្រាល 
integral_f = sp.integrate(f, x)
print("អាំងតេក្រាលនៃ 2x គឺ:", integral_f)
# លទ្ធផល: x**2 (ព្រោះដេរីវេនៃ x**2 គឺ 2x)
```

### ២. អាំងតេក្រាលកំណត់ (Definite Integral - Area Under Curve)

ចង់រកផ្ទៃក្រឡានៅក្រោមខ្សែកោង $f(x) = x^2$ នៅចន្លោះ $x = 0$ ដល់ $x = 3$។

```python
f_curve = x**2

# បញ្ចូល (អនុគមន៍, អថេរ, គោលក្រោម, គោលលើ)
area = sp.integrate(f_curve, (x, 0, 3))

print("ផ្ទៃក្រឡានៅក្រោមខ្សែកោងពី 0 ដល់ 3 គឺ:", area)
# លទ្ធផល: 9
```

អាំងតេក្រាលមានសារៈសំខាន់ណាស់នៅក្នុងការគណនា **ប្រូបាប៊ីលីតេ** (Probability Density Function) ដើម្បីរកមើលឱកាសនៃការកើតឡើងនៃព្រឹត្តិការណ៍ណាមួយក្នុងចន្លោះពេលកំណត់មួយ។
