## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងពិភព Machine Learning យើងមានមុខងារមួយហៅថា Cost Function ដែលវាស់កំហុស (Error) របស់ AI។ គោលដៅរបស់យើង គឺត្រូវ "បង្រួមកំហុសនោះអោយតូចបំផុត (Minimum)"។ ដេរីវេ គឺជាត្រីវិស័យដែលនាំយើងចុះទៅដល់បាតនៃកំហុសនោះ។

## 💻 ការបំបែកកូដ (Code Breakdown)

### ស្វែងរកចំណុចអប្បបរមា (Minimum Point)

ឧបមាថាអនុគមន៍កំហុស (Cost Function) គឺ $f(x) = x^2 - 4x + 6$។ តើនៅត្រង់ $x$ ស្មើប៉ុន្មាន ទើបកំហុសមានតម្លៃតូចបំផុត?

```python
import sympy as sp

x = sp.symbols('x')
f = x**2 - 4*x + 6

# ១. គណនាដេរីវេ
f_prime = sp.diff(f, x)
print("ដេរីវេគឺ:", f_prime)
# លទ្ធផល: 2*x - 4

# ២. អោយដេរីវេស្មើ 0 រួចដោះស្រាយរក x (Optimization)
# 2*x - 4 = 0
critical_points = sp.solve(f_prime, x)

print("ចំណុចដែលមានកំហុសតិចបំផុតគឺត្រង់ x =", critical_points[0])
# លទ្ធផល: x = 2

# ៣. ផ្ទៀងផ្ទាត់កំហុសនៅត្រង់ចំណុចនោះ
min_error = f.subs(x, 2)
print("តម្លៃកំហុសតូចបំផុតនោះគឺ:", min_error)
# លទ្ធផល: 2
```

នេះគឺជាអ្វីដែល AI កំពុងធ្វើរាប់លានដងនៅពីក្រោយខ្នង (Backpropagation) ដើម្បីក្លាយជាឆ្លាតជាងមុន!
