## 🌐 សេចក្តីផ្តើម (Overview)

លីមីត (Limit) គឺជាព្រំដែនដែលបែងចែករវាងគណិតវិទ្យាធម្មតា និង Calculus។ គណិតវិទ្យាធម្មតាអាចប្រាប់អ្នកពីល្បឿនមធ្យម តែ Calculus (តាមរយៈលីមីត) អាចប្រាប់អ្នកពីល្បឿនភ្លាមៗត្រង់វិនាទីណាមួយ!

## 💻 ការបំបែកកូដ (Code Breakdown)

### ការគណនាលីមីតជាមួយ SymPy

ឧបមាថាយើងចង់គណនាលីមីតនៃអនុគមន៍ $f(x) = \frac{x^2 - 1}{x - 1}$ នៅពេល $x$ ខិតជិត $1$។

បើយើងជំនួស $x=1$ ចូលផ្ទាល់ យើងនឹងបាន $\frac{0}{0}$ (គ្មានន័យ)។ ប៉ុន្តែបើយើងប្រើ Limit...

```python
import sympy as sp

# កំណត់អថេរ x
x = sp.symbols('x')

# កំណត់អនុគមន៍ f(x)
f = (x**2 - 1) / (x - 1)

# គណនាលីមីតនៅពេល x ខិតជិត 1
lim = sp.limit(f, x, 1)

print("លីមីតនៅពេល x ខិតជិត 1 គឺ:", lim)
# លទ្ធផល: 2
```

ទោះបីជាត្រង់ចំណុចនោះគ្មានតម្លៃ (undefined) ក៏ដោយ ក៏ Calculus អាចដឹងថាទិសដៅរបស់វាកំពុងតម្រង់ទៅរកលេខ ២ ដែរ។ នេះហើយជាថាមពលរបស់លីមីត!
