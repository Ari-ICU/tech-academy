## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុង Machine Learning មានអថេររាប់លាន ដូច្នេះយើងមិនអាចប្រើ `sympy.solve(f_prime, x)` ដើម្បីដោះស្រាយវាត្រង់ៗបានទេ (កុំព្យូទ័រមិនអាចគណនារូបមន្តធំបែបនេះរួចទេ)។ ជំនួសមកវិញ យើងប្រើប្រាស់ **Gradient Descent** ដែលជាក្បួន "ស្មានសាកល្បងចុះម្តងបន្តិចៗ" ដោយផ្អែកលើជម្រាល (Derivative)។

---

## 🧠 របៀបវាដំណើរការ (The Logic)

ស្រមៃថាអ្នកបិទភ្នែក ហើយចង់ដើរចុះទៅកាន់បាតជ្រលងភ្នំ។ 
1. អ្នកប្រើជើងស្ទាបដី (គណនា **Derivative** ដើម្បីដឹងពីជម្រាល)។
2. បើដីទេរចុះទៅមុខ អ្នកបោះជំហានទៅមុខបន្តិច។ បើដីទេរមកក្រោយ អ្នកថយក្រោយបន្តិច។
3. ប្រវែងនៃជំហាននីមួយៗរបស់អ្នក គឺហៅថា **Learning Rate** ($\alpha$)។
4. អ្នកធ្វើបែបនេះដដែលៗ (Iterations / Epochs) រហូតទាល់តែដីស្មើ (Derivative = 0) ដែលមានន័យថាអ្នកដល់បាតហើយ!

### រូបមន្តគណិតវិទ្យា

$$ x_{new} = x_{old} - ( \text{Learning Rate} \times \text{Derivative ត្រង់ } x_{old} ) $$

```python
# កូដសង្ខេបពីក្បួន Gradient Descent
x = 5.0 # ចាប់ផ្តើមពីចំណុចចៃដន្យណាមួយ
learning_rate = 0.1

for i in range(20): # សាកដើរ ២០ ជំហាន
    derivative = 2 * x # ឧបមាថាអនុគមន៍គឺ x^2 (ដេរីវេគឺ 2x)
    x = x - (learning_rate * derivative)
    
print("ទីតាំងចុងក្រោយរបស់ x:", x) 
# វានឹងខិតជិតលេខ 0 (ដែលជាបាតពិតប្រាកដ)
```

អ្នកនឹងសរសេរកូដនេះដោយផ្ទាល់ដៃ និងគូរក្រាហ្វិកអោយឃើញចលនានៃការដើរចុះនេះយ៉ាងច្បាស់ នៅក្នុងម៉ូឌុលចុងក្រោយ (Capstone)!
