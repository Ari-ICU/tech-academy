## 🌐 សេចក្តីផ្តើម (Overview)

ហេតុអ្វីបានជាកម្ពស់របស់មនុស្ស ឫពិន្ទុប្រឡង តែងតែមានអ្នកពិន្ទុកណ្តាលៗច្រើនជាងគេ ហើយអ្នកខ្សោយខ្លាំង ឫពូកែខ្លាំងមានតិចតួច? នេះមិនមែនជារឿងចៃដន្យទេ វាគឺជាច្បាប់ធម្មជាតិមួយដែលគេហៅថា **Normal Distribution (របាយកណ្តឹង)**។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

យើងអាចប្រើប្រាស់ `scipy.stats` ដើម្បីបង្កើត និងគូររូបរបាយកណ្តឹងដ៏ស្រស់ស្អាត។

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm

# កំណត់កម្ពស់មធ្យម (Mean) គឺ 165cm និងគម្លាតស្តង់ដារ (Std) គឺ 5cm
mean = 165
std_dev = 5

# បង្កើតចំណុច x ពី 145 ដល់ 185 ដើម្បីគូរក្រាហ្វិក
x = np.linspace(145, 185, 100)

# គណនា PDF (Probability Density Function) ដើម្បីចេញជារាងកណ្តឹង
y = norm.pdf(x, loc=mean, scale=std_dev)

# គូរក្រាហ្វិក
plt.plot(x, y, color='blue', linewidth=2)

# បំពេញពណ៌ដើម្បីបង្ហាញពីច្បាប់ 68% (1 Std Deviation)
x_fill = np.linspace(mean - std_dev, mean + std_dev, 50)
y_fill = norm.pdf(x_fill, loc=mean, scale=std_dev)
plt.fill_between(x_fill, y_fill, color='lightblue', alpha=0.5, label='68% នៃទិន្នន័យ')

plt.title("របាយកណ្តឹង (Normal Distribution) នៃកម្ពស់មនុស្ស")
plt.xlabel("កម្ពស់ (cm)")
plt.ylabel("ដង់ស៊ីតេ (Probability Density)")
plt.legend()
plt.show()
```

អ្នកនឹងឃើញក្រាហ្វិកមានរាងដូចជួង (Bell-curve) ដោយកំពូលរបស់វាស្ថិតនៅចំកណ្តាល (១៦៥ cm)។ ម៉ូដែល AI ជាច្រើនត្រូវបានសាងសង់ឡើងដោយសន្មតថាទិន្នន័យរបស់អ្នកមានរូបរាងបែបនេះ!
