## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុង AI ជារឿយៗវាត្រូវសម្រេចចិត្តលើបញ្ហាស្មុគស្មាញ។ ឧទាហរណ៍៖ "តើមានឱកាសប៉ុន្មានភាគរយដែលអ្នកជំងឺនេះមានអាយុលើសពី ៥០ ឆ្នាំ **និង (AND)** មានប្រវត្តិជក់បារី?"។ ដើម្បីគណនាវា យើងត្រូវយល់ពីច្បាប់បូក និងច្បាប់គុណ។

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ច្បាប់គុណ (Multiplication Rule: $P(A \text{ and } B)$)

ប្រើនៅពេលយើងចង់អោយព្រឹត្តិការណ៍ទាំងពីរកើតឡើង (A ក៏កើត ឯ B ក៏កើត)។

**ឧទាហរណ៍:** បោះគ្រាប់ឡុកឡាក់ ២ គ្រាប់។ តើឱកាសចេញលេខ ៦ ទាំងពីរគ្រាប់មានប៉ុន្មាន?

```python
# ឱកាសចេញលេខ 6 លើគ្រាប់ឡុកឡាក់ ១ គ្រាប់
prob_six = 1 / 6

# ព្រឹត្តិការណ៍កើតឡើងព្រមគ្នា (AND) -> យកទៅគុណ
prob_two_sixes = prob_six * prob_six

print(f"ឱកាសចេញលេខ ៦ ទាំងពីរគ្រាប់: {prob_two_sixes * 100:.2f}%")
# លទ្ធផល: 2.78% (កម្រណាស់!)
```

### ២. ច្បាប់បូក (Addition Rule: $P(A \text{ or } B)$)

ប្រើនៅពេលយើងចង់បានតែមួយណាក៏បាន (A ក៏បាន ឫ B ក៏បាន)។ រូបមន្ត៖ $P(A) + P(B) - P(\text{ជាន់គ្នា})$

**ឧទាហរណ៍:** បោះគ្រាប់ឡុកឡាក់ ១ គ្រាប់។ តើឱកាសចេញលេខ ២ ឫ លេខ ៥ មានប៉ុន្មាន?

```python
prob_two = 1 / 6
prob_five = 1 / 6

# ព្រឹត្តិការណ៍មួយណាឫមួយណា (OR) -> យកទៅបូក 
# (ដោយសារលេខ ២ និង ៥ មិនអាចចេញព្រមគ្នា វាមិនជាន់គ្នាទេ)
prob_two_or_five = prob_two + prob_five

print(f"ឱកាសចេញលេខ ២ ឫ ៥: {prob_two_or_five * 100:.2f}%")
# លទ្ធផល: 33.33%
```

ការយល់ដឹងពីពាក្យ **AND ($\times$)** និង **OR ($+$)** គឺសំខាន់បំផុតនៅក្នុងមុខវិជ្ជាប្រូបាប៊ីលីតេ!
