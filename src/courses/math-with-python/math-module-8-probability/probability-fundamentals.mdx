## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងពិភព Machine Learning យើងមិនអាចដឹងរឿងរ៉ាវអនាគត ១០០% ទេ យើងគ្រាន់តែអាច "ទាយ" វាដោយផ្អែកលើ **ប្រូបាប៊ីលីតេ (Probability)**។ AI ដែលទស្សន៍ទាយជំងឺ ឫសម្គាល់មុខ មិនមែនប្រាកដ ១០០% ទេ តែវាមាន "ប្រូបាប៊ីលីតេខ្ពស់" ក្នុងការទាយត្រូវ។

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការគណនាប្រូបាប៊ីលីតេសាមញ្ញ

រូបមន្តប្រូបាប៊ីលីតេ: 
$$ P(A) = \frac{\text{ចំនួនលទ្ធផលដែលចង់បាន}}{\text{ចំនួនលទ្ធផលដែលអាចកើតមានទាំងអស់}} $$

ឧទាហរណ៍: ការបោះគ្រាប់ឡុកឡាក់ដើម្បីឱ្យចេញលេខគូ (២, ៤, ៦)។
```python
# លទ្ធផលដែលចង់បាន (លេខគូមាន ៣ គឺ ២, ៤, ៦)
favorable_outcomes = 3

# លទ្ធផលសរុប (គ្រាប់ឡុកឡាក់មាន ៦ មុខ)
total_outcomes = 6

probability = favorable_outcomes / total_outcomes
print(f"ប្រូបាប៊ីលីតេក្នុងការបោះបានលេខគូគឺ: {probability*100}%")
```

### ២. ការក្លែងធ្វើព្រឹត្តិការណ៍ (Simulation)

ការបោះកាក់ ១ ម៉ឺនដងក្នុង Python:
```python
import random

heads = 0
tails = 0
trials = 10000

for _ in range(trials):
    result = random.choice(['Head', 'Tail'])
    if result == 'Head':
        heads += 1
    else:
        tails += 1

print(f"ចេញក្បាល: {heads} ដង ({heads/trials*100}%)")
print(f"ចេញកន្ទុយ: {tails} ដង ({tails/trials*100}%)")
```
តាមច្បាប់ចំនួនធំ (Law of Large Numbers) កាលណាយើងបោះកាន់តែច្រើន លទ្ធផលនឹងកាន់តែខិតជិត ៥០%!
