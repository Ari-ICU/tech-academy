## 🌐 សេចក្តីផ្តើម (Overview)

## 💻 ការបំបែកកូដ (Code Breakdown)

### ហ្គេមបោះគ្រាប់ឡុកឡាក់ (Dice Game Simulation)

**ច្បាប់ហ្គេម:** 
- អ្នកបោះគ្រាប់ឡុកឡាក់ (១-៦) ចំនួន ២ គ្រាប់។
- ប្រសិនបើផលបូករបស់វា ស្មើនឹង ៧ ឬ ១១ នោះអ្នកឈ្នះ!
- តើអ្នកមានឱកាសឈ្នះប៉ុន្មានភាគរយ?

ជំនួសអោយការគណនាដោយរូបមន្ត យើងអោយ Python លេងហ្គេមនេះ ១ សែនដង!

```python
import random

# កំណត់ចំនួននៃការសាកល្បង
trials = 100000
wins = 0

# អោយកុំព្យូទ័រលេងរាប់ម៉ឺនដង
for _ in range(trials):
    # បោះឡុកឡាក់ ២ គ្រាប់
    dice_1 = random.randint(1, 6)
    dice_2 = random.randint(1, 6)
    total = dice_1 + dice_2
    
    # ពិនិត្យលក្ខខណ្ឌឈ្នះ
    if total == 7 or total == 11:
        wins += 1

# គណនាប្រូបាប៊ីលីតេនៃការឈ្នះ (ប្រហែល 22.2%)
probability = wins / trials

print(f"បន្ទាប់ពីសាកល្បង {trials} ដង, ឱកាសឈ្នះគឺ: {probability*100:.2f}%")
```

អ្នកបានដោះស្រាយបញ្ហាគណិតវិទ្យាយ៉ាងលឿន ដោយប្រើកម្លាំងបាយរបស់កុំព្យូទ័រ (Brute-force simulation)។ ក្បួន Monte Carlo នេះក៏ត្រូវបានប្រើប្រាស់ដោយ AI AlphaGo របស់ Google ដើម្បីយកឈ្នះជើងឯកលេងអុកពិភពលោកផងដែរ!
