## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងពិភពពិត លទ្ធផលនៃការស្ទង់មតិមិនមែនចេញជាពាក្យ "ក្បាល" ឬ "កន្ទុយ" រហូតទេ។ យើងត្រូវបំប្លែងលទ្ធផលទាំងនោះទៅជា **លេខ** ដើម្បីអោយកុំព្យូទ័រអាចគណនាបាន។ នេះហើយហៅថា **អថេរចៃដន្យ (Random Variables)**។

---

## 💻 ការបំបែកគំនិត (Concept Breakdown)

អថេរចៃដន្យចែកចេញជា ២ ប្រភេទធំៗ នៅក្នុង Data Science៖

### ១. អថេរចៃដន្យដាច់ (Discrete Random Variables)

វាជាទិន្នន័យដែលយើងអាច **"រាប់"** បានជាដុំៗ (១, ២, ៣...)។
- ចំនួនកូនក្នុងគ្រួសារមួយ
- ចំនួនអតិថិជនដែលទិញអីវ៉ាន់ក្នុងមួយថ្ងៃ
- ពិន្ទុបាល់ទាត់

ឧទាហរណ៍ Python (ប្រើ Poisson Distribution សម្រាប់ទិន្នន័យ Discrete):
```python
import numpy as np

# ចំនួនអតិថិជនជាមធ្យម 5 នាក់ក្នុងមួយម៉ោង
# Simulation សម្រាប់ 10 ម៉ោងបន្ទាប់
customers = np.random.poisson(lam=5, size=10)
print("ចំនួនភ្ញៀវក្នុង ១០ ម៉ោងបន្ទាប់:", customers)
# លទ្ធផល: [5 6 4 5 3 2 8 5 4 6] (សុទ្ធតែជាចំនួនគត់)
```

### ២. អថេរចៃដន្យជាប់ (Continuous Random Variables)

វាជាទិន្នន័យដែលកើតចេញពីការ **"វាស់វែង"** វាអាចមានតម្លៃរាប់លានក្នុងចន្លោះមួយ។
- ទម្ងន់របស់មនុស្ស (65.2 kg, 65.21 kg...)
- សីតុណ្ហភាពទឹក
- រយៈពេលបំពេញការងារ

ឧទាហរណ៍ Python (ប្រើ Uniform Distribution សម្រាប់ទិន្នន័យ Continuous):
```python
# កម្ពស់មនុស្សចន្លោះ 160cm ដល់ 180cm ចំនួន 5 នាក់
heights = np.random.uniform(low=160, high=180, size=5)
print("កម្ពស់ (Continuous):", np.round(heights, 2))
# លទ្ធផល: [165.24 177.89 161.42 173.05 168.99]
```

ការបែងចែកនេះជួយឱ្យអ្នកដឹងថា តើគួរប្រើប្រាស់ក្រាហ្វិកមួយណា ឫសម្មតិកម្មមួយណា នៅក្នុងមេរៀនបន្តបន្ទាប់!
