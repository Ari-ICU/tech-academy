## 🛠️ តម្រូវការគម្រោង (Project Requirements)

### កម្មវិធី "Mathematical Analysis Toolkit"

អ្នកត្រូវសរសេរកម្មវិធី Python មួយ ដែលមានមុខងារយ៉ាងតិច ៤ ដូចខាងក្រោម៖

1. **Equation Solver (កម្មវិធីដោះស្រាយសមីការ):**
   - ប្រើប្រាស់ `SymPy` ដើម្បីអនុញ្ញាតអោយអ្នកប្រើប្រាស់បញ្ចូលសមីការណាមួយ (ឧ. $x^2 - 5x + 6 = 0$) ហើយកម្មវិធីត្រូវបញ្ចេញចម្លើយមកវិញដោយស្វ័យប្រវត្តិ។
2. **Function Plotter (អ្នកគូរក្រាហ្វិក):**
   - អនុញ្ញាតអោយអ្នកប្រើប្រាស់បញ្ចូលរូបមន្តអនុគមន៍ ហើយប្រើប្រាស់ `Matplotlib` + `NumPy` ដើម្បីគូររូបក្រាហ្វិកនោះ។
3. **Matrix Calculator (ម៉ាស៊ីនគិតលេខម៉ាទ្រីស):**
   - អនុញ្ញាតអោយអ្នកប្រើប្រាស់បញ្ចូលម៉ាទ្រីស ២ រួចធ្វើការបូក ដក និង គុណ (Dot Product) ដោយប្រើ `NumPy`។
4. **Statistics Analyzer (កម្មវិធីវិភាគស្ថិតិ):**
   - អ្នកប្រើប្រាស់អាចបញ្ចូលបញ្ជីនៃលេខ ហើយកម្មវិធីត្រូវប្រាប់ពី មធ្យមភាគ (Mean) មេដ្យាន (Median) គម្លាតស្តង់ដារ (Standard Deviation) និងគូររបាយកណ្តឹង (Histogram) ផងដែរ។
