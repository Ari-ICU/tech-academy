## 🌐 សេចក្តីផ្តើម (Overview)

នេះគឺជាចំណុចដែលគណិតវិទ្យា ជួបជាមួយ AI! Machine Learning គឺពឹងផ្អែកលើការគណនាគណិតវិទ្យាសុទ្ធសាធ។ ប្រសិនបើអ្នកបញ្ចូលអាយុ (ឧ. 25) និងប្រាក់ខែ (ឧ. 50,000) ទៅក្នុង AI វានឹងគិតថា "ប្រាក់ខែធំជាងអាយុណាស់ ដូច្នេះប្រាក់ខែសំខាន់ជាង!"។ ដើម្បីការពាររឿងនេះ យើងត្រូវប្រើ **Normalization** ដើម្បីបង្រួមលេខទាំងអស់មកនៅចន្លោះ ០ ទៅ ១ ដូចគ្នា។

## 💻 ការបំបែកកូដ (Code Breakdown)

### រូបមន្ត Min-Max Scaling
$$ X_{new} = \frac{X - X_{min}}{X_{max} - X_{min}} $$

តោះសរសេររូបមន្តនេះជាកូដ Python៖

```python
import numpy as np

# ទិន្នន័យប្រាក់ខែ និង អាយុ របស់មនុស្ស ៥ នាក់
salaries = np.array([30000, 50000, 45000, 80000, 120000])
ages = np.array([22, 35, 28, 45, 60])

# ១. បង្កើតអនុគមន៍ Normalization
def min_max_scaling(data):
    min_val = np.min(data)
    max_val = np.max(data)
    return (data - min_val) / (max_val - min_val)

# ២. អនុវត្តទៅលើទិន្នន័យ
normalized_salaries = min_max_scaling(salaries)
normalized_ages = min_max_scaling(ages)

print("ប្រាក់ខែមុនពេល:", salaries)
print("ប្រាក់ខែក្រោយពេល:", normalized_salaries)
# លទ្ធផលនឹងនៅចន្លោះ 0 ទៅ 1

print("\nអាយុក្រោយពេល:", normalized_ages)
```

ឥឡូវនេះ ប្រាក់ខែ និង អាយុ ត្រូវបានបង្រួមមកនៅចន្លោះ ០ ទៅ ១ ដូចគ្នា ធ្វើអោយ AI អាចរៀនបានដោយយុត្តិធម៌ (មិនលម្អៀង)!
