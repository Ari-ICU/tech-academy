## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងម៉ូឌុល Calculus យើងប្រើ SymPy ដើម្បីរកដេរីវេ រួចអោយស្មើ ០ រួចដោះស្រាយសមីការ។ វាដំណើរការល្អលើក្រដាស ប៉ុន្តែមិនល្អសម្រាប់កុំព្យូទ័រពេលទិន្នន័យមានរាប់លានទេ! បណ្ណាល័យ `scipy.optimize` ត្រូវបានបង្កើតឡើងដើម្បីរកចំណុចបាត (Minimum) ដោយស្វ័យប្រវត្តិ តាមរយៈក្បួនដូចជា Gradient Descent ។

## 💻 ការបំបែកកូដ (Code Breakdown)

### ប្រើប្រាស់ `scipy.optimize.minimize`

ឧបមាថាយើងចង់រកចំណុចបាតនៃអនុគមន៍ $f(x) = (x - 3)^2 + 5$។ (មើលនឹងភ្នែកក៏ដឹងថាកំហុសតិចបំផុត ៥ គឺកើតឡើងនៅពេល $x = 3$)។ 

តោះប្រើ SciPy!

```python
import numpy as np
from scipy.optimize import minimize

# ១. បង្កើតអនុគមន៍ធម្មតារបស់ Python (Objective Function)
def cost_function(x):
    # វានឹងគណនាតម្លៃ (x-3)^2 + 5
    return (x - 3)**2 + 5

# ២. កំណត់ចំណុចចាប់ផ្តើមនៃការស្មាន (Initial Guess)
# យើងអោយកុំព្យូទ័រចាប់ផ្តើមស្មានពី x = 0 ទៅ
x_start = [0.0]

# ៣. ហៅមុខងារ minimize ដើម្បអោយវាដើររកបាត (Optimization)
result = minimize(cost_function, x_start)

# ៤. បញ្ចេញលទ្ធផល
print("ស្ថានភាពជោគជ័យ?:", result.success)
print("តម្លៃ x ដែលធ្វើអោយកំហុសតិចបំផុត (x-value):", result.x[0])
print("តម្លៃកំហុសតិចបំផុតនោះ (Cost):", result.fun)

# លទ្ធផលរំពឹងទុក:
# x ប្រហែល 3.00000...
# Cost ប្រហែល 5.0
```

`minimize` បានប្រើប្រាស់ក្បួនជម្រាលដ៏ស្មុគស្មាញដោយលាក់បាំងពីក្រោយខ្នង (Under the hood) ដើម្បីដើររកចម្លើយអោយយើងដោយស្វ័យប្រវត្តិ! វាក៏ជាក្បួនដែលគេប្រើក្នុងការអោយ AI រៀនទម្រង់របស់មុខមនុស្ស (Facial Recognition) ផងដែរ!
