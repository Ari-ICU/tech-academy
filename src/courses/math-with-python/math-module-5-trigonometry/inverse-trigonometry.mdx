## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងមេរៀនមុន យេីងស្គាល់មុំ ដេីម្បីទៅរកប្រវែងជ្រុង។ ចុះបើអ្នកកំពុងបង្កើតហ្គេមបាញ់ធ្នូ អ្នកស្គាល់កម្ពស់សត្រូវ និងចម្ងាយពីអ្នកទៅសត្រូវ តើអ្នកត្រូវបាញ់ធ្នូក្នុងមុំប៉ុន្មានដឺក្រេ ទើបចំគោលដៅ? នេះហើយជាតួនាទីរបស់ **ច្រាសត្រីកោណមាត្រ (Inverse Trigonometry)**!

## 💻 ការបំបែកកូដ (Code Breakdown)

### ប្រើប្រាស់ Asin, Acos, និង Atan

អនុគមន៍ច្រាសនៅក្នុង Python ត្រូវបានសរសេរដោយបន្ថែមអក្សរ `a` ពីមុខ (មកពីពាក្យ arc ដូចជា arcsin, arccos, arctan)។

**ចំណាំដ៏សំខាន់៖** លទ្ធផលដែលទទួលបានពីមុខងារទាំងនេះ គឺជា **រ៉ាដ្យង់**។ អ្នកត្រូវបំប្លែងវាទៅជា **ដឺក្រេ** វិញដើម្បីអោយងាយយល់!

```python
import math

# ឧទាហរណ៍៖ តើមុំប៉ុន្មាន ទើបមានស៊ីនុសស្មើ 0.5?
sin_value = 0.5

# រកមុំជារ៉ាដ្យង់
angle_rad = math.asin(sin_value)

# បំប្លែងទៅជាដឺក្រេ
angle_deg = math.degrees(angle_rad)

print(f"មុំដែលមានស៊ីនុសស្មើ 0.5 គឺ: {angle_deg:.1f} ដឺក្រេ") # ចេញ 30.0
```

### ឧទាហរណ៍ជាក់ស្តែង៖ ហ្គេមបាញ់ធ្នូ
សត្រូវនៅឆ្ងាយ ១០ ម៉ែត្រ (Adjacent) និងឈរលើប្រអប់កម្ពស់ ១០ ម៉ែត្រ (Opposite)។

```python
opp = 10
adj = 10

# យើងដឹងថា Tan = Opp / Adj
tan_value = opp / adj # ស្មើ 1.0

# រកមុំ
angle_rad_game = math.atan(tan_value)
angle_deg_game = math.degrees(angle_rad_game)

print(f"អ្នកត្រូវបាញ់ធ្នូក្នុងមុំ: {angle_deg_game} ដឺក្រេ") # ចេញ 45.0
```
នេះគឺជាកូដពិតៗដែលអ្នកបង្កើតហ្គេម (Game Developers) ប្រើប្រាស់ជារៀងរាល់ថ្ងៃដើម្បីបង្កើតប្រព័ន្ធតម្រង់គោលដៅ (Aiming System)!
