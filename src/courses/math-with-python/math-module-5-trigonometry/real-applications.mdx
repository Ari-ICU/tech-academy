## 💻 ការបំបែកកូដ (Code Breakdown)

### ការគណនាចម្ងាយរវាងចំណុចពីរ (Distance Formula)

ឧបមាថា AI កំពុងតាមដានភ្នែករបស់មនុស្សនៅលើកាមេរ៉ា។ ភ្នែកឆ្វេងនៅកូអរដោណេ $(x_1, y_1) = (2, 3)$ ហើយភ្នែកស្តាំនៅ $(x_2, y_2) = (5, 7)$។ តើភ្នែកទាំងពីរឃ្លាតគ្នាប្រវែងប៉ុន្មាន?

រូបមន្តគឺ៖ $Distance = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$ (បានមកពីពីតាក័រ)

```python
import math

# កូអរដោណេភ្នែក
x1, y1 = 2, 3
x2, y2 = 5, 7

# គណនាប្រវែងជ្រុងជាប់ និងជ្រុងឈម
dx = x2 - x1 # ប្រវែងតាមអ័ក្ស X (Adjacent)
dy = y2 - y1 # ប្រវែងតាមអ័ក្ស Y (Opposite)

# គណនាអ៊ីប៉ូតេនុស (ចម្ងាយ)
distance = math.sqrt(dx**2 + dy**2)
# ឬអាចសរសេរខ្លីៗដោយប្រើមុខងារមានស្រាប់: math.hypot(dx, dy)

print(f"ភ្នែកទាំងពីរឃ្លាតគ្នាប្រវែង: {distance} ឯកតា") # ចេញ 5.0
```

អ្នកបានបញ្ចប់ម៉ូឌុលត្រីកោណមាត្រហើយ! នៅក្នុងម៉ូឌុលបន្ទាប់ យើងនឹងចាប់ផ្តើមរៀនពី Linear Algebra ដែលជាគ្រឹះដ៏សំខាន់បំផុតរបស់ Machine Learning និង Deep Learning (Neural Networks)!
