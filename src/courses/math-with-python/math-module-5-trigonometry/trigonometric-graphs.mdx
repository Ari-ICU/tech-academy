## 🌐 សេចក្តីផ្តើម (Overview)

តើអ្នកធ្លាប់ឆ្ងល់ទេថាតើ កម្មវិធីកាត់តសំឡេងបង្កើតរលកសំឡេងបានយ៉ាងដូចម្តេច? សំឡេងទាំងអស់គ្រាន់តែជាការបូកបញ្ចូលគ្នានៃ **រលកស៊ីនុស (Sine Waves)** ជាច្រើនប៉ុណ្ណោះ! ការគូររលកទាំងនេះគឺជាជំហានដំបូងចូលទៅកាន់ពិភព Signal Processing។

## 💻 ការបំបែកកូដ (Code Breakdown)

### ការគូររលកស៊ីនុស និង កូស៊ីនុស

ដើម្បីគូរវាអោយបានរលោង យើងត្រូវការចំណុច $x$ ជាច្រើន (ពី $0$ ដល់ $4\pi$ ដែលស្មើនឹងរង្វង់ ២ ជុំ)។

```python
import numpy as np
import matplotlib.pyplot as plt

# បង្កើតចំណុច x ពី 0 ទៅ 4*Pi (ប្រហែល 12.5) ចំនួន ២០០ គ្រាប់
x = np.linspace(0, 4 * np.pi, 200)

# គណនា y (Sine និង Cosine)
# ចំណាំ: np.sin ទទួលយក Array ហើយបញ្ចេញ Array វិញភ្លាមៗ
y_sin = np.sin(x)
y_cos = np.cos(x)

# គូរក្រាហ្វិក
plt.plot(x, y_sin, label="Sine Wave (sin)", color="blue")
plt.plot(x, y_cos, label="Cosine Wave (cos)", color="red", linestyle="--")

plt.title("ក្រាហ្វិករលកត្រីកោណមាត្រ")
plt.xlabel("រ៉ាដ្យង់ (Radians)")
plt.ylabel("អំព្លីទីត (Amplitude)")
plt.legend()
plt.grid(True)
plt.axhline(0, color='black',linewidth=1) # គូសបន្ទាត់ផ្តេកត្រង់លេខ 0
plt.show()
```

អ្នកនឹងឃើញរលកអណ្តែតឡើងចុះៗជានិច្ចកាលចន្លោះពី 1 ទៅ -1។ រលកកូស៊ីនុស (ក្រហម) គ្រាន់តែជារលកស៊ីនុសដែលដើរមុនស៊ីនុសបន្តិចប៉ុណ្ណោះ។ នេះគឺជាមូលដ្ឋានដែលអ្នកត្រូវដឹងមុននឹងសិក្សាពីរលកអគ្គិសនី ឫការបង្ហាប់រូបភាព!
