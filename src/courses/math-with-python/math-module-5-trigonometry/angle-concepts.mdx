## 🌐 សេចក្តីផ្តើម (Overview)

ត្រីកោណមាត្រ (Trigonometry) គឺជាការសិក្សាអំពីមុំ និងត្រីកោណ។ វាមិនត្រឹមតែសំខាន់សម្រាប់សំណង់ប៉ុណ្ណោះទេ តែវាក៏ជាបេះដូងនៃការបង្កើត Animation ក្នុងហ្គេម ឫដំណើរការសញ្ញា (Signal Processing) ក្នុង AI ផងដែរ។ ជំហានដំបូងបំផុត គឺត្រូវយល់ដឹងពីរបៀបដែលកុំព្យូទ័រយល់ពី "មុំ"។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ដឺក្រេ និង រ៉ាដ្យង់

មនុស្សចូលចិត្តវាស់មុំជារង្វង់ ៣៦០ **ដឺក្រេ**។ ប៉ុន្តែនៅក្នុងគណិតវិទ្យា និង Programming គេវាស់វាជា **រ៉ាដ្យង់** (Rad) ដោយផ្អែកលើប្រវែងធ្នូនៃរង្វង់ (រង្វង់មួយជុំមាន $2\pi$ រ៉ាដ្យង់)។

$$ 360^{\circ} = 2\pi \text{ រ៉ាដ្យង់} $$
$$ 180^{\circ} = \pi \text{ រ៉ាដ្យង់} $$

### ២. ការបំប្លែងចុះឡើង (Conversion)

Python បានរៀបចំមុខងាររួចជាស្រេច ដើម្បីអោយអ្នកងាយស្រួលក្នុងការផ្លាស់ប្តូរ៖

```python
import math

# បំប្លែង ៩០ ដឺក្រេ ទៅជារ៉ាដ្យង់
angle_deg = 90
angle_rad = math.radians(angle_deg)

print(f"{angle_deg} ដឺក្រេ ស្មើនឹង {angle_rad:.4f} រ៉ាដ្យង់")
# លទ្ធផល: 90 ដឺក្រេ ស្មើនឹង 1.5708 រ៉ាដ្យង់ (ប្រហែល Pi/2)

# បំប្លែងត្រលប់មកវិញ
back_to_deg = math.degrees(angle_rad)
print(f"បំប្លែងត្រលប់មកវិញ: {back_to_deg} ដឺក្រេ")
```

កុំភ្លេចណា! មុននឹងប្រើ `math.sin()` អ្នកត្រូវបំប្លែងមុំទៅជា រ៉ាដ្យង់ ជានិច្ច!
