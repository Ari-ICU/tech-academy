## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការពង្រីក/បង្រួម (Scaling Transformation)

ដើម្បីពង្រីកវ៉ិចទ័រ យើងត្រូវបង្កើតម៉ាទ្រីសពិសេសមួយ។ ម៉ាទ្រីសនេះនឹងរក្សាទិសដៅដើម តែធ្វើអោយប្រវែងរបស់វាខុសពីមុន។

```python
import numpy as np

# ចំណុចដើម (x=2, y=1)
v = np.array([2, 1])

# ម៉ាទ្រីសសម្រាប់ពង្រីកទំហំគុណនឹង ៣ ទាំងអ័ក្ស X និង Y
# [ 3, 0 ]
# [ 0, 3 ]
scaling_matrix = np.array([
    [3, 0],
    [0, 3]
])

# អនុវត្តការទាញ (Transformation = Matrix @ Vector)
v_new = scaling_matrix @ v

print("វ៉ិចទ័រថ្មី:", v_new) # លទ្ធផល: [6, 3]
```

### ២. ការបង្វិល (Rotation Transformation)

នេះជាចំណុចដែល Linear Algebra និង ត្រីកោណមាត្រ ជួបគ្នា! រូបមន្តម៉ាទ្រីសសម្រាប់បង្វិលមុំ $\theta$ (រ៉ាដ្យង់) គឺ៖
$$ R = \begin{bmatrix} \cos(\theta) & -\sin(\theta) \\ \sin(\theta) & \cos(\theta) \end{bmatrix} $$

```python
import math

# ចង់បង្វិល ៩០ ដឺក្រេ (ត្រូវបំប្លែងទៅរ៉ាដ្យង់សិន)
theta = math.radians(90)

# បង្កើតម៉ាទ្រីសបង្វិល
rotation_matrix = np.array([
    [math.cos(theta), -math.sin(theta)],
    [math.sin(theta), math.cos(theta)]
])

# អនុវត្តទៅលើវ៉ិចទ័រ v [2, 1] ខាងលើ
v_rotated = rotation_matrix @ v

# ដោយសារបញ្ហា Floating point ផលនៃ cos(90) មិនស្មើ 0 បេះបិទទេ យើងត្រូវ Round វាអោយស្អាត
print("បន្ទាប់ពីបង្វិល ៩០ ដឺក្រេ:", np.round(v_rotated, 2))
# លទ្ធផល: [-1.,  2.]
```

ឃើញទេ? ពីកូអរដោណេ `(2, 1)` វាបានវិលទៅជា `(-1, 2)` យ៉ាងត្រឹមត្រូវ!
