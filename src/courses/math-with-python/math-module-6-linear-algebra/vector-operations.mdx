## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងពិភព AI វ៉ិចទ័រតំណាងអោយលក្ខណៈ (Features) របស់ទិន្នន័យ។ ឧទាហរណ៍ ផ្ទះមួយមានទំហំ $100$ ម៉ែត្រការ៉េ និងមានបន្ទប់ ៣ យើងអាចសរសេរជាវ៉ិចទ័រ $v = [100, 3]$។ ការចេះធ្វើប្រមាណវិធីលើវ៉ិចទ័រ ជួយអោយ AI អាចប្រៀបធៀបផ្ទះនេះ ជាមួយផ្ទះដទៃទៀតបាន!

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការបូក ដក និង Scalar Multiplication

ការបូកវ៉ិចទ័រ គឺគ្រាន់តែបូកលេខមួយទល់មួយ។ ឯ Scalar Multiplication គឺការគុណវ៉ិចទ័រជាមួយនឹងលេខធម្មតាមួយ។

```python
import numpy as np

v1 = np.array([2, 4])
v2 = np.array([1, 3])

# បូក និង ដក
print("ការបូកវ៉ិចទ័រ:", v1 + v2) # [3, 7]
print("ការដកវ៉ិចទ័រ:", v1 - v2) # [1, 1]

# Scalar Multiplication (គុណវ៉ិចទ័រនឹងលេខ 5)
print("គុណនឹង 5:", v1 * 5) # [10, 20]
```

### ២. ផលគុណ Dot Product (បេះដូងរបស់ AI)

Dot Product គឺជាប្រមាណវិធីដ៏សំខាន់បំផុតក្នុងសរសៃប្រសាទសិប្បនិម្មិត (Neural Networks)។ រូបមន្ត៖ $(x_1 * x_2) + (y_1 * y_2)$

```python
# គណនា Dot Product
result = np.dot(v1, v2)

# ឬអាចសរសេរខ្លីៗដោយប្រើសញ្ញា @
# result = v1 @ v2

print("Dot Product របស់ v1 និង v2 គឺ:", result) 
# ការគណនា: (2*1) + (4*3) = 2 + 12 = 14
```

### ហេតុអ្វីបានជា Dot Product សំខាន់?
ស្រមៃថា `v1` ជាចំនួនផ្លែប៉ោម និងក្រូចដែលអ្នកទិញ `[2 ផ្លែ, 4 ផ្លែ]`។ `v2` ជាតម្លៃក្នុងមួយផ្លែ `[1$, 3$]`។
Dot Product ជួយអ្នកគណនាតម្លៃសរុប ($2\times1\$ + 4\times3\$ = 14\$$) ដោយមិនបាច់សរសេរ For Loop ទាល់តែសោះ! នេះធ្វើអោយកុំព្យូទ័រគណនាលឿនជាងមុនរាប់ពាន់ដង!
