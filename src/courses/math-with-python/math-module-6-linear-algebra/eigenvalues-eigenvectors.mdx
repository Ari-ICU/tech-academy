## 🌐 សេចក្តីផ្តើម (Overview)

ពាក្យ "Eigen" គឺជាភាសាអាល្លឺម៉ង់ ប្រែថា "ជាលក្ខណៈសម្គាល់ផ្ទាល់ខ្លួន" (Characteristic)។ គ្រប់ម៉ាទ្រីស (រាងការ៉េ) ទាំងអស់ សុទ្ធតែមាន "DNA" ផ្ទាល់ខ្លួនរបស់វា ដែលយើងហៅថា Eigenvalues និង Eigenvectors។ ក្បួនដោះស្រាយដ៏ល្បីល្បាញរបស់ Google (PageRank) ដើម្បីស្វែងរក Website ណាដែលល្អជាងគេ គឺពឹងផ្អែកលើ Eigenvectors នេះឯង!

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. តើវាដំណើរការយ៉ាងដូចម្តេច?

ឧបមាថាយើងមានម៉ាទ្រីស $A$ (ម៉ាស៊ីនទាញរូប) និងវ៉ិចទ័រ $v$ (Eigenvector)។ រូបមន្តគឺ៖
$$ A \times v = \lambda \times v $$
កូដនេះមានន័យថា៖ "ការយកម៉ាទ្រីស ទៅកាឡៃវ៉ិចទ័រ ($A \times v$) គឺទទួលបានលទ្ធផលដូចគ្នាបេះបិទ ទៅនឹងការយកលេខធម្មតា (Eigenvalue $\lambda$) ទៅគុណនឹងវ៉ិចទ័រនោះដែរ ($\lambda \times v$)!"។

### ២. គណនាវាជាមួយ NumPy

ការគណនាវាដោយដៃគឺស្មុគស្មាញណាស់ (ត្រូវដោះស្រាយសមីការដឺក្រេទី ៣ ឫ ៤)។ តែ NumPy អាចធ្វើបានក្នុង ១ បន្ទាត់!

```python
import numpy as np

# បង្កើតម៉ាទ្រីស A (រាងការ៉េ 2x2)
A = np.array([
    [3, 1],
    [0, 2]
])

# ហៅអនុគមន៍ eig() (មកពី linalg = Linear Algebra)
eigenvalues, eigenvectors = np.linalg.eig(A)

print("តម្លៃលក្ខណៈ (Eigenvalues):", eigenvalues)
# លទ្ធផល: [3, 2]

print("វ៉ិចទ័រលក្ខណៈ (Eigenvectors):\n", eigenvectors)
# លទ្ធផលនឹងចេញជាម៉ាទ្រីស ដែលជួរឈរនីមួយៗ គឺជា Eigenvector មួយ។
```

### ហេតុអ្វីបានជាវានៅតែជាបេះដូងរបស់ AI?
នៅក្នុង Machine Learning, ទិន្នន័យជារឿយៗមានរហូតដល់ ១ ម៉ឺនជួរឈរ (10,000 Dimensions) ដែលធ្វើអោយកុំព្យូទ័រគណនាយឺត។ Data Scientists ប្រើប្រាស់ **PCA (Principal Component Analysis)** ដែលជាក្បួនយក Eigenvectors ទាំងនេះ ទៅស្វែងរក "ឆ្អឹងខ្នង" សំខាន់ៗនៃទិន្នន័យ រួចបោះចោលទិន្នន័យណាដែលឥតប្រយោជន៍ ដើម្បីបង្រួមទិន្នន័យអោយតូចដោយមិនបាត់បង់អត្ថន័យដើម!
