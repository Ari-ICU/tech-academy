## 🌐 សេចក្តីផ្តើម (Overview)

ហេតុអ្វីបានជា AI ត្រូវការ **Linear Algebra**? ស្រមៃថារូបភាពមួយសន្លឹក (Image) គ្រាន់តែជាតារាង (Matrix) នៃលេខកូដពណ៌។ ការបញ្ជូនរូបភាពនេះចូលទៅក្នុង AI គឺជាការប្រមាណវិធីគុណម៉ាទ្រីស (Matrix Multiplication) រាប់លានដង! **NumPy** គឺជាស្តេចនៃ Linear Algebra នៅក្នុង Python។

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ស្កាលែរ (Scalar - លេខទោល)

ស្កាលែរ គ្រាន់តែជាលេខធម្មតាមួយ ដែលមានតែទំហំប៉ុណ្ណោះ (គ្មានទិសដៅ)។
```python
# ស្កាលែរ
speed = 50
```

### ២. វ៉ិចទ័រ (Vectors - 1D Array)

វ៉ិចទ័រ គឺជាបន្ទាត់នៃលេខដែលមានទិសដៅ និងទំហំ (ដូចជាល្បឿន និងទិសដៅនៃខ្យល់)។
```python
import numpy as np

# វ៉ិចទ័រ (បញ្ជីនៃលេខ ១ វិមាត្រ)
v = np.array([2, 3, 5])
print("វ៉ិចទ័រ:", v)
```

### ៣. ម៉ាទ្រីស (Matrices - 2D Array)

ម៉ាទ្រីស គឺជាតារាងនៃលេខដែលមានជួរដេក និងជួរឈរ (២ វិមាត្រ)។
```python
# ម៉ាទ្រីស (តារាងនៃលេខ ២ វិមាត្រ)
M = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
print("ម៉ាទ្រីស:\n", M)
```
គ្រឹះនេះគឺសំខាន់បំផុត សម្រាប់ការបន្តទៅរៀន Deep Learning (Neural Networks)!
