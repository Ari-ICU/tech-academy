## 🌐 សេចក្តីផ្តើម (Overview)

បើវ៉ិចទ័រប្រៀបដូចជាតារាងមួយជួរ (List) នោះម៉ាទ្រីសគឺប្រៀបដូចជាតារាង Excel ទាំងមូល។ នៅក្នុង Machine Learning រាល់ទិន្នន័យដែលយើងបញ្ចូល (Input Data) និងទម្ងន់របស់ម៉ូដែល (Weights) សុទ្ធតែជាម៉ាទ្រីស!

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. រាងរបស់ម៉ាទ្រីស (Shape)

```python
import numpy as np

# ម៉ាទ្រីស A មាន ២ ជួរដេក និង ៣ ជួរឈរ (2x3)
A = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print("រាងរបស់ម៉ាទ្រីស A គឺ:", A.shape) # ចេញ (2, 3)
```

### ២. ការគុណម៉ាទ្រីស (Matrix Multiplication / Dot Product)

ដូចដែលបានរៀនក្នុង Quiz យើងត្រូវការម៉ាទ្រីស B ដែលមានរាង (3x...) ដើម្បីអាចគុណនឹង A បាន។ យើងនឹងបង្កើត B ជារាង (3x2)។

```python
# ម៉ាទ្រីស B (3x2)
B = np.array([
    [7, 8],
    [9, 10],
    [11, 12]
])

# គុណម៉ាទ្រីស A(2x3) @ B(3x2) នឹងបញ្ចេញលទ្ធផលជារាង (2x2)
C = A @ B 
# ឬអាចសរសេរ np.dot(A, B)

print("លទ្ធផលម៉ាទ្រីស C:\n", C)
```

*ចំណាំ: កុំប្រើសញ្ញាគុណធម្មតា `A * B`! ព្រោះវានឹងគ្រាន់តែយកលេខដែលនៅទីតាំងដូចគ្នាទៅគុណគ្នា (Element-wise) វាមិនមែនជាក្បួន Matrix Multiplication ត្រឹមត្រូវទេ។*

### ៣. ការបង្វិលម៉ាទ្រីស (Transpose)

ពេលខ្លះ យើងចាំបាច់ត្រូវបង្វិលទិន្នន័យ (ប្តូរជួរដេក ទៅជាជួរឈរវិញ) ដើម្បីអោយវាត្រូវវិមាត្រមុននឹងយកទៅគុណ។

```python
# បង្វិលម៉ាទ្រីស A (ពី 2x3 ទៅជា 3x2 វិញ)
A_T = A.T

print("ម៉ាទ្រីស A ដើម:\n", A)
print("បន្ទាប់ពី Transpose:\n", A_T)
```
Transpose ត្រូវបានប្រើប្រាស់គ្រប់ទីកន្លែងក្នុងសរសៃប្រសាទសិប្បនិម្មិត ដើម្បីតម្រង់ទិសទិន្នន័យអោយហូរចូលទៅក្នុងស្រទាប់នីមួយៗ (Layers) បានត្រឹមត្រូវ។
