## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងការសរសេរកម្មវិធីធម្មតា (Software Engineering) យើងប្រើប្រាស់ VS Code ដើម្បីសរសេរកូដរាប់ពាន់បន្ទាត់។ ប៉ុន្តែសម្រាប់ការវិភាគទិន្នន័យ (Data Analysis) និងគណិតវិទ្យា យើងតែងតែចង់ឃើញលទ្ធផល ក៏ដូចជាក្រាហ្វិក "ភ្លាមៗ" បន្ទាប់ពីសរសេរកូដមួយបន្ទាត់។ នោះហើយជាពេលដែល **Jupyter Notebook** (ឬ Google Colab) ចូលមកដើរតួ។

---

## 💡 ចំណុចសំខាន់ៗនៃ Jupyter Notebook

### ១. Code Cells និង Markdown Cells
Jupyter ចែកឯកសារជាក្រឡាៗ (Cells)៖
- **Code Cell:** កន្លែងដែលអ្នកសរសេរកូដ Python និងដំណើរការ (Run) វា។
- **Markdown Cell:** កន្លែងដែលអ្នកសរសេរអត្ថបទ ពន្យល់ ឫសរសេររូបមន្ត។

### ២. ការសរសេររូបមន្តដោយប្រើ LaTeX (នៅក្នុង Markdown Cell)

LaTeX គឺជាភាសាស្តង់ដារសម្រាប់សរសេរនិមិត្តសញ្ញាគណិតវិទ្យានៅក្នុងសៀវភៅ និងឯកសារស្រាវជ្រាវនានា។

សាកល្បងវាយកូដនេះចូលទៅក្នុង Markdown Cell របស់អ្នក៖

```markdown
ទ្រឹស្តីបទពីតាក័រត្រូវបានសរសេរជា៖
$a^2 + b^2 = c^2$

រូបមន្តប្រភាគ៖
$\frac{1}{2}x + 5$

រូបមន្តអាំងតេក្រាល៖
$\int_0^\infty x^2 dx$
```

នៅពេលអ្នក Run Cell នោះ (ចុច `Shift + Enter`) វានឹងប្រែក្លាយកូដខាងលើ ទៅជារូបមន្តដ៏ស្រស់ស្អាតដូចក្នុងសៀវភៅពុម្ពអញ្ចឹង!

### ៣. ការបង្ហាញក្រាហ្វិក (Inline Visualization)

ចំណុចខ្លាំងបំផុតរបស់ Jupyter គឺក្រាហ្វិកដែលអ្នកគូរដោយ Matplotlib នឹងបង្ហាញដោយផ្ទាល់នៅខាងក្រោមកូដរបស់អ្នកតែម្តង។ នេះជួយអោយអ្នកងាយស្រួលសង្កេត និងផ្លាស់ប្តូររូបមន្តគណិតវិទ្យា។
