## 🌐 សេចក្តីផ្តើម (Overview)

តាំងពីថ្នាក់បឋមសិក្សា យើងត្រូវបានបង្រៀនឱ្យគណនាលេខដោយប្រើក្រដាស និងប៊ិច។ ប៉ុន្តែនៅក្នុងយុគសម័យ AI និង Data Science ទិន្នន័យមានរាប់លានជួរ ដែលមនុស្សមិនអាចគណនាដោយដៃបានទេ។ ដូច្នេះហើយទើប **Mathematical Computing** (ការប្រើប្រាស់កុំព្យូទ័រដើម្បីដោះស្រាយគណិតវិទ្យា) ត្រូវបានបង្កើតឡើង។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. គណិតវិទ្យាប្រពៃណី vs ជាមួយ Python

ប្រសិនបើអ្នកចង់រកមធ្យមភាគនៃលេខ 10, 20 និង 30 ដោយដៃ អ្នកត្រូវបូកវាបញ្ចូលគ្នា រួចចែកនឹង 3។ នៅក្នុង Python វិញ៖

```python
# របៀបគណនាបែបកុំព្យូទ័រ
numbers = [10, 20, 30]

average = sum(numbers) / len(numbers)

print("មធ្យមភាគគឺ:", average)
```

### ២. ណែនាំប្រព័ន្ធអេកូឡូស៊ីគណិតវិទ្យារបស់ Python (Ecosystem)

Python មិនមែនគ្រាន់តែជាភាសាសរសេរកូដធម្មតាទេ វាជា "ម៉ាស៊ីនគិតលេខដ៏អស្ចារ្យបំផុត" ដោយសារតែ Library ទាំងនេះ៖

- **`math`**: សម្រាប់ប្រមាណវិធីធម្មតា (ឫសការ៉េ ស៊ីនុស កូស៊ីនុស)។
- **`numpy`**: សម្រាប់លេខរាប់លាន និងម៉ាទ្រីស។
- **`sympy`**: សម្រាប់ពីជគណិត និងសមីការដែលមានអញ្ញាត ($x, y$)។
- **`matplotlib`**: សម្រាប់គូរក្រាហ្វិក។

```python
import math

print("តម្លៃ Pi គឺ:", math.pi)
print("ឫសការ៉េនៃ ១៦ គឺ:", math.sqrt(16))
```
