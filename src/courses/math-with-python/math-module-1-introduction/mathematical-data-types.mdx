## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងគណិតវិទ្យា លេខ ១ និង ១.០ គឺមានន័យដូចគ្នា។ ប៉ុន្តែសម្រាប់កុំព្យូទ័រ ពួកវាត្រូវបានរក្សាទុកក្នុងទម្រង់ (Data Types) ខុសគ្នាស្រឡះ ហើយការប្រើប្រាស់ខុសប្រភេទអាចនាំឱ្យមានបញ្ហាធំ ជាពិសេសក្នុងប្រព័ន្ធហិរញ្ញវត្ថុ!

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ចំនួនគត់ និង ចំនួនទសភាគ (Integer & Float)

```python
x = 10      # Integer (int) - គ្មានក្បៀស
pi = 3.14   # Float - មានក្បៀស

print(type(x))  # <class 'int'>
print(type(pi)) # <class 'float'>
```

### ២. ចំនួនកុំផ្លិច (Complex Numbers)

គណិតវិទ្យាមានចំនួននិម្មិត ($i = \sqrt{-1}$)។ នៅក្នុង Python គេប្រើអក្សរ `j` ជំនួសអក្សរ `i`។ ពួកវាត្រូវបានប្រើច្រើនក្នុងរូបវិទ្យា និងវិស្វកម្ម។

```python
z = 3 + 4j

print("ផ្នែកពិត (Real):", z.real)
print("ផ្នែកនិម្មិត (Imaginary):", z.imag)
```

### ៣. បញ្ហានៃ Floating Point (Floating Point Error)

សាកល្បងរត់កូដនេះក្នុងកុំព្យូទ័ររបស់អ្នក៖
```python
print(0.1 + 0.2)
# លទ្ធផលនឹងចេញ: 0.30000000000000004 (មិនមែន 0.3 ទេ!)
```
ហេតុអ្វី? ព្រោះកុំព្យូទ័រគិតជាលេខ 0 និង 1។ ដើម្បីដោះស្រាយបញ្ហានេះ (ជាពិសេសពេលគិតលុយ) យើងត្រូវប្រើ `Decimal`។

### ៤. ការដោះស្រាយដោយប្រើ `Decimal`

```python
from decimal import Decimal

# ប្រើប្រាស់ Decimal ដោយបញ្ជូលជាអក្សរ (String)
money = Decimal('0.1') + Decimal('0.2')

print(money) # លទ្ធផលចេញ 0.3 ពិតប្រាកដ!
```
ចំណេះដឹងនេះជួយឱ្យអ្នកក្លាយជាអ្នកសរសេរកូដដ៏ប្រុងប្រយ័ត្ន និងជៀសវាងការខាតបង់ថវិកាក្នុងប្រព័ន្ធអាជីវកម្មធំៗ!
