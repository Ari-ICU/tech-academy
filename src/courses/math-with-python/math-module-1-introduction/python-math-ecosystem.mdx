## 🌐 សេចក្តីផ្តើម (Overview)

Python ដោយខ្លួនវាផ្ទាល់ គឺគ្រាន់តែជាភាសាសរសេរកូដធម្មតាប៉ុណ្ណោះ។ អ្វីដែលធ្វើអោយវាល្បីល្បាញដល់ថ្នាក់អ្នកវិទ្យាសាស្ត្រនៅអង្គការ NASA ក៏ប្រើវានោះ គឺដោយសារតែ **Ecosystem (ប្រព័ន្ធអេកូឡូស៊ី)** នៃបណ្ណាល័យ (Libraries) របស់វា។ ក្នុងមេរៀននេះ យើងនឹងពិនិត្យមើល "អាវុធ" ទាំង ៤ របស់អ្នកសម្រាប់មុខវិជ្ជានេះ។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. Standard Library: `math`

បណ្ណាល័យ `math` មានភ្ជាប់មកជាមួយ Python ស្រាប់។ វាប្រើសម្រាប់ការគណនាធម្មតា។

```python
import math

print("តម្លៃ Pi:", math.pi)
print("ឫសការ៉េនៃ ២៥:", math.sqrt(25))
print("ស៊ីនុសនៃ ៩០ ដឺក្រេ (គិតជារ៉ាដ្យង់):", math.sin(math.radians(90)))
```

### ២. Numerical Computation: `NumPy`

`NumPy` គឺលឿនជាង Python List ធម្មតា ព្រោះវាត្រូវបានសរសេរដោយភាសា C។ វាស័ក្តិសមបំផុតសម្រាប់ទិន្នន័យធំៗ។

```python
import numpy as np

# បង្កើត Array ទំហំធំ
numbers = np.array([1, 2, 3, 4, 5])
print("គុណគ្រប់ធាតុនឹង ២ ក្នុងពេលតែមួយ:", numbers * 2)
```

### ៣. Symbolic Mathematics: `SymPy`

`SymPy` អនុញ្ញាតអោយកុំព្យូទ័រគិតដូចមនុស្ស គឺការរក្សាអញ្ញាត។

```python
import sympy as sp

# កំណត់អញ្ញាត x
x = sp.symbols('x')

# ដោះស្រាយសមីការ x + 5 = 10
solution = sp.solve(x + 5 - 10, x)
print("តម្លៃ x គឺ:", solution)
```

### ៤. Visualization: `Matplotlib`

បើគ្មានការបង្ហាញជារូបភាពទេ គណិតវិទ្យាគឺស្ងួត និងគួរអោយធុញ។ `Matplotlib` ជាអ្នកគូរក្រាហ្វិក។

```python
import matplotlib.pyplot as plt

x_vals = [1, 2, 3, 4]
y_vals = [1, 4, 9, 16] # x ការ៉េ

plt.plot(x_vals, y_vals, marker='o')
plt.title("ក្រាហ្វិក y = x^2")
plt.show()
```
