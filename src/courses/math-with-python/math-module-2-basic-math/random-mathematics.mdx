## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុង AI ជារឿយៗយើងត្រូវចាប់ផ្តើមការ Training ដោយទម្ងន់ចៃដន្យ (Random Weights) ឬយើងត្រូវទាញយកទិន្នន័យសំណាក (Random Sampling) ដើម្បីកុំអោយមានភាពលម្អៀង (Bias)។ Python ផ្តល់នូវបណ្ណាល័យ `random` យ៉ាងសាមញ្ញសម្រាប់កិច្ចការនេះ!

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. លេខគត់ចៃដន្យ `randint()`

```python
import random

# បោះគ្រាប់ឡុកឡាក់ (ពីលេខ ១ ដល់ ៦)
dice_roll = random.randint(1, 6)
print("អ្នកបោះបានលេខ:", dice_roll)
```

### ២. លេខទសភាគចៃដន្យ (ប្រូបាប) `random()`

វាបង្កើតលេខពី $0.0$ ដល់ $0.999...$។

```python
# បង្កើតឱកាស ៥០% (ដូចបោះកាក់)
chance = random.random()

if chance < 0.5:
    print("ចេញ ក្បាល")
else:
    print("ចេញ កន្ទុយ")
```

### ៣. ការចាប់ឆ្នោត (Random Choice)

ជំនួសអោយការបង្កើតលេខ អ្នកអាចអោយ Python រើសយកធាតុណាមួយដោយចៃដន្យពីក្នុងបញ្ជី។

```python
colors = ["ក្រហម", "ខៀវ", "បៃតង", "លឿង"]

# រើសពណ៌មួយដោយចៃដន្យ
winner_color = random.choice(colors)
print("ពណ៌ដែលឈ្នះឆ្នោតគឺ:", winner_color)
```

នៅក្នុងមេរៀនក្រោយៗ យើងនឹងប្រើប្រាស់ `numpy.random` ដែលអាចបង្កើតលេខចៃដន្យរាប់លានក្នុងពេលតែមួយ!
