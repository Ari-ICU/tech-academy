## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ប្រមាណវិធីធម្មតា

```python
x = 10
y = 3

print("បូក:", x + y) # 13
print("ដក:", x - y) # 7
print("គុណ:", x * y) # 30
print("ចែក (ចេញទសភាគ):", x / y) # 3.3333333333333335
```

### ២. ស្វ័យគុណ (Power) 

នៅក្នុងគណិតវិទ្យាយើងសរសេរ $10^2$ ចំណែកក្នុង Python យើងប្រើសញ្ញាផ្កាយពីរ `**`។
```python
print("10 ស្វ័យគុណ 2 គឺ:", x ** 2) # 100
```

### ៣. ការចែកយកចំនួនគត់ និងការរកសំណល់

ពេលខ្លះអ្នកមិនចង់បានលេខទសភាគទេ ឧទាហរណ៍បើអ្នកចែកមនុស្ស មិនអាចមានមនុស្ស ៣.៣ នាក់នោះទេ។

```python
print("ចែកយកតែចំនួនគត់ (Floor Division):", 10 // 3) # 3
print("ចែកយកតែសំណល់ (Modulus):", 10 % 3) # 1
```

*ចំណាំ៖ សញ្ញា `%` ត្រូវបានគេប្រើប្រាស់យ៉ាងច្រើននៅក្នុង Programming ដើម្បីឆែកមើលថាតើលេខមួយជា លេខគូ ឫ លេខសេស (បើចែកនឹង ២ សល់ ០ គឺលេខគូ)។*
