## 🌐 សេចក្តីផ្តើម (Overview)

ពេលអ្នកធ្វើការជាមួយលុយ ឫរង្វាស់រង្វាល់ អ្នកមិនចង់បង្ហាញលេខ `10.333333333` ទៅកាន់អតិថិជននោះទេ។ អ្នកត្រូវចេះបង្កត់លេខអោយបានត្រឹមត្រូវ។ នៅក្នុង Python ការបង្កត់លេខមានច្រើនរបៀបទៅតាមកាលៈទេសៈ!

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការបង្កត់លេខតាមក្បួនគណិតវិទ្យាធម្មតា `round()`

បើចាប់ពីក្បៀស ៥ ឡើងលើវានឹងបង្កត់ឡើង បើក្រោម ៥ វានឹងបង្កត់ចុះ។ អ្នកក៏អាចកំណត់ចំនួនខ្ទង់ទសភាគ (Precision) បានដែរ។

```python
pi = 3.14159

# បង្កត់យកចំនួនគត់
print(round(pi)) # ចេញ 3

# បង្កត់យកទសភាគ ២ ខ្ទង់
print(round(pi, 2)) # ចេញ 3.14
```

### ២. បង្កត់ឡើងលើជានិច្ច `math.ceil()`

ឧបមាថាអ្នកមានភ្ញៀវ ២១ នាក់។ ឡានមួយជិះបាន ១០ នាក់។ ដូច្នេះអ្នកត្រូវការឡាន $21 / 10 = 2.1$ ឡាន។ អ្នកមិនអាចជួលឡាន ២.១ គ្រឿងបានទេ អ្នកត្រូវតែជួលឡាន ៣ គ្រឿង!

```python
import math

cars_needed = 21 / 10
print(math.ceil(cars_needed)) # ចេញ 3 (បង្កត់ឡើងលើរហូត)
```

### ៣. បង្កត់ចុះក្រោមជានិច្ច `math.floor()`

ឧបមាថាអ្នកមានលុយ $10 ឯនំមួយថ្លៃ $3។ អ្នកអាចទិញបាន $10 / 3 = 3.33$ នំ។ អ្នកមិនអាចទិញនំ ៣.៣៣ បានទេ ដូច្នេះអ្នកបាននំតែ ៣ ប៉ុណ្ណោះ ទោះបីសល់លុយក៏ដោយ។

```python
cakes_bought = 10 / 3
print(math.floor(cakes_bought)) # ចេញ 3 (បង្កត់ចុះក្រោមរហូត)
```
