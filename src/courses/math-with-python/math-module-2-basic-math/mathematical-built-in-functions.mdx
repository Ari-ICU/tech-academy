## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងគណិតវិទ្យា យើងតែងតែចងចាំរូបមន្តវែងៗ។ ប៉ុន្តែក្នុង Python អ្នកមិនបាច់សរសេរក្បួនដោះស្រាយដើម្បីរកឫសការ៉េដោយខ្លួនឯងទេ។ Python មាន "ប្រអប់ឧបករណ៍" រួចជាស្រេច ដែលអនុញ្ញាតឱ្យអ្នកគណនាវាដោយគ្រាន់តែហៅឈ្មោះវាមកប្រើ!

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. តម្លៃដាច់ខាត (Absolute Value)

នៅក្នុង AI ពេលយើងវាស់កំហុស (Error) យើងមិនចង់បានលេខអវិជ្ជមានទេ។ $abs(x)$ ឬ $|x|$ ផ្លាស់ប្តូរលេខទាំងអស់អោយវិជ្ជមាន។

```python
error_1 = 10
error_2 = -15

print("តម្លៃដាច់ខាត:", abs(error_2)) # 15
```
*ចំណាំ៖ `abs()` អាចប្រើបានដោយផ្ទាល់ មិនបាច់ `import math` ទេ។*

### ២. ឫសការ៉េ និង ស្វ័យគុណ (Square Root & Power)

```python
import math

# ឫសការ៉េនៃ ២៥ (ចេញ ៥.០)
print("ឫសការ៉េ (Square Root):", math.sqrt(25)) 

# ២ ស្វ័យគុណ ៣ (២ គុណ ២ គុណ ២)
print("ស្វ័យគុណ (Power):", math.pow(2, 3)) 
# អាចសរសេរជា 2 ** 3 ក៏បាន
```

### ៣. ហ្វាក់តូរីយ៉ែល (Factorial)

$5! = 5 \times 4 \times 3 \times 2 \times 1 = 120$។ ហ្វាក់តូរីយ៉ែល ត្រូវបានប្រើប្រាស់យ៉ាងច្រើននៅក្នុងមេរៀនប្រូបាប៊ីលីតេ។

```python
# គណនា 5!
print("ហ្វាក់តូរីយ៉ែល ៥! គឺ:", math.factorial(5))
```
