## 🌐 សេចក្តីផ្តើម (Overview)

មនុស្សយើងរាប់លេខដោយប្រើប្រាស់ប្រព័ន្ធគោល ១០ (ពីលេខ ០ ដល់ ៩) ព្រោះយើងមានម្រាមដៃ ១០។ កុំព្យូទ័រមានតែចរន្តអគ្គិសនី (បិទ និង បើក) ទើបវាប្រើប្រព័ន្ធគោល ២ (0 និង 1) ដែលហៅថា **Binary**។ ក្រៅពីនេះ នៅមានប្រព័ន្ធមួយទៀតដែលពេញនិយមក្នុងការកំណត់ពណ៌ក្នុង Website និងទិន្នន័យ គឺប្រព័ន្ធគោល ១៦ ដែលហៅថា **Hexadecimal**។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ប្រព័ន្ធគោល ២ (Binary)

ដើម្បីបំប្លែងលេខមនុស្សទៅជាលេខកុំព្យូទ័រ យើងប្រើ `bin()`។ លទ្ធផលនឹងមានអក្សរ `0b` នៅខាងមុខ ដែលបញ្ជាក់ថាវាជា Binary។

```python
number = 10
binary_num = bin(number)

print(f"លេខ {number} ជា Binary គឺ: {binary_num}") 
# ចេញ: 0b1010
```

### ២. ប្រព័ន្ធគោល ១៦ (Hexadecimal)

ប្រព័ន្ធនេះប្រើលេខ ០-៩ និងអក្សរ A-F។ វាមានអក្សរ `0x` នៅខាងមុខ។ ពណ៌ស គឺ `FFFFFF` ពណ៌ខ្មៅ គឺ `000000`។

```python
color_value = 255
hex_num = hex(color_value)

print(f"លេខ {color_value} ជា Hexadecimal គឺ: {hex_num}")
# ចេញ: 0xff (ដែលយើងស្គាល់ថាជាពណ៌សពេលផ្សំបញ្ចូលគ្នា)
```

### ៣. បំប្លែងត្រលប់មកលេខធម្មតាវិញ (Decimal)

```python
# ប្រាប់ Python ថាវាជាគោល ១៦
dec_from_hex = int('ff', 16) 
print("0xff ទៅជាលេខធម្មតា:", dec_from_hex) # 255

# ប្រាប់ Python ថាវាជាគោល ២
dec_from_bin = int('1010', 2) 
print("0b1010 ទៅជាលេខធម្មតា:", dec_from_bin) # 10
```
