## 🌐 សេចក្តីផ្តើម (Overview)

គ្រាន់តែដឹងពី "មធ្យមភាគ (Mean)" គឺមិនគ្រាប់គ្រាន់ទេ។ បើអ្នកឆ្លងស្ទឹងដែលមានជម្រៅទឹក "ជាមធ្យម ១ ម៉ែត្រ" អ្នកអាចលង់ទឹកស្លាប់បាន បើស្ទឹងនោះមានកន្លែងរាក់ (០.១ម) និងកន្លែងជ្រៅខ្លាំង (៥ម)! ដូច្នេះអ្នកត្រូវដឹងពី **កម្រិតនៃការរាយប៉ាយ (Spread/Dispersion)** របស់ទិន្នន័យ។

## 💻 ការបំបែកកូដ (Code Breakdown)

### របៀបគណនា Standard Deviation (std)

នៅទីនេះ យើងមានពិន្ទុរបស់សិស្សថ្នាក់ទី ១ (ពូកែស្មើៗគ្នា) និងថ្នាក់ទី ២ (អ្នកខ្សោយខ្លាំង និងពូកែខ្លាំងនៅលាយឡំគ្នា)។ ថ្នាក់ទាំងពីរមានមធ្យមភាគពិន្ទុ $75$ ដូចគ្នា!

```python
import numpy as np

# ថ្នាក់ទី ១ (ទិន្នន័យផ្តុំគ្នា)
class_1 = np.array([73, 74, 75, 76, 77])

# ថ្នាក់ទី ២ (ទិន្នន័យរាយប៉ាយ)
class_2 = np.array([40, 50, 75, 100, 110])

print("មធ្យមភាគ ថ្នាក់ទី ១:", np.mean(class_1)) # 75.0
print("មធ្យមភាគ ថ្នាក់ទី ២:", np.mean(class_2)) # 75.0

# គណនា Standard Deviation (std)
std_1 = np.std(class_1)
std_2 = np.std(class_2)

print(f"គម្លាតស្តង់ដារ ថ្នាក់ទី ១: {std_1:.2f}") # ប្រហែល 1.41
print(f"គម្លាតស្តង់ដារ ថ្នាក់ទី ២: {std_2:.2f}") # ប្រហែល 26.83
```

**អត្ថន័យ៖** 
- `std_1 = 1.41` មានន័យថាសិស្សថ្នាក់ទី ១ ភាគច្រើនមានពិន្ទុខុសពីមធ្យមភាគ (75) ត្រឹមតែ ១ ទៅ ២ ពិន្ទុប៉ុណ្ណោះ។
- `std_2 = 26.83` មានន័យថាសិស្សថ្នាក់ទី ២ ពិន្ទុខុសពីមធ្យមភាគដល់ទៅជិត ២៧ ពិន្ទុឯណោះ (រាយប៉ាយខ្លាំង)! 

*ចំណាំ: ក្នុង NumPy `np.std()` គណនា Population ដោយស្វ័យប្រវត្តិ។ បើចង់គណនា Sample ត្រូវថែមប៉ារ៉ាម៉ែត្រ `ddof=1` (Degrees of freedom)។*
