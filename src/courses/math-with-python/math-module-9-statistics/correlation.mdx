## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុង Data Science សំណួរដែលគេតែងសួរជាងគេគឺ៖ "តើអ្វីដែលប៉ះពាល់ដល់ការលក់ שלנו?" ការចង់ដឹងថាទិន្នន័យពីរទាក់ទងគ្នា (ប្រែប្រួលតាមគ្នា) កម្រិតណានោះ គឺត្រូវគណនា **Correlation (សហសម្ព័ន្ធ)**។

## 💻 ការបំបែកកូដ (Code Breakdown)

### គណនា Correlation ជាមួយ Pandas / NumPy

ឧបមាថាយើងតាមដាន **សីតុណ្ហភាព (X)** និង **ចំនួនការលក់ការ៉េម (Y)** ប្រចាំថ្ងៃ។

```python
import numpy as np
import matplotlib.pyplot as plt

# ទិន្នន័យ ៥ ថ្ងៃ
temp = np.array([25, 30, 32, 35, 40]) # ក្តៅឡើងៗ
sales = np.array([50, 70, 80, 100, 120]) # ការលក់ក៏កើនឡើងៗ

# គណនា Correlation Coefficient (Pearson)
# វានឹងបញ្ចេញមកជាម៉ាទ្រីស 2x2 យើងយក [0, 1] ដែលជាការប្រៀបធៀប X និង Y
corr = np.corrcoef(temp, sales)[0, 1]

print(f"ទំនាក់ទំនង (Correlation) គឺ: {corr:.2f}") 
# លទ្ធផលប្រហែល 0.99 (ទាក់ទងគ្នាខ្លាំងមែនទែន!)

# គូរក្រាហ្វិក Scatter Plot ដើម្បីមើលនិន្នាការ
plt.scatter(temp, sales, color='red')
plt.title(f"ទំនាក់ទំនងរវាងកម្តៅថ្ងៃ និងការលក់ការ៉េម (r={corr:.2f})")
plt.xlabel("សីតុណ្ហភាព (អង្សាសេ)")
plt.ylabel("ចំនួនការ៉េមលក់បាន")
plt.show()
```

ក្រាហ្វិកនេះបង្ហាញយ៉ាងច្បាស់ថា ចំណុចទាំងអស់រៀបរយជាជួរកាត់បញ្ឆៀងឡើងលើ! (Positive Correlation)។

> [!WARNING]
> **Correlation is NOT Causation!**
> ទោះបីសីតុណ្ហភាព និងការលក់ការ៉េមឡើងព្រមគ្នាមែន ប៉ុន្តែការឡើងកម្តៅផែនដី មិនមែនបណ្តាលមកពីការលក់ការ៉េមដាច់នោះទេ! ការទាក់ទងគ្នា មិនមែនមានន័យថាវាជា "មូលហេតុ" របស់គ្នានោះឡើយ!
