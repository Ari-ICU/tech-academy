## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងមេរៀនមុន (Correlation) យើងគ្រាន់តែដឹងថាវា "ទាក់ទងគ្នា"។ ប៉ុន្តែនៅក្នុង **Regression** យើងយកចំណេះដឹងពីជគណិត $y = mx + c$ មកប្រើ ដើម្បីទស្សន៍ទាយ (Predict) តែម្តង! នេះគឺជាទម្រង់សាមញ្ញបំផុតនៃ **AI / Machine Learning**!

## 💻 ការបំបែកកូដ (Code Breakdown)

### ការរកបន្ទាត់ដែលល្អបំផុត (Line of Best Fit)

ឧបមាថាយើងមានទិន្នន័យ (សីតុណ្ហភាព និងការ៉េមដដែល)។ តើបើថ្ងៃស្អែកសីតុណ្ហភាពឡើងដល់ ៤៥ អង្សា តើយើងអាចលក់ការ៉េមបានប៉ុន្មាន?

```python
import numpy as np
import matplotlib.pyplot as plt

# ទិន្នន័យដើម
temp = np.array([25, 30, 32, 35, 40])
sales = np.array([50, 70, 80, 100, 120])

# ១. ប្រើ NumPy ដើម្បីរកសមីការបន្ទាត់ (deg=1 មានន័យថាបន្ទាត់ត្រង់/លីនេអ៊ែរ)
# វាបញ្ចេញមេគុណ m (slope) និង c (intercept) នៃ y = mx + c
coefficients = np.polyfit(temp, sales, deg=1)
m, c = coefficients
print(f"សមីការបន្ទាត់គឺ: y = {m:.2f}x + {c:.2f}")

# ២. ធ្វើការទស្សន៍ទាយថ្ងៃអនាគត
future_temp = 45
predicted_sales = (m * future_temp) + c
print(f"បើថ្ងៃស្អែកក្តៅ 45 អង្សា យើងប្រហែលជាលក់បាន: {predicted_sales:.0f} ដើម!")

# ៣. គូរក្រាហ្វិកបង្ហាញពីបន្ទាត់ទស្សន៍ទាយ (Regression Line)
plt.scatter(temp, sales, color='red', label="ទិន្នន័យពិត")

# បង្កើតចន្លោះបន្ទាត់ពី ២០ ដល់ ៥០
x_line = np.array([20, 50])
y_line = m * x_line + c
plt.plot(x_line, y_line, color='blue', label="បន្ទាត់ AI ទស្សន៍ទាយ")

plt.xlabel("សីតុណ្ហភាព")
plt.ylabel("ការ៉េម")
plt.legend()
plt.show()
```
