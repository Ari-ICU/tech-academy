## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងការងារពិត ទិន្នន័យកម្រនឹងមានរាងកណ្តឹង (Normal) ដ៏ស្រស់ស្អាតណាស់។ ពេលខ្លះវាលម្អៀងទៅខាងស្តាំ (ដូចជាប្រាក់ខែ ដែលមានអ្នកមានស្តុកស្តម្ភមួយក្តាប់តូចទាញទិន្នន័យអោយលម្អៀង)។ ដើម្បីមើលឃើញភាពមិនប្រក្រតីនេះយ៉ាងរហ័ស គេប្រើ **Boxplot**។

## 💻 ការបំបែកកូដ (Code Breakdown)

### គូរក្រាហ្វិក Boxplot ដើម្បីចាប់ Outliers

ឧបមាថាយើងមានទិន្នន័យតម្លៃផ្ទះនៅក្នុងតំបន់មួយ។ ផ្ទះភាគច្រើនមានតម្លៃចន្លោះពី ៥ម៉ឺន ទៅ ១០ម៉ឺន។ ប៉ុន្តែមានផ្ទះវីឡាមួយតម្លៃដល់ទៅ ៥០ម៉ឺនដុល្លារ! 

```python
import numpy as np
import matplotlib.pyplot as plt

# ទិន្នន័យតម្លៃផ្ទះ (គិតជាពាន់ដុល្លារ)
house_prices = [45, 50, 55, 60, 65, 70, 75, 80, 500] 
# លេខ 500 គឺជា Outlier!

plt.boxplot(house_prices, vert=False) # vert=False គឺគូរជាទម្រង់ផ្តេក
plt.title("Boxplot បង្ហាញពីតម្លៃផ្ទះ")
plt.xlabel("តម្លៃ (ពាន់ដុល្លារ)")
plt.show()
```

### ការបកស្រាយ Boxplot:
1. **ប្រអប់ (Box):** តំណាងអោយ 50% នៃផ្ទះដែលមានតម្លៃកណ្តាលៗ។ គែមឆ្វេង (Q1=25%), គែមស្តាំ (Q3=75%) និងបន្ទាត់ក្រហមចំកណ្តាលគឺ Median (Q2=50%)។
2. **ពុកមាត់ (Whiskers):** តំណាងអោយតម្លៃដែលនៅអាចទទួលយកបាន (មិនទាន់ចម្លែកពេក)។
3. **ចំណុចមូល (Dots/Fliers):** អ្នកនឹងឃើញមានចំណុចមូលមួយនៅខាងស្តាំដៃឆ្ងាយជាងគេ ត្រង់លេខ 500។ នោះហើយគឺជា **Outlier** ឫផ្ទះវីឡានោះឯង!

ការយល់ដឹងពីរបាយ និង Outliers គឺជាជំហានសំអាតទិន្នន័យ (Data Cleaning) មុននឹងបញ្ចុកវាទៅអោយ AI រៀន។ ព្រោះ AI ងាយនឹងមានកំហុសណាស់បើវារៀនពី Outliers ច្រើនពេក។
