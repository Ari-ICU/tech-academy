## 🌐 សេចក្តីផ្តើម (Overview)

ទិន្នន័យដោយគ្មានស្ថិតិ គឺគ្រាន់តែជាបញ្ជីលេខដ៏គួរឱ្យធុញប៉ុណ្ណោះ។ ស្ថិតិពិពណ៌នា (Descriptive Statistics) គឺជាឧបករណ៍ដែលជួយយើងក្នុងការ "សង្ខេប" រឿងរ៉ាវរបស់ទិន្នន័យ អោយទៅជាតួលេខដែលអាចយល់បាន។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

### ការប្រើប្រាស់បណ្ណាល័យ `statistics`

Python មានបណ្ណាល័យស្តង់ដារមួយឈ្មោះថា `statistics` ដែលមានស្រាប់ (មិនបាច់ install)។

```python
import statistics

salaries = [300, 350, 400, 320, 380, 15000] # 15000 គឺជា Outlier (នាយក)

# ១. មធ្យមភាគ (Mean - បូកបញ្ចូលគ្នា រួចចែកនឹងចំនួន)
mean_salary = statistics.mean(salaries)
print(f"ប្រាក់ខែមធ្យម (Mean): ${mean_salary:.2f}") 
# ចេញលទ្ធផលខ្ពស់ខ្លាំង ($2791.67) ធ្វើឱ្យមានការយល់ច្រឡំ

# ២. មេដ្យាន (Median - តម្លៃនៅចំកណ្តាលគេ ក្រោយពេលតម្រៀប)
median_salary = statistics.median(salaries)
print(f"ប្រាក់ខែនៅកណ្តាលគេ (Median): ${median_salary:.2f}")
# ចេញលទ្ធផលត្រឹមត្រូវតាមទិន្នន័យពិតប្រាកដ ($365.00)

# ៣. ម៉ូត (Mode - តម្លៃដែលលេចឡើងច្រើនដងជាងគេ)
# ឧទាហរណ៍ទិន្នន័យថ្មី៖
ages = [22, 25, 22, 30, 35, 22]
mode_age = statistics.mode(ages)
print(f"អាយុដែលពេញនិយមជាងគេ (Mode): {mode_age} ឆ្នាំ")
```

ការចេះជ្រើសរើសរវាង Mean និង Median គឺជាជំនាញទី ១ ដែល Data Analyst គ្រប់រូបត្រូវតែមាន!
