## 🌐 សេចក្តីផ្តើម (Overview)

សមីការដឺក្រេទីពីរមានទម្រង់ $ax^2 + bx + c = 0$ ដែលក្រាហ្វរបស់វាមានរាងកោងដូចអក្សរ U (ប៉ារ៉ាបូល)។ ចម្លើយរបស់វាគឺចំណុចដែលខ្សែកោងកាត់អ័ក្ស $x$។ ជាទូទៅ វាមាន ២ ចម្លើយ!

---

## 💻 ការបំបែកកូដ (Code Breakdown)

### ការរកឫស (Roots) នៃសមីការ

តោះសាកល្បងដោះស្រាយសមីការនេះ៖
$$ x^2 - 5x + 6 = 0 $$

នៅសាលា អ្នកត្រូវរៀនគណនាឌីស្គ្រីមីណង់ (Discriminant $\Delta = b^2 - 4ac$) ដ៏ស្មុគស្មាញ។ តែក្នុង Python:

```python
import sympy as sp

x = sp.symbols('x')

# កំណត់កន្សោមសមីការ
equation = x**2 - 5*x + 6

# ដោះស្រាយសមីការ
roots = sp.solve(equation, x)

print("ឫសនៃសមីការមាន:", roots)
# លទ្ធផលនឹងចេញ List មួយដែលមានពីរចម្លើយ: [2, 3]
```

### ចុះបើគ្មានចម្លើយជាលេខពិត?

ពេលខ្លះ ក្រាហ្វអណ្តែតផុតអ័ក្ស $x$ ធ្វើអោយសមីការគ្មានចម្លើយ (ឧទាហរណ៍ $x^2 + 1 = 0$)។ ក្នុងករណីនេះ SymPy នឹងបញ្ចេញចម្លើយជា "ចំនួនកុំផ្លិច (Complex Numbers)" ជូនអ្នកដោយស្វ័យប្រវត្តិ ដែលមានតួ $I$ ជាប់ជាមួយ!

```python
equation_2 = x**2 + 1
roots_2 = sp.solve(equation_2, x)

print("ចម្លើយនៃ x^2 + 1 = 0 គឺ:", roots_2)
# លទ្ធផល: [-I, I] (I គឺចំនួននិម្មិត i)
```
