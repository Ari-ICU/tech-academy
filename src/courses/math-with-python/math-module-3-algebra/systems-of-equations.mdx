## 🌐 សេចក្តីផ្តើម (Overview)

ជារឿយៗ បញ្ហាក្នុងជីវិតពិតមិនមានត្រឹមតែអញ្ញាតមួយទេ។ ឧទាហរណ៍៖ "សៀវភៅ ១ និងប៊ិច ១ ថ្លៃ $10$, តែសៀវភៅ ១ និងប៊ិច ៣ ថ្លៃ $14$"។ តើសៀវភៅមួយ និងប៊ិចមួយ មានតម្លៃប៉ុន្មាន? បញ្ហាបែបនេះហៅថា ប្រព័ន្ធសមីការ (System of Equations) ពោលគឺសមីការពីរ ឫច្រើនភ្ជាប់គ្នា។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. តំណាងបញ្ហាជាសមីការ

តាង $x$ ជាតម្លៃសៀវភៅ ហេីយ $y$ ជាតម្លៃប៊ិច៖
1. $x + y = 10$
2. $x + 3y = 14$

យើងត្រូវប្តូរវាអោយស្មើ $0$៖
1. $x + y - 10 = 0$
2. $x + 3y - 14 = 0$

### ២. ការដោះស្រាយជាមួយ SymPy

យើងអាចអោយ `sp.solve()` នូវសមីការទាំងពីរ (ជាទម្រង់ List `[]`) ដើម្បីអោយវាដោះស្រាយក្នុងពេលតែមួយ។

```python
import sympy as sp

# ប្រកាសអញ្ញាតទាំង ២ ក្នុងពេលតែមួយ
x, y = sp.symbols('x y')

# កំណត់សមីការទាំងពីរ
eq1 = x + y - 10
eq2 = x + 3*y - 14

# ដោះស្រាយ (បញ្ជូន List នៃសមីការ និង List នៃអញ្ញាត)
solution = sp.solve([eq1, eq2], [x, y])

print("ចម្លើយគឺ:", solution)
# លទ្ធផល: {x: 8, y: 2} (សៀវភៅ ៨$ ប៊ិច ២$)
```

នៅក្នុង Machine Learning, Data Scientists តែងតែជួបប្រទះប្រព័ន្ធសមីការដែលមានអញ្ញាតរាប់ពាន់រាប់ម៉ឺន (រាប់សែន Features)។ ទោះបី SymPy ល្អសម្រាប់សមីការតូចៗ តែបើជួបទិន្នន័យរាប់ម៉ឺន យើងនឹងប្តូរទៅប្រើប្រាស់ **NumPy** និង **Linear Algebra (ម៉ាទ្រីស)** វិញក្នុងម៉ូឌុលទី ៦។
