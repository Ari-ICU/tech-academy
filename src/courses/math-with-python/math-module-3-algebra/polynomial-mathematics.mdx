## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងពិភពពីជគណិត ការពង្រាត (Expand) និងការដាក់ជាផលគុណកត្តា (Factorize) គឺជារឿងដែលគួរឱ្យធុញទ្រាន់បំផុត ពិសេសនៅពេលដែលស្វ័យគុណមានទំហំធំ។ តែពេលនេះ កុំព្យូទ័រអាចធ្វើវាជំនួសអ្នកបានត្រឹមមួយវិនាទី!

---

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការពង្រាតកន្សោម (Expand)

តើអ្នកនៅចាំរូបមន្ត $(a+b)^2 = a^2 + 2ab + b^2$ ទេ? ចុះបើ $(x+2)^5$ វិញ?

```python
import sympy as sp

x = sp.symbols('x')

# កន្សោមដើម
expr = (x + 2)**5

# ពង្រាតវា
expanded_expr = sp.expand(expr)
print("បន្ទាប់ពីពង្រាត:", expanded_expr)
# លទ្ធផល: x**5 + 10*x**4 + 40*x**3 + 80*x**2 + 80*x + 32
```

### ២. ដាក់ជាផលគុណកត្តា (Factor)

ឧបមាថាអ្នកមានកន្សោមដ៏វែងអន្លាយមួយ ហើយចង់ផ្តុំវាអោយខ្លីវិញ។

```python
long_expr = x**3 - x**2 - 14*x + 24

# ដាក់ជាផលគុណកត្តា
factored_expr = sp.factor(long_expr)
print("ជាផលគុណកត្តា:", factored_expr)
# លទ្ធផល: (x - 3)*(x - 2)*(x + 4)
```

### ៣. ការធ្វើសាមញ្ញកម្ម (Simplify)

បើអ្នកមិនច្បាស់ថាគួរ Expand ឫ Factor ទេ គ្រាន់តែប្រាប់អោយ `simplify()` ធ្វើការសម្រួលអោយអ្នក!

```python
complex_expr = (x**2 - x - 6)/(x**2 - 3*x)

# សម្រួលប្រភាគ
simple_expr = sp.simplify(complex_expr)
print("បន្ទាប់ពីសម្រួល:", simple_expr)
# លទ្ធផល: (x + 2)/x
```
ជាមួយជំនាញនេះ អ្នកប្រៀបដូចជាមានម៉ាស៊ីនគិតលេខវេទមន្តនៅក្នុងដៃអញ្ចឹង!
