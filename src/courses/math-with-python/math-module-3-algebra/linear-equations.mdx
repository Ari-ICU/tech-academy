## 🌐 សេចក្តីផ្តើម (Overview)

សមីការលីនេអ៊ែរ (សមីការបន្ទាត់ត្រង់) គឺជាសមីការមូលដ្ឋានបំផុតដែលគ្មានស្វ័យគុណ។ ឧទាហរណ៍៖ "បើអ្នកទិញសៀវភៅ ២ ក្បាល ហើយឱ្យលុយធីប ៥ ដុល្លារ អស់លុយសរុប ១៥ ដុល្លារ តើសៀវភៅមួយក្បាលថ្លៃប៉ុន្មាន?" គណិតវិទ្យាសរសេរថា $2x + 5 = 15$។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ការរៀបចំសមីការ

មុននឹងដោះស្រាយ អ្នកត្រូវរៀបចំសមីការអោយទៅជាទម្រង់ស្មើ $0$ សិន។
$$ 2x + 5 = 15 $$
ប្តូរទៅជា៖
$$ 2x + 5 - 15 = 0 $$

### ២. ដោះស្រាយជាមួយ SymPy

ឥឡូវនេះ យើងអាចប្រាប់ Python អោយរកចម្លើយជំនួសយើងបានយ៉ាងងាយ!

```python
import sympy as sp

# ១. ប្រាប់ Python ថា x ជាអញ្ញាត មិនមែនជាអថេរធម្មតាទេ
x = sp.symbols('x')

# ២. សរសេរកន្សោមដែលស្មើ 0 (2*x + 5 - 15)
equation = 2*x + 5 - 15

# ៣. ប្រើអនុគមន៍ solve() ដើម្បីរកចម្លើយ
solution = sp.solve(equation, x)

print("តម្លៃសៀវភៅមួយក្បាល (x) គឺ:", solution[0])
# លទ្ធផល: 5
```

ដូចដែលអ្នកឃើញ SymPy បានរកឃើញចម្លើយ $x = 5$ យ៉ាងត្រឹមត្រូវ។ វានឹងកាន់តែមានប្រយោជន៍ នៅពេលដែលសមីការកាន់តែវែង និងស្មុគស្មាញដែលយើងពិបាកគិតដោយដៃ!
