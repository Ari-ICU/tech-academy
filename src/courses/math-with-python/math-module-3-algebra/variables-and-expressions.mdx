## 🌐 សេចក្តីផ្តើម (Overview)

នៅក្នុងម៉ោងរៀនពីជគណិត (Algebra) អ្នកតែងតែលឺគ្រូនិយាយថា "រក $x$" ។ អថេរ (Variable) ដូចជា $x$ ឬ $y$ គ្រាន់តែជាប្រអប់ទទេមួយដែលយើងទុកសម្រាប់ដាក់លេខចូលប៉ុណ្ណោះ។ នៅក្នុង Programming អថេរដើរតួនាទីយ៉ាងសំខាន់ក្នុងការរក្សាទិន្នន័យ។

---

## 💻 ការបំបែកកូដ (Code Breakdown)

### ១. ពីក្រដាស មកកូដ

ឧបមាថាអ្នកចង់គណនាក្រឡាផ្ទៃចតុកោណកែង ដែលមានរូបមន្តពិតប្រាកដគឺ៖
$$ Area = width \times height $$

នៅក្នុង Python អ្នកគ្រាន់តែប្រកាសអថេរ ហើយបញ្ចូលតម្លៃ៖

```python
# កំណត់អថេរ (Variables)
width = 5
height = 10

# អនុវត្តកន្សោមគណិតវិទ្យា (Expression)
area = width * height

print("ក្រឡាផ្ទៃគឺ:", area)
```

### ២. ការប្រើប្រាស់រូបមន្តស្មុគស្មាញ

ចូរយកចំណេះដឹងពីមេរៀនមុនមកប្រើ។ ឧបមាថាយើងចង់គណនាប្រវែងអ៊ីប៉ូតេនុស (c) នៃត្រីកោណកែងដោយប្រើទ្រឹស្តីបទពីតាក័រ៖
$$ c = \sqrt{a^2 + b^2} $$

```python
import math

a = 3
b = 4

# បំប្លែងរូបមន្តខាងលើមកជាកូដ
c = math.sqrt(a**2 + b**2)

print("ប្រវែងអ៊ីប៉ូតេនុសគឺ:", c) # លទ្ធផល: 5.0
```
ដូចដែលអ្នកបានឃើញ ការបំប្លែងគណិតវិទ្យាទៅជាកូដ គឺសាមញ្ញដូចការសរសេរវានៅលើក្រដាសអញ្ចឹង!
