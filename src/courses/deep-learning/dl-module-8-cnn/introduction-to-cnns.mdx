## �� Overview

CNNs revolutionised computer vision by exploiting the spatial structure of images. Instead of connecting every pixel to every neuron (which would require billions of parameters for a 1080p image), CNNs use local, weight-sharing filters that detect the same features anywhere in the image.


Convolutional Neural Networks (CNNs) គឺជាចំណុចសំខាន់នៅក្នុងកម្មវិធីសិក្សានេះ។ វាផ្ដល់នូវបច្ចេកទេសស្នូលសម្រាប់អ្នកដើម្បីពង្រឹងចំណេះដឹង និងការអនុវត្តជាក់ស្ដែង។

## 💡 គំនិតសំខាន់

Imagine scanning an image looking for a cat's eye. You don't need to learn a separate detector for "eye in top-left corner" and "eye in bottom-right corner" — the eye looks the same everywhere. CNNs exploit this **translation invariance** by using the same filter weights at every position.

## 🔢 គណិតវិទ្យា

**Convolution**: for input $X$ and filter $K$ of size $k \times k$:

$$S(i, j) = \sum_{m}\sum_{n} X(i+m,\, j+n) \cdot K(m, n)$$

**Output size** after convolution with padding $p$ and stride $s$:

$$O = \left\lfloor \frac{W - k + 2p}{s} \right\rfloor + 1$$

**Parameter count** in a conv layer: $k \times k \times C_{in} \times C_{out} + C_{out}$ (biases)

## 📖 ការសិក្សាស៊ីជម្រៅ

### Convolution Operation

$$S(i, j) = \sum_{m}\sum_{n} X(i+m,\, j+n) \cdot K(m, n)$$

### Output Size

$$O = \left\lfloor \frac{W - k + 2p}{s} \right\rfloor + 1$$

where $W$ = input size, $k$ = kernel size, $p$ = padding, $s$ = stride.

### CNN Architecture Pattern

```
Input → [Conv → BN → ReLU → Pool] × N → Flatten → FC → Output
```

| Layer type | Purpose |
|---|---|
| Conv | Learn spatial filters (edges, textures, shapes) |
| BatchNorm | Stabilise activations, faster training |
| ReLU | Non-linearity |
| MaxPool | Reduce spatial size, translation invariance |
| Dropout | Regularisation — randomly zero activations |
| Flatten | Convert spatial maps to vector |
| Linear (FC) | Final classification/regression |

import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

torch.manual_seed(42)
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# ── CNN ARCHITECTURE ──────────────────────────────────
class CNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()

        # Feature extraction
        self.features = nn.Sequential(
            # Block 1
            nn.Conv2d(1, 32, kernel_size=3, padding=1),   # 28→28
            nn.BatchNorm2d(32),
            nn.ReLU(inplace=True),
            nn.Conv2d(32, 32, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(2, 2),                            # 28→14
            nn.Dropout2d(0.25),

            # Block 2
            nn.Conv2d(32, 64, kernel_size=3, padding=1),  # 14→14
            nn.BatchNorm2d(64),
            nn.ReLU(inplace=True),
            nn.Conv2d(64, 64, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(2, 2),                            # 14→7
            nn.Dropout2d(0.25),
        )

        # Classifier
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(64 * 7 * 7, 256),
            nn.ReLU(inplace=True),
            nn.Dropout(0.5),
            nn.Linear(256, num_classes),
        )

    def forward(self, x):
        x = self.features(x)
        x = self.classifier(x)
        return x

model = CNN(num_classes=10).to(device)

def train_epoch(model, loader, criterion, optimiser):
    model.train()
    total_loss = correct = 0
    for X, y in loader:
        X, y = X.to(device), y.to(device)
        optimiser.zero_grad()
        logits = model(X)

        optimiser.step()
        total_loss += loss.item() * len(X)
        correct    += (logits.argmax(1) == y).sum().item()
    return total_loss / len(loader.dataset), correct / len(loader.dataset)

    return total_loss / len(loader.dataset), correct / len(loader.dataset)

## ✅ ចំណុចសំខាន់ៗដែលត្រូវចាំ

CNNs exploit spatial structure through **weight-sharing** (the same filter applied everywhere) and **local connectivity** (each neuron connects only to a local region). **Conv layers** learn spatial filters. **Pooling layers** reduce spatial dimensions and add translation invariance. **BatchNorm** stabilises training. **Dropout** prevents overfitting. The architecture pattern `Conv → BN → ReLU → Pool` repeated 2-3 times, followed by fully-connected layers, is the backbone of most image classification networks.
